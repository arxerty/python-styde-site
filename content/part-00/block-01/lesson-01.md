# Как здесь учиться

Каждый урок состоит из трёх вкладок: **Теория**, **Вопросы** и **Задачи**. Урок считается пройденным, когда вы ответили на все вопросы и решили все задачи. После всех уроков блока открывается **практикум**, а после всех блоков части — **проект**.

## Запуск кода прямо в тексте

Под каждым примером на Python есть кнопка **«▶ Запустить»**. Код выполняется прямо в браузере — ничего устанавливать не нужно. Первый запуск занимает ~10 секунд: браузер загружает интерпретатор Python.

```python
print("Привет, AI-инженер!")
print(2 + 2)
```

Кнопка **«✎ Изменить»** открывает редактор: меняйте пример и смотрите, что получится. Это лучший способ учиться — экспериментировать.

```python
name = "Ада"
print(f"Меня зовут {name}, и я пишу на Python")
```

Если программа просит ввод через `input()`, появится поле для данных:

```python
age = int(input("Сколько вам лет? "))
print("Через 10 лет вам будет", age + 10)
```

Ошибки показываются на русском — с номером строки и подсказкой:

```python
print(10 / 0)
```

## Вопросы

Бывают четырёх типов: один ответ, несколько ответов, «что выведет код?» и «найди ошибку». После ответа появляется разбор: почему верный вариант верен и почему остальные — нет. В уроке можно ответить заново, а в практикуме засчитывается только первая попытка.

## Задачи

Пишете код в редакторе и нажимаете **«Проверить»** — решение прогоняется через скрытые тесты. Вы видите, какие тесты прошли, а какие упали, и почему. Есть две подсказки, а эталонное решение с разбором открывается после решения или трёх попыток.

С шестой части курса появятся задачи с пометкой **«локально»**: вы скачиваете заготовку с тестами pytest, решаете у себя на компьютере и вставляете вывод тестов.

## Частые ошибки

- Читать теорию, не запуская примеры. Запускайте и меняйте каждый пример.
- Сразу открывать решение. Сначала подсказки — так знания закрепляются.

## Где это в AI-инженерии

Привычка экспериментировать с кодом маленькими шагами — ровно то, как AI-инженеры работают с моделями: поменял параметр, запустил, посмотрел на результат.
