# Шпаргалка: как работать с платформой

| Действие | Как |
|---|---|
| Запустить пример | «▶ Запустить» под кодом или `Ctrl+Enter` в редакторе |
| Изменить пример | «✎ Изменить» |
| Проверить задачу | «✔ Проверить» — скрытые тесты |
| Подсказка | «💡 Подсказка» — их две, по возрастанию |
| Эталон | после решения или 3 попыток |
| Повторить ошибки | «Мои ошибки» в шапке |

## Типы вопросов

- **Один ответ** — радиокнопки.
- **Несколько ответов** — отметьте все верные.
- **Что выведет код?** — мысленно выполните код построчно.
- **Найди ошибку** — ищите опечатки, типы, отступы.

## Частые ошибки

- `print` вместо `return` в функциях — тесты вызывают функцию и ждут возвращаемое значение.
- Лишний текст в выводе — при проверке по выводу сравнивается каждый символ (приглашения `input()` не учитываются).
