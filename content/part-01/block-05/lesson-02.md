# Перебор списков: enumerate, zip, сортировка

## Перебор элементов

Список — последовательность, поэтому его перебирают циклом `for`, как строку или `range`:

```python
models = ["small", "medium", "large"]
for model in models:
    print("Тестируем модель", model)
```

```text
Тестируем модель small
Тестируем модель medium
Тестируем модель large
```

Это самый частый и самый «питоничный» способ: на каждой итерации переменная указывает на очередной элемент, индексы не нужны.

### Перебор с индексами

Иногда нужна ещё и **позиция** элемента: вывести нумерованный список, сравнить соседей, изменить элемент в исходном списке. Новички пишут так:

```python
models = ["small", "medium", "large"]
for i in range(len(models)):
    print(i + 1, models[i])
```

```text
1 small
2 medium
3 large
```

Работает, но выглядит громоздко: `range(len(...))` и обращение по индексу `models[i]`. В Python для этого есть встроенная функция **`enumerate()`** — она выдаёт пары «номер, элемент»:

```python
models = ["small", "medium", "large"]
for i, model in enumerate(models):
    print(i, model)
for number, model in enumerate(models, start=1):
    print(f"{number}. {model}")
```

```text
0 small
1 medium
2 large
1. small
2. medium
3. large
```

`for i, model in enumerate(...)` — это распаковка пары в две переменные (подробно о распаковке — в следующем уроке). Параметр `start` задаёт начальный номер: для людей удобнее считать с 1.

Когда всё-таки нужен `range(len(...))`? Когда вы обращаетесь к нескольким позициям сразу — например, к соседним элементам `lst[i]` и `lst[i + 1]`:

```python
prices = [100, 105, 103, 110]
for i in range(len(prices) - 1):
    change = prices[i + 1] - prices[i]
    print(f"день {i + 1} → {i + 2}: {change:+d}")
```

```text
день 1 → 2: +5
день 2 → 3: -2
день 3 → 4: +7
```

### Изменение элементов при переборе

Переменная цикла — это ярлык на элемент. Присваивание ей **не меняет** список:

```python
scores = [1, 2, 3]
for score in scores:
    score = score * 10
print(scores)
```

```text
[1, 2, 3]
```

`score = score * 10` перевешивает ярлык `score` на новое число, а элемент списка остаётся прежним. Чтобы изменить список, обращайтесь по индексу:

```python
scores = [1, 2, 3]
for i in range(len(scores)):
    scores[i] = scores[i] * 10
print(scores)
```

```text
[10, 20, 30]
```

Ещё чаще вместо изменения на месте создают **новый** список — это проще и безопаснее (урок 7 про comprehensions сделает это одной строкой).

## zip: параллельный перебор

Часто данные лежат в нескольких списках «параллельно»: имена и оценки, предсказания и правильные ответы, вопросы и ответы. **`zip()`** перебирает несколько последовательностей одновременно, выдавая кортежи из элементов с одинаковыми позициями:

```python
names = ["Ада", "Алан", "Грейс"]
scores = [95, 88, 91]
for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

```text
Ада: 95
Алан: 88
Грейс: 91
```

Название — от застёжки-молнии: zip «сцепляет» последовательности зубчик к зубчику.

### Пример: точность классификатора

Самое частое применение `zip` в ML — сравнение предсказаний с правильными ответами:

```python
predictions = [1, 0, 1, 1, 0, 1]
labels = [1, 0, 0, 1, 0, 0]
correct = 0
for pred, label in zip(predictions, labels):
    if pred == label:
        correct += 1
print(f"Accuracy: {correct / len(labels):.2%}")
```

```text
Accuracy: 66.67%
```

### Разная длина

Если последовательности разной длины, `zip` останавливается на **самой короткой** — лишние элементы молча отбрасываются:

```python
print(list(zip([1, 2, 3], ["a", "b"])))
```

```text
[(1, 'a'), (2, 'b')]
```

Это удобно, но может скрыть ошибку: если предсказаний меньше, чем меток, вы посчитаете метрику по части данных и не заметите. В Python 3.10+ есть защита — `zip(a, b, strict=True)` выбросит `ValueError` при разной длине. Для данных, которые **обязаны** совпадать по длине, используйте `strict=True`.

`zip` можно комбинировать с `enumerate`:

```python
questions = ["2+2?", "Столица Франции?"]
answers = ["4", "Париж"]
for i, (q, a) in enumerate(zip(questions, answers), start=1):
    print(f"{i}. {q} → {a}")
```

```text
1. 2+2? → 4
2. Столица Франции? → Париж
```

## Сортировка: sort и sorted

Два способа отсортировать список:

- **`lst.sort()`** — метод, сортирует **на месте** (меняет список), возвращает `None`;
- **`sorted(seq)`** — функция, возвращает **новый** отсортированный список, исходный не меняет. Работает с любой последовательностью: строкой, кортежем, `range`.

```python
numbers = [5, 2, 9, 1]
ordered = sorted(numbers)
print(numbers, ordered)
numbers.sort()
print(numbers)
print(sorted("python"))
```

```text
[5, 2, 9, 1] [1, 2, 5, 9]
[1, 2, 5, 9]
['h', 'n', 'o', 'p', 't', 'y']
```

Как выбрать:

- исходный порядок ещё нужен → `sorted()`;
- список ваш и порядок не важен, а данных много → `sort()` (не тратит память на копию).

Классическая ошибка — `numbers = numbers.sort()`: метод вернёт `None`, и список потеряется. Тот же принцип, что у `append`.

### Обратный порядок

```python
scores = [70, 95, 82]
print(sorted(scores, reverse=True))
print(scores[::-1])
scores.reverse()
print(scores)
```

```text
[95, 82, 70]
[82, 95, 70]
[82, 95, 70]
```

Не путайте: `reverse=True` сортирует по убыванию, а `[::-1]` и `reverse()` просто разворачивают текущий порядок без сортировки.

### Ключ сортировки: key

Параметр `key` задаёт, **по какому признаку** сравнивать элементы. В него передают функцию, которую Python применит к каждому элементу:

```python
words = ["банан", "Яблоко", "киви", "абрикос"]
print(sorted(words))
print(sorted(words, key=str.lower))
print(sorted(words, key=len))
print(sorted(words, key=len, reverse=True))
```

```text
['Яблоко', 'абрикос', 'банан', 'киви']
['абрикос', 'банан', 'киви', 'Яблоко']
['киви', 'банан', 'Яблоко', 'абрикос']
['абрикос', 'Яблоко', 'банан', 'киви']
```

- Без `key` строки сравниваются по кодам символов: заглавная `Я` (1071) раньше строчных.
- `key=str.lower` — сравнивать в нижнем регистре (сами слова не меняются!).
- `key=len` — по длине.

Обратите внимание: функцию передают **без скобок** — `key=len`, а не `key=len()`. Мы не вызываем функцию сами, а отдаём её `sorted`, чтобы она вызвала её для каждого элемента. В блоке про функции вы научитесь писать свои ключи, в том числе короткими `lambda`-функциями.

### Стабильность

Сортировка в Python **стабильная**: элементы с одинаковым ключом сохраняют исходный порядок.

```python
animals = ["кот", "пёс", "ёж", "лев"]
print(sorted(animals, key=len))
```

```text
['ёж', 'кот', 'пёс', 'лев']
```

У `кот`, `пёс` и `лев` одинаковая длина 3, и они остались в том порядке, в каком были в исходном списке. Это свойство позволяет сортировать в несколько проходов: сначала по второстепенному признаку, потом по главному — порядок по второстепенному сохранится внутри групп.

### min и max с ключом

`key` есть и у `min`/`max` — так находят элемент с экстремальным признаком:

```python
words = ["нейросеть", "ИИ", "модель"]
print(max(words, key=len))
print(min(words, key=len))
```

```text
нейросеть
ИИ
```

### Что нельзя сравнивать

Сортировка сравнивает элементы друг с другом, поэтому они должны быть сравнимы:

```python
print(sorted([3, "a", 1]))
```

Результат — `TypeError: '<' not supported between instances of 'str' and 'int'`. Числа с числами, строки со строками — можно; смешивать нельзя.

## Как устроена сортировка

Python использует алгоритм **Timsort** (изобретён Тимом Питерсом в 2002 году специально для Python, позже переняли Java и Android). Он особенно быстр на «почти отсортированных» данных, которые часто встречаются в жизни, а в худшем случае выполняет порядка n·log₂n сравнений: для миллиона элементов — около 20 миллионов. Писать собственную сортировку в реальном коде не нужно — разбор алгоритмов сортировки ждёт вас в блоке 2.6.

## Разбор задачи: топ-k результатов поиска

Поисковая система (например, ретривер в RAG) вернула документы и оценки релевантности. Нужно выбрать три самых релевантных:

```python
documents = ["доставка", "возврат", "оплата", "гарантия", "скидки"]
scores = [0.42, 0.91, 0.67, 0.88, 0.15]
ranked = sorted(zip(scores, documents), reverse=True)
for rank, (score, doc) in enumerate(ranked[:3], start=1):
    print(f"{rank}. {doc} ({score:.2f})")
```

```text
1. возврат (0.91)
2. гарантия (0.88)
3. оплата (0.67)
```

Приём: `zip(scores, documents)` создаёт пары «оценка, документ». Пары сортируются по **первому** элементу (а при равенстве — по второму), поэтому оценку ставим первой. `reverse=True` — по убыванию, срез `[:3]` — первые три, `enumerate(start=1)` — места с единицы. Пять встроенных инструментов, одна задача.

## Частые ошибки

**1. `lst = lst.sort()`.** Метод возвращает `None`. Либо `lst.sort()`, либо `lst = sorted(lst)`.

**2. Присваивать переменной цикла, надеясь изменить список.** Меняйте `lst[i]` или создавайте новый список.

**3. zip с разной длиной.** Лишние элементы молча отбрасываются. Для критичных данных — `strict=True`.

**4. `key=len()` со скобками.** Нужно передать функцию, а не результат её вызова.

**5. Путать `reverse=True` и `reverse()`.** Первое сортирует по убыванию, второе разворачивает как есть.

**6. Сортировать смесь типов.** `TypeError`: числа и строки не сравниваются.

## Где это в AI-инженерии

- **Метрики.** `zip(predictions, labels)` — основа подсчёта accuracy, precision, recall вручную. В NumPy это заменяется векторными операциями, но логика та же.
- **Логи обучения.** `for epoch, loss in enumerate(losses, start=1):` — вывод истории обучения.
- **Ранжирование.** Ретривер RAG-системы сортирует документы по релевантности и берёт top-k — ровно как в разборе.
- **Сэмплирование токенов.** Стратегия top-k при генерации текста LLM: отсортировать токены по вероятности и выбирать только из k лучших. Вы реализуете её в блоке 3.3.
- **Пары вопрос-ответ.** Датасеты для fine-tuning и эвалов часто хранятся как параллельные списки вопросов и эталонных ответов — `zip` сцепляет их.
- **Контроль длины данных.** `zip(..., strict=True)` — дешёвая страховка от рассинхронизации признаков и меток, которая иначе тихо портит обучение.

## Итоги урока

- `for x in lst` — перебор элементов; `enumerate(lst, start=1)` — элементы с номерами.
- Присваивание переменной цикла не меняет список — меняйте по индексу или создавайте новый.
- `zip(a, b)` — параллельный перебор; останавливается на самой короткой последовательности; `strict=True` проверяет длины.
- `lst.sort()` — на месте, возвращает `None`; `sorted(seq)` — новый список.
- `reverse=True` — по убыванию; `key=функция` — признак сравнения; сортировка стабильна.
