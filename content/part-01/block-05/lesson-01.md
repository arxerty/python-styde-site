# Списки: создание, индексы, изменение, методы

## Зачем нужны коллекции

До сих пор каждая переменная хранила одно значение: одно число, одну строку. Но реальные данные — это **наборы**: оценки всех студентов, все сообщения диалога с чат-ботом, вероятности для каждого из 1000 классов, эмбеддинг из 768 чисел, тысячи документов базы знаний. Заводить по переменной на каждый элемент невозможно — нужны **коллекции**, которые хранят много значений под одним именем.

В Python четыре основные встроенные коллекции:

| Коллекция | Пример | Главное свойство |
|---|---|---|
| список `list` | `[3, 1, 2]` | упорядочен, изменяем |
| кортеж `tuple` | `(3, 1, 2)` | упорядочен, неизменяем |
| словарь `dict` | `{"имя": "Ада"}` | пары ключ → значение |
| множество `set` | `{3, 1, 2}` | уникальные элементы, без порядка |

Этот блок посвящён им всем, а начнём с самой универсальной — **списка**.

## Создание списка

Список записывается в квадратных скобках, элементы — через запятую:

```python
scores = [4, 5, 3, 5]
names = ["Ада", "Алан", "Грейс"]
mixed = [42, "текст", 3.14, True, None]
empty = []
print(scores)
print(names)
print(len(mixed), len(empty))
print(type(scores))
```

```text
[4, 5, 3, 5]
['Ада', 'Алан', 'Грейс']
5 0
<class 'list'>
```

Особенности:

- Элементы могут быть **любых типов**, даже разных в одном списке. На практике списки обычно однородны: список чисел, список строк — так с ними проще работать.
- Элементы могут **повторяться**.
- Порядок элементов **сохраняется**: какой порядок задали, такой и будет.
- `len()` возвращает количество элементов.

Список можно получить и из других последовательностей функцией `list()`:

```python
print(list("abc"))
print(list(range(5)))
print("a b c".split())
```

```text
['a', 'b', 'c']
[0, 1, 2, 3, 4]
['a', 'b', 'c']
```

## Индексы и срезы

С индексами и срезами всё работает **так же, как у строк**: нумерация с нуля, отрицательные индексы с конца, срез `[start:stop:step]` не включает `stop`.

```python
letters = ["a", "b", "c", "d", "e"]
print(letters[0], letters[-1])
print(letters[1:4])
print(letters[::-1])
print(letters[:2] + letters[3:])
```

```text
a e
['b', 'c', 'd']
['e', 'd', 'c', 'b', 'a']
['a', 'b', 'd', 'e']
```

Срез списка возвращает **новый список**. Обращение к несуществующему индексу — `IndexError`, как у строк.

## Списки изменяемы

Главное отличие от строк: список можно **менять на месте** — заменять, добавлять и удалять элементы.

```python
scores = [4, 5, 3]
scores[2] = 5
print(scores)
scores[0:2] = [2, 2, 2]
print(scores)
```

```text
[4, 5, 5]
[2, 2, 2, 5]
```

Присваивание по индексу заменяет элемент, присваивание срезу заменяет кусок списка (причём новый кусок может быть другой длины).

## Добавление элементов

```python
messages = []
messages.append("Привет!")
messages.append("Как дела?")
print(messages)
messages.insert(0, "Начало диалога")
print(messages)
messages.extend(["Отлично", "Пока"])
print(messages)
```

```text
['Привет!', 'Как дела?']
['Начало диалога', 'Привет!', 'Как дела?']
['Начало диалога', 'Привет!', 'Как дела?', 'Отлично', 'Пока']
```

| Метод | Действие |
|---|---|
| `append(x)` | добавить `x` в конец |
| `insert(i, x)` | вставить `x` на позицию `i` |
| `extend(seq)` | добавить в конец все элементы `seq` |

Частая путаница — `append` и `extend` для списка:

```python
a = [1, 2]
a.append([3, 4])
print(a)
b = [1, 2]
b.extend([3, 4])
print(b)
```

```text
[1, 2, [3, 4]]
[1, 2, 3, 4]
```

`append` добавляет **один** элемент — сам список целиком (получается вложенный список). `extend` добавляет **каждый** элемент по отдельности.

Шаблон «пустой список + `append` в цикле» — способ собрать список из данных:

```python
squares = []
for n in range(1, 6):
    squares.append(n * n)
print(squares)
```

```text
[1, 4, 9, 16, 25]
```

## Удаление элементов

```python
tasks = ["купить молоко", "написать код", "позвонить", "написать код"]
tasks.remove("написать код")
print(tasks)
last = tasks.pop()
print(last, tasks)
first = tasks.pop(0)
print(first, tasks)
del tasks[0]
print(tasks)
```

```text
['купить молоко', 'позвонить', 'написать код']
написать код ['купить молоко', 'позвонить']
купить молоко ['позвонить']
[]
```

| Способ | Действие | Если элемента нет |
|---|---|---|
| `remove(x)` | удалить **первое** вхождение значения `x` | `ValueError` |
| `pop()` | удалить и **вернуть** последний элемент | `IndexError` на пустом |
| `pop(i)` | удалить и вернуть элемент по индексу | `IndexError` |
| `del lst[i]` | удалить по индексу (или срез `del lst[1:3]`) | `IndexError` |
| `clear()` | удалить всё | — |

`pop()` особенно полезен: он одновременно удаляет и отдаёт элемент. Пара `append` + `pop` превращает список в **стек** — структуру «последним пришёл — первым ушёл» (как стопка тарелок). На стеке построены функция «Отменить» в редакторах и обход вложенных структур.

## Поиск и подсчёт

```python
colors = ["red", "green", "blue", "green"]
print("blue" in colors, "pink" in colors)
print(colors.index("green"))
print(colors.count("green"))
print(min([4, 1, 7]), max([4, 1, 7]), sum([4, 1, 7]))
```

```text
True False
1
2
1 7 12
```

- `x in lst` — есть ли элемент (как у строк, но ищется **элемент целиком**, а не подстрока);
- `index(x)` — позиция первого вхождения, `ValueError`, если нет;
- `count(x)` — сколько раз встречается;
- встроенные `min`, `max`, `sum` работают со списками чисел.

Помните мини-проект «анализатор текста» из прошлого блока? Подсчёт слов с методом `count` у списка становится короче, хотя и остаётся квадратичным. Настоящее решение — словарь, урок 4.

## Изменение на месте и копии

Важнейшая тема урока, на которой спотыкаются даже опытные разработчики. Вспомните модель «имя — ярлык на объект» из блока 1.1. Для строк она почти незаметна, потому что строки неизменяемы. Для списков — критична:

```python
original = [1, 2, 3]
alias = original
alias.append(4)
print(original)
print(alias is original)
```

```text
[1, 2, 3, 4]
True
```

`alias = original` **не копирует** список — теперь два имени указывают на **один и тот же** объект. Изменение через одно имя видно через другое. Оператор `is` проверяет, что это один объект.

Чтобы получить независимую копию, её нужно создать явно:

```python
original = [1, 2, 3]
copy1 = original.copy()
copy2 = original[:]
copy3 = list(original)
copy1.append(99)
print(original, copy1)
print(copy1 is original, copy1 == original[:])
```

```text
[1, 2, 3] [1, 2, 3, 99]
False False
```

Все три способа делают **поверхностную копию**: новый список с теми же элементами. Для списков чисел и строк этого достаточно. Если внутри — другие списки, они останутся общими; о глубоком копировании — в уроке 6 и в части 2.

Сравните `==` и `is`:

- `a == b` — равны ли **значения** (те же элементы в том же порядке);
- `a is b` — один ли это **объект** в памяти.

### Методы, которые меняют список, возвращают None

Ещё одна ловушка: методы, изменяющие список на месте (`append`, `insert`, `extend`, `remove`, `sort`, `reverse`, `clear`), возвращают `None`:

```python
numbers = [3, 1, 2]
result = numbers.append(4)
print(result)
print(numbers)
```

```text
None
[3, 1, 2, 4]
```

Поэтому `numbers = numbers.append(4)` — ошибка: в `numbers` окажется `None`. Это противоположность методам строк, которые список не меняют, а возвращают новую строку. Запомните: **строковые методы возвращают результат, списочные — меняют на месте**.

## Как список устроен внутри

Список в Python — это **динамический массив**: непрерывный блок памяти, в котором лежат ссылки на объекты-элементы. Отсюда скорость операций:

| Операция | Скорость |
|---|---|
| `lst[i]`, `lst[i] = x`, `len(lst)` | мгновенно, независимо от размера |
| `append(x)`, `pop()` | мгновенно (почти всегда) |
| `insert(0, x)`, `pop(0)` | медленно: сдвигаются все элементы |
| `x in lst`, `index`, `count`, `remove` | медленно: перебор всего списка |

Python заранее выделяет немного лишней памяти в конце, поэтому `append` почти никогда не требует перекладывания всего списка. А вставка в начало сдвигает все элементы — для списка из миллиона элементов это миллион операций. Если нужно часто добавлять и в начало, и в конец, используют `collections.deque` (часть 2). А если часто проверять «есть ли элемент» — множество (урок 5), где проверка мгновенная.

## Разбор задачи: история диалога с чат-ботом

Языковые модели не помнят разговор сами — приложение хранит историю сообщений и отправляет её модели целиком с каждым запросом. Простейшая версия истории — список строк. Чтобы не превысить контекстное окно модели, храним только последние N сообщений:

```python
history = []
max_messages = 4
for message in ["Привет", "Как дела?", "Отлично", "Что умеешь?", "Всё", "Пока"]:
    history.append(message)
    if len(history) > max_messages:
        history.pop(0)
    print(len(history), history)
```

```text
1 ['Привет']
2 ['Привет', 'Как дела?']
3 ['Привет', 'Как дела?', 'Отлично']
4 ['Привет', 'Как дела?', 'Отлично', 'Что умеешь?']
4 ['Как дела?', 'Отлично', 'Что умеешь?', 'Всё']
4 ['Отлично', 'Что умеешь?', 'Всё', 'Пока']
```

Это **скользящее окно**: новое сообщение добавляется в конец, самое старое удаляется из начала. Реальные приложения считают не сообщения, а токены, и часто сохраняют первое системное сообщение, — но принцип тот же. В части 7 вы реализуете полноценное управление историей с ролями `system`/`user`/`assistant` (там каждое сообщение будет словарём — урок 4).

## Частые ошибки

**1. `lst = lst.append(x)`.** Методы изменения возвращают `None` — присваивание затирает список.

**2. Копия через `=`.** `b = a` создаёт второе имя для того же списка. Для копии — `a.copy()` или `a[:]`.

**3. `append` вместо `extend`.** `a.append([3, 4])` добавит вложенный список, а не два элемента.

**4. `remove` несуществующего элемента.** `ValueError`. Сначала проверьте `if x in lst:`.

**5. Индекс за границей.** `lst[len(lst)]` → `IndexError`; у пустого списка нет даже `lst[0]` и `lst[-1]`.

**6. Удаление элементов во время перебора того же списка.** `for x in lst: lst.remove(x)` пропускает элементы, потому что список сдвигается под циклом. Перебирайте копию (`for x in lst[:]`) или собирайте новый список (урок 7).

## Где это в AI-инженерии

- **История сообщений.** Диалог с LLM — список сообщений, к которому добавляются новые (`append`), а старые обрезаются под лимит контекста.
- **Батчи и датасеты.** Примеры для обучения, предсказания модели, метки — списки. Перед передачей в нейросеть их превращают в массивы NumPy или тензоры PyTorch.
- **Векторы.** Эмбеддинг текста — по сути список из сотен чисел. В части 3 вы будете считать косинусное сходство на чистых списках, а затем — на NumPy.
- **Логи метрик.** `losses.append(loss)` после каждого шага, затем график кривой обучения — так строятся learning curves в блоке 4.3.
- **Ссылочная семантика.** В NumPy и PyTorch ситуация «два имени — один объект» встречается постоянно: срезы тензоров часто не копируют данные. Понимание `is` и `copy()` спасёт от неуловимых багов, когда «почему-то изменились исходные данные».

## Итоги урока

- Список `[a, b, c]` — упорядоченная изменяемая коллекция; индексы и срезы как у строк.
- Добавление: `append`, `insert`, `extend`; удаление: `remove`, `pop`, `del`, `clear`.
- Поиск: `in`, `index`, `count`; агрегаты: `len`, `min`, `max`, `sum`.
- `b = a` — не копия, а второе имя; копия — `a.copy()`, `a[:]`, `list(a)`.
- Методы изменения списка возвращают `None`.
- `append`/`pop()` с конца — быстро; вставка и удаление в начале, поиск `in` — медленно.
