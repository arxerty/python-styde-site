# Множества

## Коллекция без повторов

**Множество** (`set`) — неупорядоченная коллекция **уникальных** элементов. Это прямое воплощение математического понятия множества: элемент либо входит в него, либо нет, и дважды войти не может.

```python
tags = {"python", "ml", "python", "ai", "ml"}
print(sorted(tags))
print(len(tags))
print(type(tags))
```

```text
['ai', 'ml', 'python']
3
<class 'set'>
```

Мы выводим `sorted(tags)`, потому что `print(tags)` показывает элементы в непредсказуемом порядке — он может меняться даже между запусками программы.

Повторы исчезли автоматически. У множества три ключевых свойства:

1. **Уникальность** — каждый элемент хранится один раз.
2. **Нет порядка** — элементы не пронумерованы, обращение по индексу `tags[0]` невозможно (`TypeError`).
3. **Мгновенная проверка принадлежности** — `x in s` работает так же быстро, как поиск ключа в словаре, независимо от размера.

Множество устроено как словарь без значений — тоже хеш-таблица. Поэтому элементы множества, как и ключи словаря, должны быть **неизменяемыми**: числа, строки, кортежи — можно; списки, словари, другие множества — нельзя.

## Создание множества

```python
numbers = {1, 2, 3}
letters = set("банан")
from_list = set([3, 1, 3, 2, 1])
empty = set()
print(sorted(letters), sorted(from_list), len(empty))
print(type({}))
```

```text
['а', 'б', 'н'] [1, 2, 3] 0
<class 'dict'>
```

Главная ловушка: **`{}` — это пустой словарь, а не множество**. Пустое множество создаётся только как `set()`. Фигурные скобки исторически раньше достались словарям.

Функция `set()` принимает любую последовательность и оставляет уникальные элементы — самый быстрый способ узнать, какие различные значения есть в данных:

```python
labels = ["кот", "пёс", "кот", "птица", "пёс", "кот"]
classes = set(labels)
print(len(classes), sorted(classes))
```

```text
3 ['кот', 'птица', 'пёс']
```

`sorted()` превращает множество в отсортированный список — удобно для вывода в стабильном порядке. («птица» оказалась раньше «пёс»: первые буквы равны, а вторая буква `т` (код 1090) меньше `ё` (код 1105).)

### Удаление дубликатов с сохранением порядка

`list(set(data))` удаляет повторы, но **теряет порядок**. Если порядок важен, используют словарь — он сохраняет порядок вставки, а ключи уникальны:

```python
words = ["в", "лесу", "родилась", "ёлочка", "в", "лесу"]
print(list(dict.fromkeys(words)))
```

```text
['в', 'лесу', 'родилась', 'ёлочка']
```

`dict.fromkeys(words)` создаёт словарь с ключами из списка (значения — `None`), повторные ключи игнорируются. Это быстрая замена ручному циклу с `if word not in unique` из прошлых уроков.

## Изменение множества

```python
skills = {"python"}
skills.add("sql")
skills.add("python")
print(sorted(skills))
skills.update(["git", "docker"])
print(sorted(skills))
skills.remove("git")
skills.discard("java")
print(sorted(skills))
```

```text
['python', 'sql']
['docker', 'git', 'python', 'sql']
['docker', 'python', 'sql']
```

| Метод | Действие |
|---|---|
| `add(x)` | добавить элемент (повтор игнорируется) |
| `update(seq)` | добавить все элементы последовательности |
| `remove(x)` | удалить; `KeyError`, если нет |
| `discard(x)` | удалить, если есть; без ошибки |
| `pop()` | удалить и вернуть произвольный элемент |
| `clear()` | очистить |

## Операции над множествами

Настоящая сила множеств — в операциях из математики. Представим студентов двух курсов:

```python
python_course = {"Ада", "Алан", "Грейс", "Линус"}
ml_course = {"Грейс", "Линус", "Джеффри", "Ян"}
print("Оба курса:", sorted(python_course & ml_course))
print("Хотя бы один:", sorted(python_course | ml_course))
print("Только Python:", sorted(python_course - ml_course))
print("Ровно один курс:", sorted(python_course ^ ml_course))
```

```text
Оба курса: ['Грейс', 'Линус']
Хотя бы один: ['Ада', 'Алан', 'Грейс', 'Джеффри', 'Линус', 'Ян']
Только Python: ['Ада', 'Алан']
Ровно один курс: ['Ада', 'Алан', 'Джеффри', 'Ян']
```

| Операция | Оператор | Метод | Смысл |
|---|---|---|---|
| Пересечение | `a & b` | `a.intersection(b)` | есть в обоих |
| Объединение | `a \| b` | `a.union(b)` | есть хотя бы в одном |
| Разность | `a - b` | `a.difference(b)` | есть в `a`, но нет в `b` |
| Симметрическая разность | `a ^ b` | `a.symmetric_difference(b)` | ровно в одном |

Операторы требуют, чтобы оба операнда были множествами; методы принимают любые последовательности: `a.union(["x", "y"])`.

Разность несимметрична: `a - b` и `b - a` — разные множества.

### Сравнение множеств

```python
required = {"python", "sql"}
candidate = {"python", "sql", "docker"}
print(required <= candidate)
print(required.issubset(candidate))
print(candidate >= required)
print(required.isdisjoint({"java", "go"}))
```

```text
True
True
True
True
```

- `a <= b` — `a` подмножество `b` (все элементы `a` есть в `b`);
- `a < b` — строгое подмножество (подмножество и не равно);
- `a >= b` — надмножество;
- `isdisjoint` — нет общих элементов.

Вопрос «есть ли у кандидата все требуемые навыки?» — одна операция `required <= skills`.

## Почему проверка in такая быстрая

Сравним поиск в списке и в множестве. В списке Python перебирает элементы один за другим, пока не найдёт, — для миллиона элементов в худшем случае миллион сравнений. В множестве он вычисляет хеш и сразу смотрит в нужную ячейку таблицы.

```python
import time

items_list = list(range(1_000_000))
items_set = set(items_list)

start = time.perf_counter()
for _ in range(100):
    999_999 in items_list
list_time = time.perf_counter() - start

start = time.perf_counter()
for _ in range(100):
    999_999 in items_set
set_time = time.perf_counter() - start

print("Множество быстрее:", list_time > set_time * 100)
```

```text
Множество быстрее: True
```

(Модуль `time` и `import` — тема блока 1.7; здесь мы лишь замеряем время.) Разница — в тысячи раз. Правило: **если нужно много раз проверять «есть ли элемент», храните элементы во множестве**. Например, стоп-слова из блока про строки — классический пример: множество из сотни слов проверяется мгновенно и без ловушки с подстроками.

```python
stop_words = {"и", "в", "на", "с", "по", "это", "а", "о"}
words = "она пошла на рынок и купила о".split()
print([w for w in words if w not in stop_words])
```

```text
['она', 'пошла', 'рынок', 'купила']
```

Слово «она» не отфильтровано, хотя содержит «на», — множество сравнивает **элементы целиком**, а не подстроки. (Запись в квадратных скобках с `for` внутри — list comprehension, тема урока 7.)

## frozenset

Обычное множество изменяемо и потому не может быть элементом другого множества или ключом словаря. Для таких случаев есть **`frozenset`** — неизменяемое множество:

```python
pair = frozenset({"кот", "пёс"})
same = frozenset({"пёс", "кот"})
print(pair == same)
friends = {pair: "дружат"}
print(friends[same])
```

```text
True
дружат
```

Множества равны независимо от порядка элементов, поэтому `frozenset` удобен как ключ для неупорядоченных пар.

## Разбор задачи: сходство Жаккара

Насколько похожи два текста? Простейшая мера — **коэффициент Жаккара**: размер пересечения множеств слов, делённый на размер объединения. 1 — одинаковые наборы слов, 0 — ни одного общего.

```python
text_a = "кот сидит на окне"
text_b = "кот лежит на диване"
words_a = set(text_a.split())
words_b = set(text_b.split())
common = words_a & words_b
total = words_a | words_b
print("Общие:", sorted(common))
print(f"Жаккар: {len(common) / len(total):.3f}")
```

```text
Общие: ['кот', 'на']
Жаккар: 0.333
```

2 общих слова из 6 различных. Мера Жаккара используется для поиска почти-дубликатов в датасетах (алгоритм MinHash) и как простой базовый уровень (baseline) для сравнения текстов. Её слабость — она не понимает смысла: «кот» и «кошка» для неё разные слова. Эту проблему решают эмбеддинги и косинусное сходство (блоки 3.1 и 7.4).

## Частые ошибки

**1. `{}` для пустого множества.** Это словарь. Пустое множество — `set()`.

**2. Индекс у множества.** `s[0]` → `TypeError`. Нужна позиция — превратите в список (`sorted(s)`).

**3. Ожидать порядок.** Порядок элементов множества не определён; для стабильного вывода используйте `sorted()`.

**4. `list(set(...))` для удаления дублей, когда порядок важен.** Порядок теряется — используйте `dict.fromkeys()`.

**5. Изменяемые элементы.** `{[1, 2]}` → `TypeError: unhashable type: 'list'`. Используйте кортежи.

**6. `remove` отсутствующего элемента.** `KeyError`. Если элемента может не быть — `discard`.

## Где это в AI-инженерии

- **Словарь (vocabulary).** Набор уникальных токенов корпуса — множество; его размер — размер словаря модели.
- **Дедупликация.** Удаление повторяющихся примеров из датасета — множество уже встреченных текстов (или их хешей). Дубликаты в обучающих данных искажают метрики и приводят к запоминанию.
- **Утечка данных.** Проверка `train_ids & test_ids` должна давать пустое множество. Если тестовые примеры попали в обучение — метрики лгут (блок 5.1).
- **Метрики поиска.** Precision и recall в RAG: `relevant & retrieved` — сколько найденных документов действительно релевантны.
- **Фильтрация.** Стоп-слова, запрещённые слова, белые списки разрешённых инструментов для AI-агента — множества с мгновенной проверкой.
- **Классы.** `set(labels)` — какие классы вообще есть в данных; сравнение классов в train и test.

## Итоги урока

- Множество `{a, b}` — уникальные элементы без порядка; пустое — `set()`, не `{}`.
- `x in s` — мгновенно; элементы должны быть неизменяемыми.
- `add`, `update`, `remove`, `discard`; `set(seq)` — уникальные значения последовательности.
- Операции: `&` пересечение, `|` объединение, `-` разность, `^` симметрическая разность; `<=` подмножество.
- Для удаления дублей с сохранением порядка — `dict.fromkeys(seq)`.
- `frozenset` — неизменяемое множество, может быть ключом словаря.
