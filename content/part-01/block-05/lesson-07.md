# List, dict и set comprehensions

## Шаблон, который пишут чаще всего

Посмотрите на код, который вы писали в каждом уроке этого блока:

```python
squares = []
for n in range(1, 6):
    squares.append(n * n)
print(squares)
```

```text
[1, 4, 9, 16, 25]
```

Создать пустой список → пройти циклом → добавить преобразованный элемент. Этот шаблон настолько частый, что в Python для него есть специальный синтаксис — **list comprehension** (по-русски иногда говорят «списковое включение» или «генератор списка»):

```python
squares = [n * n for n in range(1, 6)]
print(squares)
```

```text
[1, 4, 9, 16, 25]
```

Одна строка вместо трёх, и читается почти как математическая запись: «список из n² для каждого n от 1 до 5».

## Синтаксис

```python norun
[выражение for переменная in последовательность]
```

Читается справа налево по смыслу: «для каждого элемента последовательности вычисли выражение и собери результаты в список». Сравните с обычным циклом — части те же:

| Цикл | Comprehension |
|---|---|
| `result = []` | `[` … `]` |
| `for x in data:` | `for x in data` |
| `result.append(выражение)` | `выражение` в начале |

Выражение может быть любым: арифметика, вызов функции или метода, f-строка, тернарный оператор.

```python
words = ["python", "data", "ai"]
print([w.upper() for w in words])
print([len(w) for w in words])
print([f"#{w}" for w in words])
print([int(x) for x in "3 1 4 1 5".split()])
```

```text
['PYTHON', 'DATA', 'AI']
[6, 4, 2]
['#python', '#data', '#ai']
[3, 1, 4, 1, 5]
```

Последний пример — идиома, которой вы будете пользоваться постоянно: превратить строку чисел в список чисел.

## Фильтрация: if в конце

После `for` можно добавить условие — тогда в результат попадут только подходящие элементы:

```python
numbers = [5, -2, 8, 0, -7, 3]
positives = [n for n in numbers if n > 0]
print(positives)
long_words = [w for w in "я учу машинное обучение".split() if len(w) > 3]
print(long_words)
```

```text
[5, 8, 3]
['машинное', 'обучение']
```

Это эквивалент цикла:

```python
numbers = [5, -2, 8, 0, -7, 3]
positives = []
for n in numbers:
    if n > 0:
        positives.append(n)
print(positives)
```

```text
[5, 8, 3]
```

Можно одновременно преобразовывать и фильтровать:

```python
numbers = [5, -2, 8, 0, -7, 3]
print([n * 10 for n in numbers if n % 2 == 1])
```

```text
[50, -70, 30]
```

## Условное выражение: if-else в начале

Не путайте фильтр с **выбором значения**. Если нужно оставить **все** элементы, но преобразовать их по-разному, используется тернарный оператор — и он стоит **в начале**, в выражении:

```python
numbers = [5, -2, 8, 0]
print(["+" if n > 0 else "-" if n < 0 else "0" for n in numbers])
print([n if n >= 0 else 0 for n in numbers])
```

```text
['+', '-', '+', '0']
[5, 0, 8, 0]
```

Правило:

- `[x for x in data if условие]` — **фильтр**: элементы отбрасываются; `else` здесь нельзя;
- `[a if условие else b for x in data]` — **выбор**: количество элементов не меняется; `else` обязателен.

Второй пример (`n if n >= 0 else 0`) — это «обрезание отрицательных значений до нуля». В нейросетях эту операцию называют **ReLU** — самая популярная функция активации (блок 6.1).

## Dict comprehension

Фигурные скобки и пара `ключ: значение` создают словарь:

```python
words = ["кот", "мышь", "слон"]
lengths = {w: len(w) for w in words}
print(lengths)
prices = {"кофе": 199, "чай": 89, "сок": 150}
expensive = {name: price for name, price in prices.items() if price > 100}
print(expensive)
with_tax = {name: round(price * 1.2) for name, price in prices.items()}
print(with_tax)
```

```text
{'кот': 3, 'мышь': 4, 'слон': 4}
{'кофе': 199, 'сок': 150}
{'кофе': 239, 'чай': 107, 'сок': 180}
```

Частые применения — построить словарь из двух списков и «перевернуть» словарь:

```python
labels = ["негатив", "нейтрально", "позитив"]
id2label = {i: label for i, label in enumerate(labels)}
label2id = {label: i for i, label in id2label.items()}
print(id2label)
print(label2id)
```

```text
{0: 'негатив', 1: 'нейтрально', 2: 'позитив'}
{'негатив': 0, 'нейтрально': 1, 'позитив': 2}
```

Сравните с задачей «кодирование меток» из урока 4 — там понадобилось три цикла.

## Set comprehension

Фигурные скобки **без** двоеточия создают множество — с автоматическим удалением повторов:

```python
text = "Кот видит кота. Кот спит"
first_letters = {w[0].lower() for w in text.split()}
print(sorted(first_letters))
```

```text
['в', 'к', 'с']
```

## Генераторное выражение

Если вместо скобок `[]` поставить круглые `()`, получится **генераторное выражение**. Оно не создаёт список в памяти, а выдаёт элементы по одному. Его удобно передавать прямо в функции-накопители `sum`, `max`, `min`, `any`, `all`, `"".join`:

```python
numbers = [3, 8, 1, 9]
print(sum(n * n for n in numbers))
print(any(n > 8 for n in numbers))
print(all(n > 0 for n in numbers))
print(", ".join(str(n) for n in numbers))
```

```text
155
True
True
3, 8, 1, 9
```

Когда генераторное выражение — единственный аргумент функции, вторые скобки не нужны: `sum(x for x in data)`. Для миллиона элементов это экономит память: список из миллиона квадратов не создаётся. Подробно о генераторах — в блоке 2.3.

## Вложенные циклы в comprehension

Можно написать несколько `for` подряд — они работают как вложенные циклы, **в том же порядке**, что и в обычном коде:

```python
pairs = [(x, y) for x in range(1, 3) for y in "ab"]
print(pairs)
matrix = [[1, 2, 3], [4, 5, 6]]
flat = [value for row in matrix for value in row]
print(flat)
```

```text
[(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]
[1, 2, 3, 4, 5, 6]
```

«Сплющивание» вложенного списка `[value for row in matrix for value in row]` читается так же, как два вложенных `for`: сначала внешний (`for row`), потом внутренний (`for value`).

Comprehension может быть и вложенным — например, для создания таблицы без ловушки с умножением списка из прошлого урока или для транспонирования матрицы:

```python
grid = [[0] * 3 for _ in range(2)]
grid[0][0] = 1
print(grid)
matrix = [[1, 2, 3], [4, 5, 6]]
transposed = [[row[i] for row in matrix] for i in range(3)]
print(transposed)
```

```text
[[1, 0, 0], [0, 0, 0]]
[[1, 4], [2, 5], [3, 6]]
```

Каждая итерация внешнего comprehension создаёт **новый** внутренний список — строки таблицы независимы. Транспонирование (строки ↔ столбцы) — операция, которую вы встретите в линейной алгебре (блок 3.1).

## Когда НЕ использовать comprehension

Comprehension — мощный инструмент, но не универсальный.

**1. Сложная логика.** Если выражение или условие не помещается в одну понятную строку — пишите обычный цикл. Вложенные comprehension с несколькими условиями быстро становятся нечитаемыми:

```python norun
# Плохо: трудно понять
result = [x * y for x in a if x > 0 for y in b if y % 2 == 0 if x != y]
```

**2. Побочные эффекты.** Comprehension предназначен для **создания коллекции**. Если вам нужно что-то напечатать или изменить внешнее состояние — используйте цикл:

```python norun
# Плохо: создаёт список из None ради печати
[print(x) for x in data]
# Хорошо
for x in data:
    print(x)
```

**3. Нужен break.** В comprehension нельзя прервать перебор досрочно. Для поиска первого подходящего используйте цикл с `break` или `next()` (часть 2).

Правило: comprehension — для **простого преобразования и/или фильтрации** с понятным результатом.

## Скорость

Comprehension обычно немного быстрее эквивалентного цикла с `append`: интерпретатор оптимизирует этот шаблон (не нужно каждый раз искать метод `append`). Но главное преимущество — читаемость: намерение «построить список» видно сразу, по квадратным скобкам.

## Разбор задачи: предобработка датасета отзывов

Соберём конвейер подготовки данных, где каждая стадия — одно comprehension:

```python
raw = [
    {"text": "  Отличный товар!  ", "rating": 5},
    {"text": "", "rating": 3},
    {"text": "Ужасно, не рекомендую", "rating": 1},
    {"text": "Нормально", "rating": None},
    {"text": "Супер, беру ещё", "rating": 4},
]
clean = [r for r in raw if r["text"].strip() and r["rating"] is not None]
texts = [r["text"].strip().lower() for r in clean]
labels = [1 if r["rating"] >= 4 else 0 for r in clean]
print(texts)
print(labels)
print({label: labels.count(label) for label in set(labels)})
```

```text
['отличный товар!', 'ужасно, не рекомендую', 'супер, беру ещё']
[1, 0, 1]
{0: 1, 1: 2}
```

Три стадии:

1. **Фильтр** — убрать пустые тексты и записи без оценки (comprehension с `if`).
2. **Преобразование** — нормализовать текст (comprehension с выражением).
3. **Разметка** — превратить оценку в бинарную метку «позитив/негатив» (тернарный оператор в выражении).

Последняя строка — dict comprehension для баланса классов. Именно так выглядит первичная подготовка данных перед обучением классификатора тональности — с той разницей, что в реальности данных тысячи, и делается это в pandas (блок 4.2) с тем же смыслом.

## Частые ошибки

**1. `else` в фильтре.** `[x for x in data if x > 0 else 0]` — `SyntaxError`. Если нужен `else`, переносите условие в начало: `[x if x > 0 else 0 for x in data]`.

**2. Неверный порядок вложенных for.** Пишутся в том же порядке, что и вложенные циклы: внешний первым.

**3. Comprehension ради побочных эффектов.** `[print(x) for x in data]` — используйте цикл.

**4. Слишком сложные выражения.** Если не читается с первого раза — разбейте на шаги или напишите цикл.

**5. `{}` для пустого множества** по аналогии с set comprehension — это всё ещё словарь.

**6. Ожидать, что генераторное выражение можно перебрать дважды.** Генератор «одноразовый»: после первого прохода он пуст. Нужен повторный перебор — создайте список.

## Где это в AI-инженерии

- **Предобработка данных.** Фильтрация пустых и некачественных примеров, нормализация текстов, преобразование меток — comprehension в каждом скрипте подготовки данных.
- **Маппинги меток.** `id2label = {i: l for i, l in enumerate(labels)}` — ровно так в конфигурациях моделей Hugging Face.
- **Сборка контекста RAG.** `context = "\n\n".join(doc["text"] for doc in documents if doc["score"] > 0.5)` — склеить релевантные документы в контекст для модели.
- **Батчи токенов.** `[tokenizer.encode(t) for t in texts]` — кодирование списка текстов.
- **Метрики.** `accuracy = sum(p == y for p, y in zip(preds, labels)) / len(labels)` — точность одной строкой.
- **Фильтрация ответов.** Отбор кандидатов-ответов модели по проверкам: `[a for a in answers if is_valid(a)]`.

## Итоги урока

- `[выражение for x in seq]` — новый список; `if` в конце — фильтр.
- `[a if условие else b for x in seq]` — выбор значения; `else` обязателен.
- `{k: v for ...}` — словарь; `{x for ...}` — множество; `(x for ...)` — генераторное выражение для `sum`, `any`, `join`.
- Несколько `for` — вложенные циклы в обычном порядке; `[[0] * n for _ in range(m)]` — безопасная таблица.
- Comprehension — для простых преобразований; сложная логика, побочные эффекты и `break` — в обычный цикл.
