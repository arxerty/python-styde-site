# Вложенные структуры — как JSON

## Данные из реального мира вложены

Коллекции могут содержать другие коллекции: список словарей, словарь списков, словарь словарей. Именно так выглядят почти все данные, с которыми работает AI-инженер:

- ответ API языковой модели — словарь, внутри которого список вариантов ответа, внутри каждого — словарь с сообщением;
- датасет — список записей-словарей;
- конфигурация эксперимента — словарь с разделами-словарями;
- история диалога — список сообщений-словарей.

Такие структуры повторяют формат **JSON** (JavaScript Object Notation) — главный формат обмена данными в вебе. Объект JSON соответствует словарю Python, массив — списку. Научившись уверенно работать с вложенными структурами, вы сможете читать ответ любого API.

## Список словарей: таблица записей

Самая частая форма — список однотипных записей, как строки таблицы:

```python
students = [
    {"name": "Ада", "age": 36, "scores": [5, 5, 4]},
    {"name": "Алан", "age": 41, "scores": [4, 5, 5, 5]},
    {"name": "Грейс", "age": 85, "scores": [5, 3]},
]
print(len(students))
print(students[0])
print(students[0]["name"])
print(students[1]["scores"][-1])
```

```text
3
{'name': 'Ада', 'age': 36, 'scores': [5, 5, 4]}
Ада
5
```

Доступ к вложенным данным — **цепочка обращений**, которая читается слева направо: `students[1]` — вторая запись (словарь), `["scores"]` — её список оценок, `[-1]` — последняя оценка.

Перебор — обычный цикл, в котором каждая переменная — словарь:

```python
students = [
    {"name": "Ада", "scores": [5, 5, 4]},
    {"name": "Алан", "scores": [4, 5, 5, 5]},
    {"name": "Грейс", "scores": [5, 3]},
]
for student in students:
    scores = student["scores"]
    average = sum(scores) / len(scores)
    print(f"{student['name']:<6} средний балл {average:.2f}")
```

```text
Ада    средний балл 4.67
Алан   средний балл 4.75
Грейс  средний балл 4.00
```

### Сортировка и фильтрация записей

Отсортировать записи по полю можно, передав в `key` функцию, которая достаёт поле. Пока вы не умеете писать функции (это следующий блок), используем приём «украсить — отсортировать»: собрать кортежи `(поле, позиция)`:

```python
students = [
    {"name": "Ада", "age": 36},
    {"name": "Алан", "age": 41},
    {"name": "Билл", "age": 30},
]
pairs = []
for i, student in enumerate(students):
    pairs.append((student["age"], i))
for age, i in sorted(pairs):
    print(students[i]["name"], age)
```

```text
Билл 30
Ада 36
Алан 41
```

В блоке 1.6 это превратится в одну строку `sorted(students, key=lambda s: s["age"])`.

## Словарь списков и словарь словарей

**Словарь списков** — группировка (вы видели её в уроке 4): ключ — категория, значение — элементы категории.

```python
by_city = {"Лондон": ["Ада", "Алан"], "Нью-Йорк": ["Грейс"]}
by_city["Лондон"].append("Тим")
for city, people in by_city.items():
    print(city, "—", ", ".join(people))
```

```text
Лондон — Ада, Алан, Тим
Нью-Йорк — Грейс
```

**Словарь словарей** — индекс записей по уникальному ключу, например по идентификатору. Поиск записи мгновенный:

```python
users = {
    "u1": {"name": "Ада", "plan": "pro"},
    "u2": {"name": "Алан", "plan": "free"},
}
print(users["u2"]["plan"])
users["u2"]["plan"] = "pro"
print(users["u2"])
```

```text
free
{'name': 'Алан', 'plan': 'pro'}
```

Из списка записей такой индекс строится одним циклом:

```python
records = [{"id": 7, "title": "Отчёт"}, {"id": 12, "title": "План"}]
by_id = {}
for record in records:
    by_id[record["id"]] = record
print(by_id[12]["title"])
```

```text
План
```

## Безопасный доступ к вложенным данным

Реальные данные неидеальны: в одной записи поле есть, в другой нет. Цепочка `data["a"]["b"]["c"]` упадёт с `KeyError` на первом отсутствующем ключе. Используйте `get` с подходящим значением по умолчанию на каждом уровне:

```python
response = {"model": "mini", "usage": {"input_tokens": 120}}
output_tokens = response.get("usage", {}).get("output_tokens", 0)
missing = response.get("error", {}).get("message", "нет ошибки")
print(output_tokens, missing)
```

```text
0 нет ошибки
```

`response.get("usage", {})` возвращает пустой словарь, если раздела нет, — и следующий `.get` не падает. Значение по умолчанию на каждом уровне должно быть того же типа, что ожидаемые данные: `{}` для словаря, `[]` для списка.

## Пример: разбор ответа языковой модели

Ответы LLM API имеют глубокую вложенность. Вот упрощённый ответ в стиле OpenAI Chat Completions:

```python
response = {
    "id": "chatcmpl-123",
    "model": "gpt-mini",
    "choices": [
        {
            "index": 0,
            "message": {"role": "assistant", "content": "Словарь — это хеш-таблица."},
            "finish_reason": "stop",
        }
    ],
    "usage": {"prompt_tokens": 25, "completion_tokens": 9, "total_tokens": 34},
}
answer = response["choices"][0]["message"]["content"]
reason = response["choices"][0]["finish_reason"]
tokens = response["usage"]["total_tokens"]
print(answer)
print(f"Причина остановки: {reason}, токенов: {tokens}")
```

```text
Словарь — это хеш-таблица.
Причина остановки: stop, токенов: 34
```

Путь к ответу: словарь → ключ `choices` → список → элемент `0` → словарь → ключ `message` → словарь → ключ `content` → строка. Когда структура незнакома, разбирайтесь **по шагам**: выведите `response.keys()`, затем `type(response["choices"])`, затем первый элемент — и так спускайтесь по уровням. Это стандартный приём исследования незнакомого JSON.

`finish_reason` полезно проверять: `"length"` означает, что ответ обрезан по лимиту `max_tokens` и, возможно, неполон.

## Копирование: поверхностное и глубокое

В уроке про списки вы узнали, что `copy()` создаёт **поверхностную** копию. Для вложенных структур это важно: внешний контейнер копируется, а вложенные объекты — **общие**:

```python
original = {"name": "Ада", "tags": ["python"]}
shallow = original.copy()
shallow["name"] = "Алан"
shallow["tags"].append("ml")
print(original)
```

```text
{'name': 'Ада', 'tags': ['python', 'ml']}
```

Имя не изменилось (мы перепривязали ключ в копии), а список тегов изменился и в оригинале: обе структуры ссылаются на **один** список. Для полной независимой копии нужна **глубокая** копия:

```python
import copy

original = {"name": "Ада", "tags": ["python"]}
deep = copy.deepcopy(original)
deep["tags"].append("ml")
print(original)
print(deep)
```

```text
{'name': 'Ада', 'tags': ['python']}
{'name': 'Ада', 'tags': ['python', 'ml']}
```

`copy.deepcopy` рекурсивно копирует все уровни. Подробно об этом — в блоке 2.6 «Python изнутри».

### Ловушка: размножение списка

Похожая ловушка — создание «таблицы» умножением:

```python
grid = [[0] * 3] * 2
grid[0][0] = 1
print(grid)
```

```text
[[1, 0, 0], [1, 0, 0]]
```

`[[0] * 3] * 2` создаёт список из **двух ссылок на один и тот же** внутренний список. Изменили «первую строку» — изменилась и вторая. Правильно создавать строки по отдельности (в уроке 7 — одной строкой через comprehension):

```python
grid = []
for _ in range(2):
    grid.append([0] * 3)
grid[0][0] = 1
print(grid)
```

```text
[[1, 0, 0], [0, 0, 0]]
```

## JSON на практике

Модуль `json` превращает строку JSON в структуру Python и обратно (подробно о файлах JSON — в блоке 1.7):

```python
import json

text = '{"name": "Ада", "skills": ["python", "ml"], "active": true, "manager": null}'
data = json.loads(text)
print(data["skills"][1], data["active"], data["manager"])
print(json.dumps(data, ensure_ascii=False))
```

```text
ml True None
{"name": "Ада", "skills": ["python", "ml"], "active": true, "manager": null}
```

Обратите внимание на соответствия: JSON `true`/`false`/`null` ↔ Python `True`/`False`/`None`; в JSON строки только в двойных кавычках. `ensure_ascii=False` сохраняет кириллицу читаемой, иначе она превратится в коды `Ада`.

## Разбор задачи: агрегирование заказов

Типичная задача анализа данных: список заказов, нужно посчитать выручку по категориям и найти самую доходную.

```python
orders = [
    {"id": 1, "category": "книги", "items": [{"price": 500, "qty": 2}]},
    {"id": 2, "category": "техника", "items": [{"price": 30000, "qty": 1}, {"price": 1500, "qty": 2}]},
    {"id": 3, "category": "книги", "items": [{"price": 800, "qty": 1}]},
]
revenue = {}
for order in orders:
    total = 0
    for item in order["items"]:
        total += item["price"] * item["qty"]
    category = order["category"]
    revenue[category] = revenue.get(category, 0) + total
print(revenue)
best = max(revenue, key=revenue.get)
print("Лидер:", best, revenue[best])
```

```text
{'книги': 1800, 'техника': 33000}
Лидер: техника 33000
```

Структура кода повторяет структуру данных: внешний цикл — по заказам, внутренний — по позициям заказа. Это общий принцип: **форма кода следует за формой данных**. Сумма по заказу — накопитель, выручка по категориям — шаблон подсчёта со словарём, лидер — `max` с ключом `get`.

## Частые ошибки

**1. `KeyError` в глубокой цепочке.** Одно отсутствующее поле роняет всю программу. Для необязательных данных — `get(..., {})` на каждом уровне.

**2. Путаница уровней.** `response["choices"]["message"]` — ошибка: `choices` — список, сначала нужен индекс `[0]`. Проверяйте `type()` на каждом шаге.

**3. Поверхностная копия вложенных данных.** Изменения внутренних списков видны в оригинале. Используйте `copy.deepcopy`.

**4. `[[0] * n] * m`.** Все строки — один и тот же список.

**5. Кавычки в f-строках.** `f"{s["name"]}"` до Python 3.12 — ошибка. Используйте `f"{s['name']}"`.

**6. JSON ≠ Python-литерал.** `true`, `null` и одинарные кавычки — разные в двух форматах. Не собирайте JSON вручную, используйте `json.dumps`.

## Где это в AI-инженерии

- **Ответы LLM API.** `response["choices"][0]["message"]["content"]` (OpenAI) или `response["content"][0]["text"]` (Anthropic) — ежедневная работа. В SDK те же данные доступны как атрибуты объектов, но структура та же.
- **История диалога.** Список словарей `{"role": ..., "content": ...}`; при вызове инструментов сообщения становятся ещё вложеннее.
- **Structured output.** Модель возвращает JSON по заданной схеме — например, список извлечённых сущностей с полями. Его разбирают и валидируют (Pydantic, блок 2.5).
- **Датасеты.** Формат JSONL (по JSON-объекту на строку) — стандарт для датасетов fine-tuning и эвалов: каждая строка — словарь с полями `prompt`, `completion`, `metadata`.
- **Описания инструментов агентов.** Инструменты описываются JSON Schema — вложенным словарём с типами параметров (блок 7.6).
- **Конфигурации.** Настройки обучения в YAML/JSON — словарь словарей: `config["optimizer"]["lr"]`.

## Итоги урока

- Вложенные структуры — коллекции в коллекциях; они повторяют формат JSON.
- Доступ — цепочка обращений `data["a"][0]["b"]`; незнакомую структуру исследуйте по уровням через `type()` и `keys()`.
- Безопасный доступ к необязательным полям — `get(key, {})` на каждом уровне.
- Список записей → индекс-словарь по id одним циклом; словарь списков — группировка.
- `copy()` поверхностный; для вложенных данных — `copy.deepcopy`; `[[0] * n] * m` — ловушка.
- `json.loads` / `json.dumps` переводят между JSON-строкой и структурами Python.
