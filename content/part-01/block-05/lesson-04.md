# Словари

## Поиск по имени, а не по номеру

Список хорош, когда к элементам обращаются **по позиции**: первый, последний, i-й. Но часто данные ищут **по имени**: телефон по имени контакта, цену по названию товара, перевод по слову, номер токена по тексту токена. Со списком пришлось бы перебирать все элементы в поисках нужного — медленно и неудобно.

**Словарь** (`dict`) хранит пары **ключ → значение** и позволяет мгновенно получить значение по ключу:

```python
phones = {"Ада": "+7 900 111-22-33", "Алан": "+7 900 444-55-66"}
print(phones["Ада"])
print(len(phones))
print(type(phones))
```

```text
+7 900 111-22-33
2
<class 'dict'>
```

Словарь записывается в фигурных скобках: пары `ключ: значение` через запятую. Как в бумажном словаре: по слову (ключу) находим статью (значение).

## Создание словаря

```python
empty = {}
person = {"name": "Ада", "age": 36, "langs": ["Python", "C"]}
config = dict(model="mini", temperature=0.7, max_tokens=256)
pairs = dict([("a", 1), ("b", 2)])
print(person)
print(config)
print(pairs)
```

```text
{'name': 'Ада', 'age': 36, 'langs': ['Python', 'C']}
{'model': 'mini', 'temperature': 0.7, 'max_tokens': 256}
{'a': 1, 'b': 2}
```

- Значения могут быть любыми: числами, строками, списками, другими словарями.
- Ключи **уникальны**: повторный ключ перезапишет значение.
- Ключи должны быть **неизменяемыми** (хешируемыми): строки, числа, кортежи из неизменяемых элементов. Списки и словари ключами быть не могут.
- `dict(ключ=значение)` — удобная запись для ключей-строк, похожих на имена переменных.
- `dict(список_пар)` строит словарь из последовательности пар — например, из результата `zip`.

```python
words = ["кот", "пёс"]
translations = ["cat", "dog"]
ru_en = dict(zip(words, translations))
print(ru_en)
```

```text
{'кот': 'cat', 'пёс': 'dog'}
```

## Чтение значений: [] и get

Доступ через квадратные скобки требует, чтобы ключ существовал:

```python
prices = {"кофе": 199, "чай": 89}
print(prices["кофе"])
print(prices["сок"])
```

Вторая строка упадёт с `KeyError: 'сок'`. Метод **`get`** безопаснее: при отсутствии ключа он возвращает `None` или значение по умолчанию:

```python
prices = {"кофе": 199, "чай": 89}
print(prices.get("сок"))
print(prices.get("сок", 0))
print(prices.get("чай", 0))
```

```text
None
0
89
```

Когда что использовать:

- `d[key]` — ключ **обязан** быть (его отсутствие — ошибка в программе, и лучше узнать о ней сразу);
- `d.get(key, default)` — ключа **может не быть**, и это нормальная ситуация.

Проверить наличие ключа — оператор `in` (он проверяет **ключи**, не значения):

```python
prices = {"кофе": 199, "чай": 89}
print("кофе" in prices, 199 in prices, "сок" not in prices)
```

```text
True False True
```

## Изменение словаря

```python
stock = {"яблоки": 10}
stock["груши"] = 5
stock["яблоки"] = 8
stock["яблоки"] += 2
print(stock)
del stock["груши"]
removed = stock.pop("яблоки")
print(removed, stock)
print(stock.pop("бананы", "нет такого"))
```

```text
{'яблоки': 10, 'груши': 5}
10 {}
нет такого
```

Разберём:

- `d[key] = value` — **добавляет** ключ или **заменяет** значение существующего;
- `del d[key]` — удаляет пару (`KeyError`, если ключа нет);
- `d.pop(key)` — удаляет и возвращает значение; с вторым аргументом не падает при отсутствии ключа;
- `d.update(other)` — добавляет/заменяет пары из другого словаря;
- `d.clear()` — очищает словарь.

```python
defaults = {"model": "mini", "temperature": 0.7, "max_tokens": 256}
user = {"temperature": 0.2}
config = defaults.copy()
config.update(user)
print(config)
print(defaults | user)
```

```text
{'model': 'mini', 'temperature': 0.2, 'max_tokens': 256}
{'model': 'mini', 'temperature': 0.2, 'max_tokens': 256}
```

Это стандартный приём «настройки по умолчанию + переопределения пользователя». Оператор `|` (Python 3.9+) делает то же, создавая новый словарь; значения из правого операнда побеждают.

## Перебор словаря

Цикл `for` по словарю перебирает **ключи**:

```python
scores = {"Ада": 95, "Алан": 88, "Грейс": 91}
for name in scores:
    print(name, scores[name])
```

```text
Ада 95
Алан 88
Грейс 91
```

Три «представления» словаря позволяют перебирать то, что нужно:

```python
scores = {"Ада": 95, "Алан": 88, "Грейс": 91}
print(list(scores.keys()))
print(list(scores.values()))
print(list(scores.items()))
for name, score in scores.items():
    print(f"{name}: {score}")
print(sum(scores.values()) / len(scores))
```

```text
['Ада', 'Алан', 'Грейс']
[95, 88, 91]
[('Ада', 95), ('Алан', 88), ('Грейс', 91)]
Ада: 95
Алан: 88
Грейс: 91
91.33333333333333
```

`items()` выдаёт пары `(ключ, значение)` — их удобно распаковывать прямо в заголовке цикла. Это самый частый способ перебора.

**Порядок.** С Python 3.7 словарь **сохраняет порядок добавления** ключей. Перебор идёт в том порядке, в каком ключи появились. На это можно полагаться.

**Нельзя менять размер словаря во время перебора.** Добавление или удаление ключей внутри `for key in d` вызовет `RuntimeError: dictionary changed size during iteration`. Перебирайте копию списка ключей: `for key in list(d):`.

## Шаблон «подсчёт»

Самый важный шаблон с словарями — подсчёт частот. Помните квадратичный подсчёт слов из прошлого блока? Со словарём он делается **за один проход**:

```python
words = "кот видит кота кот спит кот".split()
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
print(counts)
```

```text
{'кот': 3, 'видит': 1, 'кота': 1, 'спит': 1}
```

`counts.get(word, 0)` возвращает текущее количество (или 0 для нового слова), прибавляем единицу и записываем обратно. Для текста из миллиона слов это миллион быстрых операций вместо миллиардов сравнений.

### Сортировка по значению

Чтобы вывести самые частые слова, сортируем **ключи по значениям**. Ключ сортировки — метод `get` самого словаря: для каждого слова он вернёт его частоту:

```python
counts = {"кот": 3, "видит": 1, "мышь": 2}
for word in sorted(counts, key=counts.get, reverse=True):
    print(word, counts[word])
```

```text
кот 3
мышь 2
видит 1
```

Благодаря стабильности сортировки и сохранению порядка в словаре слова с одинаковой частотой останутся в порядке первого появления.

## Шаблон «группировка»

Второй важный шаблон — собрать элементы в группы по признаку. Значения словаря — списки:

```python
words = ["арбуз", "банан", "апельсин", "вишня", "брусника"]
groups = {}
for word in words:
    letter = word[0]
    if letter not in groups:
        groups[letter] = []
    groups[letter].append(word)
print(groups)
```

```text
{'а': ['арбуз', 'апельсин'], 'б': ['банан', 'брусника'], 'в': ['вишня']}
```

То же самое короче — метод `setdefault`: «верни значение по ключу, а если ключа нет — сначала установи значение по умолчанию»:

```python
words = ["арбуз", "банан", "апельсин"]
groups = {}
for word in words:
    groups.setdefault(word[0], []).append(word)
print(groups)
```

```text
{'а': ['арбуз', 'апельсин'], 'б': ['банан']}
```

В части 2 вы узнаете `collections.defaultdict` и `Counter`, которые делают оба шаблона ещё проще.

## Как словарь устроен внутри

Словарь — это **хеш-таблица**. Для каждого ключа Python вычисляет **хеш** — число, полученное из значения ключа функцией `hash()`. По хешу сразу вычисляется место в таблице, где лежит значение. Поэтому:

- поиск, добавление и удаление по ключу работают **мгновенно** — примерно одинаково для словаря из 10 и из 10 миллионов элементов;
- ключи должны быть **неизменяемыми**: если бы ключ поменялся, его хеш изменился бы, и значение «потерялось» бы в таблице. Поэтому список не может быть ключом, а кортеж — может;
- проверка `key in d` мгновенная, в отличие от `x in list`, которая перебирает весь список.

```python
print(hash("кот") == hash("кот"))
print(hash((1, 2)) == hash((1, 2)))
```

```text
True
True
```

(Конкретные числа хешей строк меняются между запусками Python — это защита от некоторых атак, поэтому мы сравниваем их, а не печатаем.)

## Разбор задачи: сообщения для языковой модели

API языковых моделей принимают историю диалога как **список словарей** — у каждого сообщения роль и текст:

```python
messages = [
    {"role": "system", "content": "Ты — вежливый помощник."},
    {"role": "user", "content": "Привет! Что такое словарь?"},
]
reply = {"role": "assistant", "content": "Словарь хранит пары ключ-значение."}
messages.append(reply)
for message in messages:
    print(f"[{message['role']}] {message['content']}")
roles = {}
for message in messages:
    roles[message["role"]] = roles.get(message["role"], 0) + 1
print(roles)
```

```text
[system] Ты — вежливый помощник.
[user] Привет! Что такое словарь?
[assistant] Словарь хранит пары ключ-значение.
{'system': 1, 'user': 1, 'assistant': 1}
```

Обратите внимание на кавычки в f-строке: снаружи двойные, у ключа — одинарные. Именно такую структуру вы будете отправлять в OpenAI и Anthropic API в части 7. Подробнее о вложенных структурах — в уроке 6.

## Частые ошибки

**1. `KeyError` при чтении отсутствующего ключа.** Используйте `get` или проверку `in`, если ключа может не быть.

**2. Список как ключ.** `{[1, 2]: "x"}` → `TypeError: unhashable type: 'list'`. Используйте кортеж.

**3. `in` проверяет ключи, не значения.** Для значений — `x in d.values()` (это медленный перебор).

**4. Изменение размера словаря во время перебора.** `RuntimeError`. Перебирайте `list(d)`.

**5. Ожидать дубликаты ключей.** `{"a": 1, "a": 2}` — это `{"a": 2}`: второе значение перезаписывает первое.

**6. Копия через `=`.** Как и со списками, `b = a` — второе имя того же словаря. Копия — `a.copy()` или `dict(a)`.

## Где это в AI-инженерии

- **Сообщения LLM.** `{"role": "user", "content": "..."}` — формат всех чат-API.
- **Конфигурации.** Гиперпараметры, параметры генерации, настройки сервиса — словари; `defaults | overrides` — стандартное слияние.
- **Словарь токенизатора.** `vocab = {"привет": 1543, ...}` — отображение токенов в номера, а `id2label = {0: "негатив", 1: "позитив"}` — номеров классов в названия.
- **Подсчёт.** Частоты слов, классов, кодов ошибок, токенов — шаблон `counts[k] = counts.get(k, 0) + 1`.
- **Кэш.** Ответы модели на одинаковые запросы хранят в словаре `cache[(model, prompt)] = response`, экономя деньги и время.
- **JSON.** Ответы всех веб-API — это JSON, который в Python превращается в словари (блок 1.7).

## Итоги урока

- Словарь `{ключ: значение}` — мгновенный доступ по ключу; ключи уникальны и неизменяемы.
- `d[k]` — ключ обязан быть; `d.get(k, default)` — может не быть; `k in d` — проверка ключа.
- `d[k] = v` добавляет или заменяет; `del`, `pop`, `update`, `|` — удаление и слияние.
- Перебор: `for k in d`, `d.keys()`, `d.values()`, `for k, v in d.items()`; порядок добавления сохраняется.
- Шаблоны: подсчёт `counts.get(k, 0) + 1`, группировка `setdefault(k, []).append(x)`, сортировка `sorted(d, key=d.get)`.
