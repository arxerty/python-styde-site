# Шпаргалка: циклы

## while

```python norun
count = 1                 # 1. инициализация
while count <= 5:         # 2. условие (проверяется перед каждой итерацией)
    print(count)
    count += 1            # 3. изменение — иначе вечный цикл
# после цикла count == 6
```

- Для неизвестного заранее числа повторений.
- Чтение до стоп-значения: первое чтение до цикла, следующее — в конце тела (или `while True` + `break`).

## for и range

```python norun
for ch in "текст":        # перебор символов
for i in range(5):        # 0 1 2 3 4
for i in range(2, 6):     # 2 3 4 5
for i in range(0, 10, 3)  # 0 3 6 9
for i in range(5, 0, -1)  # 5 4 3 2 1
for _ in range(3):        # повторить 3 раза
```

- `stop` не включается: 1…n — это `range(1, n + 1)`.
- Длина `range(a, b)` = `b − a`; интервалы стыкуются без пересечений.
- Шаг ≠ 0; аргументы только целые.

## break / continue / else

| Инструкция | Действие |
|---|---|
| `break` | выйти из ближайшего цикла |
| `continue` | перейти к следующей итерации |
| `else` у цикла | выполнить, если цикл закончился **без** `break` |

```python norun
for item in items:
    if подходит(item):
        print("нашли")
        break
else:
    print("не нашли")
```

В `while` изменяйте счётчик **до** `continue`.

## Вложенные циклы

- Внутренний выполняется полностью на каждой итерации внешнего: всего n × m.
- Пары без повторов: `for b in range(a + 1, n + 1)`.
- `break` выходит только из внутреннего; для выхода из обоих — флаг или функция с `return`.

## Накопители

| Задача | Начальное значение | Обновление |
|---|---|---|
| Сумма | `0` | `total += x` |
| Произведение | `1` | `product *= x` |
| Счётчик | `0` | `if условие: count += 1` |
| Максимум | первый элемент или `None` | `if best is None or x > best: best = x` |
| argmax | `0` (индекс) | `if data[i] > data[best_i]: best_i = i` |
| Есть ли (any) | `False` | `if условие: found = True; break` |
| Все ли (all) | `True` | `if not условие: ok = False; break` |
| Строка | `""` | `result += часть` |

Среднее: `total / count` — **только если `count > 0`**.

## Алгоритмы

- Процесс: понять → решить руками → псевдокод → код по шагам → граничные случаи → улучшить.
- Цифры числа: `n % 10` — последняя, `n //= 10` — убрать её.
- Евклид: `while b: a, b = b, a % b` → НОД = a.
- Делители — до `int(n ** 0.5)`.
- Если цикл «съедает» переменную — сохраните копию до цикла.

## Частые ошибки

- Нет изменения переменной условия → вечный цикл.
- `range(1, 10)` не включает 10.
- Накопитель инициализирован внутри цикла.
- Максимум начат с 0 при отрицательных данных.
- Потерянная последняя серия/элемент после цикла.
