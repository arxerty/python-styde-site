# Цикл for и range()

## Перебор вместо счётчика

В прошлом уроке мы печатали числа от 1 до 5 через `while`: заводили счётчик, проверяли условие, не забывали увеличивать. Три места, где можно ошибиться. Но задача «сделай что-то для каждого элемента» встречается так часто, что для неё есть специальный цикл — **`for`**:

```python
for number in range(1, 6):
    print("Итерация", number)
print("Готово")
```

```text
Итерация 1
Итерация 2
Итерация 3
Итерация 4
Итерация 5
Готово
```

Ни инициализации, ни условия, ни увеличения — `for` всё делает сам. Забыть шаг и устроить бесконечный цикл здесь невозможно.

## Синтаксис for

```python norun
for переменная in последовательность:
    тело цикла
```

Читается как «для каждой переменной из последовательности выполни тело»:

1. Python берёт **первый** элемент последовательности и привязывает к нему имя переменной.
2. Выполняет тело.
3. Берёт **следующий** элемент, снова привязывает имя, выполняет тело.
4. Когда элементы закончились — выходит из цикла.

В других языках такой цикл называют **foreach** («для каждого»). В Python это основной цикл — `while` используется заметно реже.

## Перебор строки

Строка — последовательность символов, поэтому её можно перебрать:

```python
for letter in "Python":
    print(letter)
```

```text
P
y
t
h
o
n
```

На каждой итерации переменная `letter` указывает на очередной символ. Например, посчитаем пробелы в тексте:

```python
text = "мама мыла раму"
spaces = 0
for char in text:
    if char == " ":
        spaces += 1
print("Пробелов:", spaces)
```

```text
Пробелов: 2
```

Полезный оператор для работы с символами — **`in`**: `символ in строка` проверяет, входит ли символ (или подстрока) в строку. Подробно о нём — в блоке «Строки глубоко», но он пригодится уже сейчас:

```python
vowels = "аеёиоуыэюя"
word = "программирование"
count = 0
for char in word:
    if char in vowels:
        count += 1
print("Гласных:", count)
```

```text
Гласных: 7
```

## Функция range()

Чтобы повторить действие **N раз** или перебрать числа, используют `range()` — она создаёт последовательность целых чисел. У неё три формы:

| Вызов | Числа | Описание |
|---|---|---|
| `range(stop)` | 0, 1, …, stop−1 | от 0 до stop, не включая |
| `range(start, stop)` | start, …, stop−1 | от start до stop, не включая |
| `range(start, stop, step)` | start, start+step, … | с шагом step |

```python
for i in range(4):
    print(i, end=" ")
print()
for i in range(2, 6):
    print(i, end=" ")
print()
for i in range(0, 20, 5):
    print(i, end=" ")
print()
```

```text
0 1 2 3 
2 3 4 5 
0 5 10 15 
```

### Почему stop не включается

Правило «начало включается, конец — нет» (полуоткрытый интервал `[start, stop)`) поначалу кажется странным, но у него есть важные достоинства:

- `range(n)` даёт **ровно n** чисел: `range(5)` — пять чисел 0…4. Удобно, чтобы «повторить n раз».
- Длина `range(a, b)` — просто `b - a`.
- Интервалы стыкуются без пересечений: `range(0, 5)` и `range(5, 10)` вместе дают 0…9 без дублей и пропусков. Это пригодится при разбиении данных на батчи.
- Индексы строк и списков начинаются с 0 и заканчиваются на `длина − 1` — то есть ровно `range(len(x))`.

Если нужно включить конец, прибавьте 1: числа от 1 до 10 включительно — `range(1, 11)`.

### Отрицательный шаг

Для обратного отсчёта шаг делают отрицательным. Тогда `start` должен быть **больше** `stop`:

```python
for i in range(5, 0, -1):
    print(i, end=" ")
print("Старт!")
```

```text
5 4 3 2 1 Старт!
```

Если перепутать порядок — например, `range(0, 5, -1)` — последовательность окажется пустой, и цикл не выполнится ни разу (без ошибки).

### range — не список

`range()` не создаёт в памяти все числа сразу, а **вычисляет их по мере надобности**. Поэтому `range(1_000_000_000)` занимает в памяти столько же, сколько `range(10)`. Чтобы увидеть числа целиком, его можно превратить в список функцией `list()`:

```python
numbers = range(3, 12, 4)
print(numbers)
print(list(numbers))
print(len(numbers))
```

```text
range(3, 12, 4)
[3, 7, 11]
3
```

Такие «ленивые» последовательности — важная идея Python. В части 2 вы научитесь создавать свои (генераторы) и использовать их для обработки датасетов, которые не помещаются в память.

## Повторить N раз

Если номер итерации не нужен, переменную по соглашению называют `_` — «это значение мне не важно»:

```python
for _ in range(3):
    print("Привет!")
```

```text
Привет!
Привет!
Привет!
```

## for и while: что выбрать

Любой `for` можно переписать через `while` и наоборот. Сравните:

```python
for i in range(1, 4):
    print(i)

i = 1
while i < 4:
    print(i)
    i += 1
```

Правило выбора:

- **`for`** — когда перебираете известную последовательность или знаете число повторений: элементы строки, числа диапазона, строки файла, эпохи обучения.
- **`while`** — когда количество итераций зависит от условия, которое определится в процессе: «пока пользователь не ввёл стоп», «пока сумма не удвоилась», «пока ответ API не успешен».

`for` безопаснее (нет риска забыть шаг) и обычно быстрее, поэтому в сомнительных случаях выбирайте его.

## Переменная цикла после цикла

После завершения цикла переменная сохраняет **последнее** значение:

```python
for i in range(5):
    pass
print(i)
```

```text
4
```

Но полагаться на это не стоит: если последовательность пустая, переменная не создастся вовсе, и обращение к ней вызовет `NameError`.

## Изменение переменной внутри for

В отличие от `while`, изменение переменной цикла внутри тела **не влияет** на ход цикла — на следующей итерации она получит следующее значение из последовательности:

```python
for i in range(3):
    print("до:", i)
    i = 100
    print("после:", i)
```

```text
до: 0
после: 100
до: 1
после: 100
до: 2
после: 100
```

`for` каждый раз заново привязывает имя к очередному элементу. Пытаться «перепрыгнуть» итерации, меняя `i`, бесполезно — для этого есть `continue` и `range` с шагом.

## Разбор задачи: таблица умножения и сумма ряда

Таблица умножения на 7:

```python
n = 7
for i in range(1, 11):
    print(n, "x", i, "=", n * i)
```

Сумма чисел от 1 до 100 (знаменитая задача юного Гаусса):

```python
total = 0
for k in range(1, 101):
    total += k
print(total)
```

```text
5050
```

Это **накопитель** — переменная, в которую на каждой итерации что-то добавляется. Накопителям посвящён урок 5 этого блока. Для суммы есть и встроенная функция: `sum(range(1, 101))`, но понимать ручной вариант необходимо — на нём строятся все более сложные алгоритмы.

## Разбор задачи: разбиение данных на батчи

Модель обучают не на всём датасете сразу, а порциями — **батчами**. Пусть у нас 10 примеров и размер батча 4. Нужно получить границы каждого батча: `[0, 4)`, `[4, 8)`, `[8, 10)`.

```python
num_samples = 10
batch_size = 4
for start in range(0, num_samples, batch_size):
    end = min(start + batch_size, num_samples)
    print("Батч: примеры с", start, "по", end - 1, "| размер", end - start)
```

```text
Батч: примеры с 0 по 3 | размер 4
Батч: примеры с 4 по 7 | размер 4
Батч: примеры с 8 по 9 | размер 2
```

Разберём приёмы:

- `range(0, num_samples, batch_size)` даёт начала батчей: 0, 4, 8. Шаг `range` — это и есть размер батча.
- Конец батча — `start + batch_size`, но он не должен выйти за пределы данных. `min(…, num_samples)` обрезает последний батч до 10.
- Благодаря полуоткрытым интервалам `[start, end)` батчи стыкуются без пропусков и повторов: каждый пример попадает ровно в один батч.

Именно так внутри устроены загрузчики данных в ML-библиотеках. В части 2 вы напишете генератор батчей, а в части 6 будете пользоваться `DataLoader` из PyTorch, который делает то же самое (плюс перемешивание и параллельную загрузку).

## Как for работает внутри

`for` в Python использует **протокол итерации**: у последовательности запрашивается **итератор** — объект, который умеет выдавать элементы по одному. Цикл вызывает у итератора «дай следующий», пока тот не сообщит «элементы кончились» (специальным исключением `StopIteration`). Поэтому `for` работает с чем угодно, что умеет выдавать элементы: строками, `range`, списками, словарями, файлами, ответами базы данных, потоками токенов от LLM. Подробно протокол итерации разбирается в части 2 — а пока главное: `for` — универсальный способ «пройтись по чему-то».

## Частые ошибки

**1. Ожидать, что `range(1, 10)` включает 10.** Не включает. Для 1…10 нужно `range(1, 11)`.

**2. Отрицательный шаг с неправильным порядком.** `range(1, 10, -1)` — пусто.

**3. Шаг 0.** `range(0, 10, 0)` → `ValueError: range() arg 3 must not be zero`.

**4. Дробные аргументы.** `range(0, 1, 0.1)` → `TypeError`: range работает только с целыми.

**5. Менять переменную цикла, надеясь повлиять на итерации.** На ход `for` это не влияет.

**6. Забыть двоеточие или отступ** — как в `if` и `while`.

## Где это в AI-инженерии

- **Эпохи обучения.** Самая узнаваемая строка ML-кода: `for epoch in range(num_epochs):`.
- **Батчи.** `for batch in dataloader:` — перебор данных порциями. `DataLoader` в PyTorch — как раз объект, поддерживающий протокол итерации.
- **Индексы батчей.** `for start in range(0, len(data), batch_size):` — разбиение на куски по `batch_size` с помощью шага `range`. Полуоткрытые интервалы стыкуются без дублей.
- **Стриминг токенов.** `for chunk in stream: print(chunk, end="")` — вывод ответа LLM по мере генерации.
- **Перебор гиперпараметров.** `for lr in [0.1, 0.01, 0.001]:` — простейший подбор параметров перебором.
- **Обработка документов.** `for document in documents:` — разбить на куски, получить эмбеддинги, сохранить в векторную базу. Основа RAG-систем из части 7.

## Итоги урока

- `for переменная in последовательность:` перебирает элементы по одному; шаг делать не нужно.
- `range(stop)`, `range(start, stop)`, `range(start, stop, step)` — конец не включается.
- Отрицательный шаг — для обратного отсчёта; `start` должен быть больше `stop`.
- `_` — имя для переменной, значение которой не нужно.
- `for` — для известных последовательностей, `while` — для условий, определяемых в процессе.
