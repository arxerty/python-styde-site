# Шпаргалка: условия и логика

## bool и сравнения

```python norun
True, False                 # только с большой буквы
==  !=  <  >  <=  >=        # результат — bool
0 <= x <= 100               # цепочка сравнений
"abc" < "abd"               # посимвольно по кодам Unicode
"10" < "9"                  # True! строки-числа сравнивать нельзя
True + True                 # 2 — bool это подтип int
```

`=` — присваивание (команда), `==` — сравнение (вопрос).

## if / elif / else

```python norun
if score >= 90:
    grade = "отлично"
elif score >= 75:           # проверяется, только если предыдущие ложны
    grade = "хорошо"
else:                       # без условия
    grade = "ниже"
```

- Двоеточие + отступ 4 пробела; отступ — часть синтаксиса.
- Выполняется **первая** истинная ветка; порядок: от строгого к общему.
- `elif` — взаимоисключающие варианты; отдельные `if` — независимые проверки.
- Переменная, нужная после ветвления, должна получить значение в каждой ветке.
- `pass` — пустой блок.

## and / or / not

| a | b | `a and b` | `a or b` |
|---|---|---|---|
| T | T | T | T |
| T | F | F | T |
| F | T | F | T |
| F | F | F | F |

- Приоритет: сравнения → `not` → `and` → `or`. Смешиваете `and`/`or` — ставьте скобки.
- **Короткое замыкание:** `count != 0 and total / count > 5` — деление не выполнится при 0.
- `x == 1 or 2` — **всегда истинно**! Нужно `x == 1 or x == 2`.
- Де Морган: `not (a and b)` = `not a or not b`.

## Truthy / falsy

Falsy: `False`, `None`, `0`, `0.0`, `""`, пустые коллекции. Остальное — truthy (`"0"`, `"False"`, `" "`, `-1`).

```python norun
if text:                      # непустая строка
if value is not None:         # когда 0 и "" допустимы
name = input() or "Гость"     # умолчание через or (ловушка: 0 → умолчание)
```

## Тернарный оператор

```python norun
status = "взрослый" if age >= 18 else "ребёнок"   # else обязателен
```

## match-case (Python 3.10+)

```python norun
match command:
    case "/help":
        ...
    case "/reset" | "/clear":     # альтернативы через |
        ...
    case ("model", name):         # структура + захват
        ...
    case t if t > 0:              # охранник
        ...
    case _:                       # всё остальное — последним
        ...
```

- Выполняется первый подошедший `case`, без проваливания.
- Голое имя в `case` — **захват**, а не сравнение с переменной.

## Частые ошибки

- Нет `:` после условия; неверные отступы.
- Пороги в неправильном порядке (`>= 60` перед `>= 90`).
- «Дыры» в диапазонах: `< 5` и `> 5` теряют 5.
- `if x = 5:` вместо `==`.
- `if temperature:` при допустимом нуле.
