# Тип bool и операторы сравнения

## Программы, которые принимают решения

Все программы из прошлого блока выполнялись одинаково: строка за строкой, без вариантов. Но почти любая полезная программа **принимает решения**: пустить пользователя или нет, отправить запрос повторно или сдаться, считать отзыв положительным или отрицательным, остановить обучение или продолжить.

В основе любого решения лежит вопрос, на который можно ответить «да» или «нет»: «пароль верный?», «точность выше 90%?», «осталось больше нуля попыток?». Для таких ответов в Python есть специальный тип — **`bool`** (логический, булев — в честь математика Джорджа Буля).

## Тип bool

У типа `bool` ровно два значения: **`True`** (истина) и **`False`** (ложь). Пишутся с большой буквы и без кавычек:

```python
is_trained = True
has_errors = False
print(is_trained, has_errors)
print(type(is_trained))
```

```text
True False
<class 'bool'>
```

`"True"` в кавычках — это строка из четырёх букв, а не логическое значение. А `true` с маленькой буквы Python не узнает: `NameError`.

Логические значения редко пишут руками. Чаще их **получают** — в результате сравнений.

## Операторы сравнения

Оператор сравнения берёт два значения и возвращает `True` или `False`:

| Оператор | Смысл | Пример | Результат |
|---|---|---|---|
| `==` | равно | `5 == 5` | `True` |
| `!=` | не равно | `5 != 3` | `True` |
| `<` | меньше | `2 < 7` | `True` |
| `>` | больше | `2 > 7` | `False` |
| `<=` | меньше или равно | `7 <= 7` | `True` |
| `>=` | больше или равно | `3 >= 9` | `False` |

```python
accuracy = 0.87
threshold = 0.9
print(accuracy > threshold)
print(accuracy < threshold)
print(accuracy == 0.87)
print(accuracy != threshold)
```

```text
False
True
True
True
```

Результат сравнения — обычное значение, его можно сохранить в переменную:

```python
age = 20
is_adult = age >= 18
print(is_adult)
```

```text
True
```

Читается это так: «вычисли `age >= 18` (получится `True`) и привяжи результат к имени `is_adult`». Сравнения выполняются после арифметики (`x + 1 > 10` — сначала сложение), а присваивание `=` — всегда последним.

### == против =

Самая частая ошибка новичков — перепутать **присваивание** `=` и **сравнение** `==`:

- `x = 5` — «привяжи имя x к 5» (команда);
- `x == 5` — «правда ли, что x равно 5?» (вопрос, ответ `True`/`False`).

```python
x = 5
print(x == 5)
print(x == 6)
```

```text
True
False
```

Если написать `print(x = 5)`, Python решит, что вы передаёте в `print` именованный аргумент `x`, и выдаст `TypeError`. В условиях (следующий урок) `if x = 5:` — это `SyntaxError`.

## Сравнение разных типов

### Числа

`int` и `float` сравниваются по значению:

```python
print(10 == 10.0)
print(3 < 3.5)
print(-1 > -2)
```

```text
True
True
True
```

Помните урок про float: из-за погрешностей `0.1 + 0.2 == 0.3` даёт `False`. Для дробных результатов вычислений сравнивайте с допуском.

### Строки

Строки сравниваются **посимвольно** по кодам символов Unicode — это называется лексикографическим порядком (как в словаре):

```python
print("apple" < "banana")
print("apple" < "Apple")
print("кот" < "кит")
print("abc" < "abcd")
print("10" < "9")
```

```text
True
False
False
True
True
```

Разберём сюрпризы:

- `"apple" < "Apple"` — `False`, потому что заглавные буквы в Unicode идут **раньше** строчных (код `A` — 65, код `a` — 97).
- `"кот" < "кит"` — первые буквы равны, сравниваются вторые: `о` после `и` в алфавите, поэтому `"кот"` больше.
- `"abc" < "abcd"` — если одна строка — начало другой, короче та, что меньше.
- `"10" < "9"` — строки сравниваются посимвольно: `"1"` меньше `"9"`, дальше не смотрим. **Числа в виде строк сравнивать нельзя** — сначала `int()`.

### Разные типы

Числа и строки на равенство сравнивать можно (результат всегда `False`), а на больше/меньше — нельзя:

```python
print(5 == "5")
print(5 != "5")
```

```text
False
True
```

`5 < "5"` вызовет `TypeError: '<' not supported between instances of 'int' and 'str'`. Это та же строгая типизация: Python не угадывает, как сравнивать число с текстом.

### Под капотом: коды символов

Чтобы понимать, как сравниваются строки, полезно увидеть сами коды символов. Функция `ord()` возвращает номер символа в Unicode, а `chr()` — символ по номеру:

```python
print(ord("A"), ord("Z"), ord("a"), ord("z"))
print(ord("А"), ord("Я"), ord("а"), ord("я"))
print(ord("0"), ord("9"))
print(chr(65), chr(1071))
```

```text
65 90 97 122
1040 1071 1072 1103
48 57
A Я
```

Видно, что внутри каждого алфавита буквы идут по порядку, заглавные — раньше строчных, а цифры — раньше всех букв. Отсюда все «сюрпризы» сравнения строк. Есть и подвох для русского языка: буква `ё` (код 1105) стоит **после** `я`, поэтому `"ёж" > "яблоко"` даёт `True`. Для корректной сортировки русских слов в реальных проектах используют специальные инструменты локализации.

Сравнение двух строк Python выполняет так:

1. Берёт первые символы обеих строк и сравнивает их коды.
2. Если коды различаются — результат определён, дальше не смотрит.
3. Если совпадают — переходит к следующей паре символов.
4. Если одна строка закончилась раньше — она меньше.

Это ровно тот же алгоритм, по которому слова расставлены в бумажном словаре.

## Сравнения внутри выражений

Сравнения можно комбинировать с арифметикой. Порядок вычисления: сначала арифметика, потом сравнение:

```python
tokens_used = 3500
tokens_new = 900
limit = 4096
print(tokens_used + tokens_new > limit)
print(tokens_used * 2 >= limit * 1.5)
print(len("hello") == 5)
```

```text
True
True
True
```

В первой строке сначала считается `3500 + 900 = 4400`, затем `4400 > 4096`. Скобки не нужны, но для читаемости их иногда ставят: `(tokens_used + tokens_new) > limit`.

Результат сравнения — полноценное значение, поэтому его можно сравнивать с другими bool, складывать, сохранять и передавать в функции. В следующих уроках вы увидите, что главное место сравнений — условия `if`, где от результата зависит, какой код выполнится.

## Цепочки сравнений

В математике пишут `0 ≤ x ≤ 100`. Python позволяет записать так же:

```python
score = 75
print(0 <= score <= 100)
temperature = 1.5
print(0 <= temperature <= 1)
```

```text
True
False
```

Цепочка `a < b < c` означает «`a < b` **и** `b < c`». Это удобная и читаемая запись проверки диапазона. Работают и цепочки с другими операторами: `a == b == c` — все три равны.

## Как bool устроен внутри

Любопытный факт: `bool` — это подтип `int`. `True` ведёт себя как `1`, а `False` — как `0`:

```python
print(True + True)
print(False * 10)
print(True == 1)
print(isinstance(True, int))
```

```text
2
0
True
True
```

Это кажется странным, но на практике очень удобно: сумма логических значений — это **количество** истинных. Например, сколько из трёх проверок прошло:

```python
passed = (5 > 3) + (2 > 8) + (10 == 10)
print(passed)
```

```text
2
```

Тот же приём используют в ML для вычисления точности (accuracy): сравнивают предсказания с правильными ответами и считают, сколько совпало.

## Разбор: считаем точность классификатора

Соединим всё вместе. Модель предсказала метки для пяти отзывов (1 — позитив, 0 — негатив), а у нас есть правильные ответы. Посчитаем accuracy — долю верных предсказаний:

```python
pred_1, true_1 = 1, 1
pred_2, true_2 = 0, 1
pred_3, true_3 = 1, 1
pred_4, true_4 = 0, 0
pred_5, true_5 = 1, 0

correct = (
    (pred_1 == true_1)
    + (pred_2 == true_2)
    + (pred_3 == true_3)
    + (pred_4 == true_4)
    + (pred_5 == true_5)
)
accuracy = correct / 5
print("Верно:", correct, "из 5")
print("Accuracy:", accuracy)
```

```text
Верно: 3 из 5
Accuracy: 0.6
```

Каждое сравнение даёт `True` или `False`, сумма превращает их в количество совпадений, деление — в долю. Выглядит громоздко из-за отдельных переменных — в блоке про коллекции вы будете хранить предсказания в списках и считать то же самое в одну строку. А в NumPy это будет выглядеть как `(preds == labels).mean()`. Но суть операции не изменится: **сравнение + подсчёт истинных**.

## Функция bool()

Любое значение можно превратить в логическое функцией `bool()`. Правила подробно разберём в уроке про truthy/falsy, а пока главное:

```python
print(bool(0))
print(bool(42))
print(bool(""))
print(bool("текст"))
```

```text
False
True
False
True
```

Ноль и пустая строка — «ложные», всё остальное — «истинное».

## Разбор задачи: проверка ответа модели

Представим, что мы оцениваем ответы языковой модели на тестовые вопросы. Есть правильный ответ и ответ модели; надо проверить совпадение без учёта регистра и посчитать оценку.

```python
expected = "Париж"
answer = "париж"
exact_match = answer == expected
print("Точное совпадение:", exact_match)

answer_length_ok = 1 <= len(answer) <= 50
print("Длина в норме:", answer_length_ok)

score = exact_match + answer_length_ok
print("Баллов:", score)
```

```text
Точное совпадение: False
Длина в норме: True
Баллов: 1
```

Точное совпадение не сработало из-за регистра. В блоке «Строки глубоко» вы узнаете метод `lower()`, который приводит текст к нижнему регистру: `answer.lower() == expected.lower()`. Именно так устроена простейшая метрика **exact match** в оценке LLM.

## Частые ошибки

**1. `=` вместо `==`.** Присваивание — команда, сравнение — вопрос.

**2. Сравнивать числа в строках.** `"10" < "9"` даёт `True`. Преобразуйте ввод: `int(input())`.

**3. Писать `true`/`false`.** Только `True` и `False` с большой буквы.

**4. Сравнивать float через `==`.** Используйте допуск: `abs(a - b) < 1e-9`.

**5. Забывать о регистре в строках.** `"Да" == "да"` — `False`.

**6. Путать `!=` с `=!` или `<>`.** В Python «не равно» пишется только как `!=`.

## Где это в AI-инженерии

- **Пороги классификации.** Модель выдаёт вероятность, например 0.73, а решение принимается сравнением: `is_spam = probability >= 0.5`. Выбор порога — важная тема в блоке про метрики.
- **Accuracy через сумму bool.** Точность = доля совпавших предсказаний. Каждое сравнение `prediction == label` даёт `True`/`False`, а их сумма — число правильных ответов. В NumPy и PyTorch это пишется одной строкой: `(preds == labels).mean()`.
- **Ранняя остановка обучения.** `if val_loss < best_loss:` — сравнение, на котором держится логика сохранения лучшей модели.
- **Эвалы LLM.** Простейшая метрика exact match — это сравнение строк `==` после нормализации.
- **Проверки лимитов.** `len(prompt) <= max_length`, `tokens_used < budget` — сравнения охраняют от превышения контекстного окна и бюджета на API.

## Итоги урока

- `bool` — тип с двумя значениями: `True` и `False`.
- Сравнения `== != < > <= >=` возвращают `bool`; `==` — вопрос, `=` — присваивание.
- Строки сравниваются посимвольно по кодам Unicode; заглавные раньше строчных; строки-числа сравниваются неправильно.
- `0 <= x <= 100` — цепочка сравнений.
- `True` ведёт себя как 1, `False` — как 0; сумма bool — число истинных.
