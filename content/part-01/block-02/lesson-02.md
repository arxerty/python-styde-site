# if / else и отступы

## Ветвление

В прошлом уроке мы научились получать ответы «да/нет» в виде `True` и `False`. Теперь используем их, чтобы программа выбирала, **что делать дальше**. Это называется **ветвлением**: в зависимости от условия выполняется одна или другая ветка кода.

Жизненный пример: «если идёт дождь — возьми зонт, иначе — надень очки». В Python:

```python
is_raining = True
if is_raining:
    print("Беру зонт")
else:
    print("Надеваю очки")
print("Выхожу из дома")
```

```text
Беру зонт
Выхожу из дома
```

Поменяйте `True` на `False` и запустите снова: выполнится другая ветка, а последняя строка — в любом случае.

## Синтаксис if

```python norun
if условие:
    действие 1
    действие 2
следующая инструкция
```

Разберём каждую деталь:

1. Ключевое слово **`if`** («если»).
2. **Условие** — любое выражение, которое Python может оценить как истину или ложь. Чаще всего это сравнение: `age >= 18`, `password == "secret"`.
3. **Двоеточие** `:` в конце строки. Оно говорит: «дальше идёт блок кода».
4. **Тело** — одна или несколько строк с **отступом**. Они выполняются, только если условие истинно.
5. Строка **без отступа** после тела — уже не часть `if`. Она выполнится в любом случае.

```python
temperature = 39.0
if temperature > 37.5:
    print("Повышенная температура")
    print("Рекомендуется обратиться к врачу")
print("Измерение завершено")
```

```text
Повышенная температура
Рекомендуется обратиться к врачу
Измерение завершено
```

При `temperature = 36.6` обе строки внутри `if` пропустятся, и останется только `Измерение завершено`.

## Отступы — это синтаксис

В большинстве языков блоки кода выделяют фигурными скобками `{ }`, а отступы ставят «для красоты». В Python **отступы — часть синтаксиса**: именно они показывают, какие строки входят в блок.

Правила:

- стандартный отступ — **4 пробела** (PEP 8); редакторы ставят их по клавише Tab;
- все строки одного блока должны иметь **одинаковый** отступ;
- блок заканчивается, когда отступ возвращается на прежний уровень;
- нельзя смешивать табуляцию и пробелы.

Сравните две программы — они отличаются только отступом последней строки:

```python
balance = 100
if balance < 0:
    print("Баланс отрицательный")
    print("Пополните счёт")
```

Эта программа ничего не выведет. А вот вторая:

```python
balance = 100
if balance < 0:
    print("Баланс отрицательный")
print("Пополните счёт")
```

```text
Пополните счёт
```

В первой программе `Пополните счёт` — часть блока `if` и не выполняется. Во второй — это отдельная инструкция после `if`, и она выполняется всегда. Один отступ — и смысл программы другой.

### Ошибки отступов

Python строго следит за отступами и сообщает о нарушениях:

```python
x = 5
if x > 0:
print("положительное")
```

Здесь у тела нет отступа → `IndentationError: expected an indented block after 'if' statement`.

```python
x = 5
if x > 0:
    print("положительное")
      print("и большое")
```

Здесь отступы в блоке разные → `IndentationError: unexpected indent`.

> Почему Гвидо ван Россум сделал отступы обязательными? Программисты и так выравнивают код отступами для читаемости. Python лишь требует, чтобы отступы **не врали**: то, что выглядит вложенным, действительно вложено. В языках со скобками бывают коварные ошибки, когда отступы показывают одно, а скобки — другое.

## else — иначе

`else` («иначе») задаёт ветку, которая выполняется, когда условие **ложно**:

```python
age = 16
if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

```text
Доступ запрещён
```

Особенности `else`:

- после `else` **нет условия** — оно не нужно: это «во всех остальных случаях»;
- после `else` тоже ставится двоеточие;
- `else` пишется на том же уровне отступа, что и его `if`;
- из двух веток выполняется **ровно одна** — никогда обе и никогда ни одной.

Схематично:

```text
            ┌── условие истинно ──► ветка if ──┐
начало ──► if                                  ├──► продолжение программы
            └── условие ложно ────► ветка else ┘
```

## Пример: чётное или нечётное

```python
number = 17
if number % 2 == 0:
    print(number, "— чётное")
else:
    print(number, "— нечётное")
```

```text
17 — нечётное
```

Условие здесь — сравнение остатка с нулём. Сначала вычисляется `number % 2` (получается 1), затем `1 == 0` (False), и выполняется ветка `else`.

## Внутри блока — любой код

Тело `if` и `else` — обычный код: присваивания, вычисления, ввод, вывод. Часто в ветках меняют переменные, а печатают результат после:

```python
total = 6200
if total >= 5000:
    discount = total * 0.1
else:
    discount = 0
final = total - discount
print("Скидка:", discount)
print("К оплате:", final)
```

```text
Скидка: 620.0
К оплате: 5580.0
```

Обратите внимание: переменная `discount` создаётся в обеих ветках. Это важно — если бы в ветке `else` её не было, при `total < 5000` строка `final = total - discount` упала бы с `NameError`. **Переменная, которую используют после ветвления, должна получить значение в каждой ветке** (или до `if`).

Альтернативный приём — задать значение по умолчанию заранее и менять его только при необходимости:

```python
total = 3000
discount = 0
if total >= 5000:
    discount = total * 0.1
print("Скидка:", discount)
```

```text
Скидка: 0
```

## Трассировка ветвления

Потренируем трассировку на программе с вводом. Пусть пользователь вводит `7`:

```python
n = int(input("Число: "))
if n > 5:
    n = n * 2
    print("Удвоили")
else:
    n = n + 100
print("Результат:", n)
```

| Шаг | Строка | Что происходит | `n` |
|---|---|---|---|
| 1 | `n = int(input(...))` | читаем 7 | 7 |
| 2 | `if n > 5:` | 7 > 5 → `True`, идём в тело if | 7 |
| 3 | `n = n * 2` | удваиваем | 14 |
| 4 | `print("Удвоили")` | вывод | 14 |
| 5 | `else:` | пропускаем — ветка if уже выполнена | 14 |
| 6 | `print("Результат:", n)` | вывод `Результат: 14` | 14 |

Для ввода `3` путь другой: шаг 2 даёт `False`, тело `if` пропускается целиком, выполняется `n = n + 100`, и выводится `Результат: 103`. Трассировка по веткам — лучший способ проверить программу «в голове» для каждого типа входных данных.

## Стиль: как писать условия читаемо

**Не сравнивайте bool с True.** Если переменная уже логическая, сравнение лишнее:

```python
is_ready = True
if is_ready:          # хорошо
    print("Запускаем")
if is_ready == True:  # работает, но избыточно
    print("Запускаем")
```

```text
Запускаем
Запускаем
```

**Называйте логические переменные вопросами:** `is_valid`, `has_access`, `can_retry`, `should_stop`. Тогда условие читается как фраза: `if can_retry:` — «если можно повторить».

**Выносите сложные условия в переменные.** Вместо длинного выражения прямо в `if` дайте ему имя:

```python
balance = 1200
price = 999
has_enough_money = balance >= price
if has_enough_money:
    print("Покупка возможна")
```

```text
Покупка возможна
```

Имя `has_enough_money` объясняет смысл условия лучше любого комментария.

**Пустые строки.** Отделяйте пустой строкой логические части программы: ввод, ветвление, вывод. Внутри коротких блоков пустые строки не нужны.

## pass — пустой блок

Иногда тело блока ещё не написано, а синтаксис требует хотя бы одну строку. Для этого есть `pass` — инструкция «ничего не делать»:

```python
score = 50
if score > 90:
    pass  # TODO: наградить лучших
else:
    print("Продолжаем тренироваться")
```

```text
Продолжаем тренироваться
```

## Шаблон: защита от плохих данных

Вспомните урок про числа: деление на ноль вызывает `ZeroDivisionError`. С помощью `if/else` такую ситуацию можно обработать заранее — проверить данные до опасной операции:

```python
total_cost = 1500
people = 0
if people > 0:
    print("С каждого:", total_cost / people)
else:
    print("Некому платить: количество человек должно быть больше нуля")
```

```text
Некому платить: количество человек должно быть больше нуля
```

Этот приём называют **защитной проверкой** (guard): прежде чем делать что-то рискованное, убедитесь, что данные подходят. В AI-коде так проверяют, что датасет не пуст перед вычислением среднего, что API-ключ задан перед запросом, что текст не длиннее лимита модели перед отправкой. Альтернативный подход — «сначала попробовать, а при ошибке обработать её» через `try/except` — вы изучите в блоке 1.7. Оба подхода нужны, и опытный разработчик выбирает между ними по ситуации.

## Разбор задачи: проверка ответа и повтор

Реалистичный сценарий из работы с API: если ответ пришёл с ошибкой, нужно сообщить об этом и решить, повторять ли запрос.

```python
status_code = 429
attempts_left = 2

if status_code == 200:
    print("Успех: обрабатываем ответ")
else:
    print("Ошибка API, код", status_code)
    attempts_left -= 1
    print("Осталось попыток:", attempts_left)
```

```text
Ошибка API, код 429
Осталось попыток: 1
```

Код 200 означает успех, 429 — «слишком много запросов» (rate limit). В части 7 вы напишете полноценную логику повторных попыток с паузами — а её фундамент именно такой `if/else`.

## Частые ошибки

**1. Забыть двоеточие.** `if x > 0` без `:` → `SyntaxError: expected ':'`.

**2. Неверный отступ.** Тело без отступа, разные отступы в одном блоке, смешение табов и пробелов → `IndentationError`/`TabError`.

**3. `=` вместо `==` в условии.** `if x = 5:` → `SyntaxError`. Нужно `if x == 5:`.

**4. Условие после else.** `else x < 0:` — ошибка. Если нужно ещё одно условие — `elif` (следующий урок).

**5. Переменная создаётся только в одной ветке.** Потом `NameError` в той ветке, где её нет. Задавайте значение по умолчанию до `if`.

**6. Лишняя строка в блоке или вне его.** Отступ определяет логику: проверяйте, какие строки должны выполняться всегда.

**7. Сравнивать строку из input() с числом.** `if input() == 5:` всегда ложно: строка `"5"` не равна числу `5`.

## Где это в AI-инженерии

- **Классификация по порогу.** `if probability >= 0.5: label = "спам" else: label = "не спам"` — так вероятность модели превращается в решение.
- **Ранняя остановка.** `if val_loss < best_loss: сохранить модель else: увеличить счётчик терпения` — ядро механизма early stopping.
- **Обработка ответов API.** `if response.status_code == 200: ... else: ...` — каждый вызов LLM проверяется на успех.
- **Выбор устройства.** `if torch.cuda.is_available(): device = "cuda" else: device = "cpu"` — стандартная строка в начале любого скрипта на PyTorch.
- **Отступы повсюду.** В ML-коде вложенность бывает глубокой: цикл по эпохам → цикл по батчам → условие логирования. Аккуратные отступы — вопрос не стиля, а правильности.

## Итоги урока

- `if условие:` + блок с отступом — выполнить, если условие истинно.
- `else:` — ветка «во всех остальных случаях»; выполняется ровно одна из двух веток.
- Отступы (4 пробела) — часть синтаксиса: они определяют, какие строки входят в блок.
- Переменные, используемые после ветвления, должны получить значение в каждой ветке.
- `pass` — пустая инструкция-заглушка.
