# Truthy/falsy значения и тернарный оператор

## Любое значение может быть условием

До сих пор в условиях `if` стояли сравнения, которые дают `True` или `False`. Но Python позволяет поставить в условие **любое** значение — число, строку, `None` и (в будущем) список или словарь. Python сам решит, считать его «истинным» или «ложным».

```python
name = "Ада"
if name:
    print("Имя указано")

count = 0
if count:
    print("Есть элементы")
else:
    print("Пусто")
```

```text
Имя указано
Пусто
```

Значения, которые в условии ведут себя как `True`, называют **truthy** («истинноподобными»), а как `False` — **falsy** («ложноподобными»). Это не официальные типы, а жаргон, принятый в сообществе Python и JavaScript.

## Какие значения falsy

Список falsy-значений короткий, и его стоит выучить наизусть:

| Значение | Тип | Смысл |
|---|---|---|
| `False` | bool | ложь |
| `None` | NoneType | «ничего» |
| `0` | int | ноль |
| `0.0` | float | ноль |
| `""` | str | пустая строка |
| `[]`, `()`, `{}`, `set()` | коллекции | пустой список, кортеж, словарь, множество |

**Всё остальное — truthy.** Любое ненулевое число (включая отрицательные), любая непустая строка (даже `" "`, `"0"` и `"False"`), любая непустая коллекция.

Общее правило легко запомнить: **«ноль», «пусто» и «ничего» — ложь, остальное — истина.**

Проверить, как Python оценит значение, можно функцией `bool()`:

```python
print(bool(0), bool(-1), bool(0.0001))
print(bool(""), bool(" "), bool("0"), bool("False"))
print(bool(None))
```

```text
False True True
False True True True
False
```

Именно `bool()` Python неявно вызывает, когда встречает значение в условии `if`, `while`, а также в операторах `and`, `or`, `not`.

### Как это работает внутри

Когда Python встречает значение в условии, он вызывает для него `bool()`. А `bool()` спрашивает у самого объекта, считает ли тот себя истинным. Для этого у объектов есть «магические» методы (подробно — в части 2, где вы будете писать свои классы):

1. Если у объекта есть метод `__bool__`, Python вызывает его — он должен вернуть `True` или `False`. Так устроены числа: ноль отвечает «ложь».
2. Если `__bool__` нет, но есть `__len__` (длина), Python проверяет, не равна ли длина нулю. Так устроены строки и коллекции: пустая — ложь.
3. Если нет ни того, ни другого — объект считается истинным.

```python
print(bool(""), len(""))
print(bool("ab"), len("ab"))
```

```text
False 0
True 2
```

Это объясняет, почему правило «пусто — значит ложь» работает одинаково для строк, списков, словарей и даже для объектов из библиотек. Например, в pandas у таблицы (DataFrame) Python не может однозначно решить, «пустая» она или нет, когда в ней есть данные, и выдаёт ошибку `The truth value of a DataFrame is ambiguous` — вы встретите её в части 4 и будете знать, откуда она берётся: авторы pandas специально запретили неоднозначное преобразование в `bool`.

## Идиоматичные проверки

Truthy/falsy позволяет писать короткие и выразительные условия. Сравните:

```python
text = ""
if text != "":
    print("Есть текст")
if len(text) > 0:
    print("Есть текст")
if text:
    print("Есть текст")
if not text:
    print("Текст пустой")
```

```text
Текст пустой
```

Первые три проверки делают одно и то же, но третья — **идиоматичная** для Python (PEP 8 рекомендует именно её для строк и коллекций). `if not text:` читается как «если текста нет».

## Ловушка: ноль — тоже значение

Короткие проверки удобны, но опасны, когда **ноль или пустая строка — допустимые данные**. Пример: пользователь задаёт температуру генерации LLM, и `0` — вполне корректное значение (детерминированные ответы).

```python
temperature = 0
if temperature:
    print("Температура задана:", temperature)
else:
    print("Температура не задана, используем 0.7")
```

```text
Температура не задана, используем 0.7
```

Это **ошибка**: пользователь явно указал 0, а программа решила, что значения нет. Правильный способ различать «нет значения» и «значение ноль» — использовать `None` как маркер отсутствия и проверять именно его:

```python
temperature = 0
if temperature is not None:
    print("Температура задана:", temperature)
else:
    print("Температура не задана, используем 0.7")
```

```text
Температура задана: 0
```

### is и None

Для проверки на `None` используют оператор **`is`** (а не `==`):

- `x is None` — «x — это None»;
- `x is not None` — «x — не None».

`is` проверяет, что это **тот же самый объект**, а `None` в Python существует в единственном экземпляре. Это рекомендация PEP 8, и так поступают все линтеры. Для чисел и строк `is` не используйте — сравнивайте значения через `==`.

Правило выбора:

- нужно проверить «есть ли хоть что-то» (непустая строка, ненулевое число) → `if x:`;
- нужно отличить «нет значения» от «ноль/пусто» → `if x is not None:`.

## or и and со значениями

В прошлом уроке вы видели, что `or` и `and` возвращают один из операндов. Теперь понятно, как именно:

- `a or b` возвращает `a`, если `a` truthy, иначе `b`;
- `a and b` возвращает `a`, если `a` falsy, иначе `b`.

Отсюда популярный приём — **значение по умолчанию через `or`**:

```python
user_name = ""
display_name = user_name or "Гость"
print("Привет,", display_name)
```

```text
Привет, Гость
```

Если `user_name` пустая, `or` вернёт `"Гость"`. С вводом это выглядит так:

```python
name = input("Ваше имя (Enter — пропустить): ") or "Гость"
print("Привет,", name)
```

Цепочки `or` возвращают **первое** truthy-значение:

```python
cli_model = ""
env_model = ""
default_model = "small-model"
model = cli_model or env_model or default_model
print(model)
```

```text
small-model
```

Так в реальных программах выбирают настройку: аргумент командной строки, иначе переменная окружения, иначе значение по умолчанию.

> Помните о ловушке с нулём: `retries = user_retries or 3` превратит явный `0` в `3`. Если ноль допустим, используйте условие с `is None`.

## Тернарный оператор

Часто `if/else` нужен лишь для того, чтобы выбрать одно из двух значений:

```python
age = 20
if age >= 18:
    status = "взрослый"
else:
    status = "ребёнок"
print(status)
```

```text
взрослый
```

Для таких случаев есть компактная запись — **условное выражение** (его называют тернарным оператором):

```python
age = 20
status = "взрослый" if age >= 18 else "ребёнок"
print(status)
```

```text
взрослый
```

Синтаксис: `значение_если_истина if условие else значение_если_ложь`. Читается почти как английская фраза: «взрослый, если возраст ≥ 18, иначе ребёнок».

Важные отличия от обычного `if`:

- это **выражение** — оно возвращает значение, его можно присвоить, передать в функцию, вставить в `print()`;
- `else` **обязателен** — выражение всегда должно что-то вернуть;
- в ветках — только выражения, а не инструкции (нельзя написать присваивание внутри).

```python
n = 7
print(n, "— чётное" if n % 2 == 0 else "— нечётное")
items = 1
print("Найден", items, "файл" if items == 1 else "файлов")
```

```text
7 — нечётное
Найден 1 файл
```

### Когда тернарный оператор уместен

- выбор одного из двух **простых** значений;
- короткие выражения, помещающиеся в строку.

Когда **не** стоит:

- в ветках длинные выражения или побочные эффекты;
- больше двух вариантов. Тернарные операторы можно вкладывать — `"плюс" if x > 0 else "минус" if x < 0 else "ноль"`, — но читать это тяжело. Для трёх и более вариантов используйте `if/elif/else`.

## Разбор задачи: параметры генерации с умолчаниями

Соберём всё на реалистичном примере. Программа получает от пользователя параметры генерации текста; пустой ввод означает «использовать значение по умолчанию», а ноль — допустимое значение.

```python
temperature_text = ""
max_tokens_text = "0"

temperature = float(temperature_text) if temperature_text else 0.7
max_tokens = int(max_tokens_text) if max_tokens_text else 256

print("temperature:", temperature)
print("max_tokens:", max_tokens)
mode = "детерминированный" if temperature == 0 else "творческий"
print("Режим:", mode)
```

```text
temperature: 0.7
max_tokens: 0
Режим: творческий
```

Обратите внимание: проверяем **строку** до преобразования. Строка `"0"` — truthy (она непустая), поэтому ноль сохраняется. А если бы мы сначала превратили ввод в число и потом проверили `if max_tokens:`, ноль потерялся бы. Порядок «сначала проверка строки на пустоту, потом преобразование» решает проблему.

## Частые ошибки

**1. Ноль считается «отсутствием значения».** `if price:` ложно при `price = 0`, хотя цена 0 может быть корректной (бесплатный товар). Используйте `is not None`.

**2. Строки `"0"` и `"False"` truthy.** `bool("False")` — `True`. Ввод нужно преобразовывать, а не проверять как есть.

**3. `== None` вместо `is None`.** Работает, но не по стандарту — линтеры будут ругаться.

**4. `x or default` с допустимыми falsy-значениями.** `retries = config_retries or 3` превращает явный 0 в 3.

**5. Тернарный оператор без `else`.** `x = "да" if cond` → `SyntaxError`.

**6. Вложенные тернарные операторы.** Технически работают, но превращают код в головоломку.

## Где это в AI-инженерии

- **Пустые ответы модели.** LLM иногда возвращает пустую строку (сработал фильтр, закончились токены). `if not response_text:` — первая проверка перед обработкой ответа.
- **Пустые результаты поиска.** В RAG-системе: `if not documents: return "Не нашёл информации"` — нельзя отправлять модели пустой контекст, иначе она начнёт выдумывать.
- **Конфигурация с умолчаниями.** `model = os.getenv("MODEL_NAME") or "default-model"` — классика настройки сервисов. И та же ловушка: для числовых параметров, где 0 допустим, нужна проверка на `None`.
- **Выбор устройства.** `device = "cuda" if torch.cuda.is_available() else "cpu"` — строка, которая есть почти в каждом скрипте на PyTorch.
- **temperature = 0.** Ровно тот случай из урока: ноль — осмысленное значение параметра генерации (максимально детерминированные ответы), и путать его с «не задано» нельзя.
- **Опциональные поля.** В Pydantic-моделях (часть 2) поля со значением `None` по умолчанию означают «не передано», и проверка `is None` — стандартный способ это обработать.

## Итоги урока

- В условии любое значение приводится к `bool`: falsy — `False`, `None`, `0`, `0.0`, `""` и пустые коллекции, остальное truthy.
- `if text:` — идиоматичная проверка на непустоту; `if x is not None:` — когда ноль или пустота допустимы.
- `a or b` возвращает первое truthy-значение — удобный способ задать умолчание.
- `x if условие else y` — тернарный оператор для выбора из двух значений; `else` обязателен.
