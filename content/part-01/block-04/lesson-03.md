# f-строки и форматирование чисел

## Проблема: собирать текст из кусков неудобно

Сравните три способа вывести одно и то же сообщение:

```python
name = "Ада"
score = 0.87654
epoch = 3
print("Пользователь " + name + ", эпоха " + str(epoch) + ", точность " + str(round(score * 100, 1)) + "%")
print("Пользователь", name + ", эпоха", epoch, ", точность", round(score * 100, 1), "%")
print(f"Пользователь {name}, эпоха {epoch}, точность {score:.1%}")
```

```text
Пользователь Ада, эпоха 3, точность 87.7%
Пользователь Ада, эпоха 3 , точность 87.7 %
Пользователь Ада, эпоха 3, точность 87.7%
```

Первый вариант — лес из плюсов и `str()`. Второй вставляет лишние пробелы, которыми трудно управлять. Третий — **f-строка** — читается как готовый текст, а форматирование числа записано прямо по месту. С f-строками вы будете писать почти весь вывод в своих программах.

## Синтаксис f-строк

f-строка — это строка с префиксом `f` перед кавычкой. Внутри фигурных скобок `{}` можно писать **любое выражение** Python: его значение вычисляется и подставляется в текст.

```python
name = "Гвидо"
year = 1991
print(f"{name} создал Python в {year} году")
print(f"Это было {2026 - year} лет назад")
print(f"Имя заглавными: {name.upper()}, длина: {len(name)}")
```

```text
Гвидо создал Python в 1991 году
Это было 35 лет назад
Имя заглавными: ГВИДО, длина: 5
```

Внутри скобок работают арифметика, вызовы функций и методов, обращения по индексу, тернарный оператор:

```python
count = 1
print(f"Найден {count} {'файл' if count == 1 else 'файлов'}")
word = "Python"
print(f"Первая буква: {word[0]}, последние три: {word[-3:]}")
```

```text
Найден 1 файл
Первая буква: P, последние три: hon
```

Обратите внимание на кавычки: снаружи двойные, внутри — одинарные. В Python 3.12 можно использовать и одинаковые кавычки, но в более старых версиях это ошибка, поэтому привычка чередовать кавычки полезна.

### Фигурные скобки как текст

Если в тексте нужны сами фигурные скобки (например, JSON в промпте), их **удваивают**:

```python
label = "positive"
print(f"Ответ в формате JSON: {{\"label\": \"{label}\"}}")
```

```text
Ответ в формате JSON: {"label": "positive"}
```

`{{` и `}}` превращаются в одиночные скобки, а `{label}` — в значение переменной. Это частый источник ошибок при сборке промптов, где пример JSON-ответа вставлен в f-строку.

### Отладочный режим: знак =

Если после выражения поставить `=`, f-строка выведет и само выражение, и его значение. Очень удобно для отладки:

```python
learning_rate = 3e-4
batch_size = 32
print(f"{learning_rate=}, {batch_size=}")
print(f"{batch_size * 4=}")
```

```text
learning_rate=0.0003, batch_size=32
batch_size * 4=128
```

## Спецификация формата

После выражения через двоеточие можно указать **спецификацию формата**: `{значение:спецификация}`. Она управляет тем, как число или строка будет выглядеть.

### Знаки после запятой: .Nf

```python
pi = 3.14159265
print(f"{pi:.2f}")
print(f"{pi:.4f}")
print(f"{pi:.0f}")
print(f"{2.5:.0f}")
print(f"{10:.2f}")
```

```text
3.14
3.1416
3
2
10.00
```

`.2f` — «фиксированная точка, 2 знака после запятой». В отличие от `round()`, формат **всегда** показывает ровно столько знаков, добавляя нули: `10` превращается в `10.00`. Для денег и метрик это обычно то, что нужно. Округление, как и у `round()`, банковское (`2.5` → `2`).

> **round или формат?** `round(x, 2)` меняет **значение** (получается новое число), а `f"{x:.2f}"` меняет только **отображение** (получается строка). Для расчётов — `round` или вообще не округлять; для вывода — формат.

### Разделители тысяч

```python
population = 8100000000
print(f"{population:,}")
print(f"{population:_}")
print(f"{1234567.891:,.2f}")
```

```text
8,100,000,000
8_100_000_000
1,234,567.89
```

### Проценты

Формат `%` умножает число на 100 и добавляет знак процента:

```python
accuracy = 0.87654
print(f"{accuracy:%}")
print(f"{accuracy:.1%}")
print(f"{0.5:.0%}")
```

```text
87.654000%
87.7%
50%
```

Метрики в ML хранят как доли (0.877), а показывают как проценты — формат `.1%` делает это без ручного умножения.

### Научная нотация

```python
lr = 0.0003
big = 175000000000
print(f"{lr:e}")
print(f"{lr:.1e}")
print(f"{big:.2e}")
```

```text
3.000000e-04
3.0e-04
1.75e+11
```

### Знак числа

```python
delta = 0.05
print(f"{delta:+.2f}")
print(f"{-delta:+.2f}")
```

```text
+0.05
-0.05
```

`+` заставляет показывать знак и у положительных чисел — удобно для изменений: «loss изменился на −0.03», «точность +2.1%».

## Ширина и выравнивание

Число после двоеточия задаёт **минимальную ширину** поля. Символы `<`, `>`, `^` — выравнивание влево, вправо, по центру:

```python
word = "AI"
print(f"[{word:10}]")
print(f"[{word:<10}]")
print(f"[{word:>10}]")
print(f"[{word:^10}]")
print(f"[{42:5}]")
```

```text
[AI        ]
[AI        ]
[        AI]
[    AI    ]
[   42]
```

По умолчанию строки выравниваются влево, числа — вправо. Перед символом выравнивания можно указать **заполнитель**:

```python
print(f"{'Отчёт':=^30}")
print(f"{7:03d}")
print(f"{42:*>8}")
```

```text
============Отчёт=============
007
******42
```

`03d` — «целое число шириной 3, дополненное нулями слева». Так форматируют номера файлов (`img_007.png`) и время (`09:05`).

### Таблицы

Ширина + выравнивание + формат числа позволяют выводить ровные таблицы:

```python
print(f"{'Модель':<12}{'Accuracy':>10}{'Время, с':>10}")
print(f"{'small':<12}{0.8123:>10.3f}{1.5:>10.1f}")
print(f"{'medium':<12}{0.8791:>10.3f}{12.25:>10.1f}")
print(f"{'large':<12}{0.9102:>10.3f}{97.0:>10.1f}")
```

```text
Модель        Accuracy  Время, с
small            0.812       1.5
medium           0.879      12.2
large            0.910      97.0
```

Спецификация `>10.3f` объединяет всё: ширина 10, выравнивание вправо, 3 знака после запятой. Порядок частей фиксирован: `[заполнитель][выравнивание][знак][0][ширина][,][.точность][тип]`.

### Ширина из переменной

Ширину можно задать выражением во вложенных скобках:

```python
width = 8
print(f"[{'x':>{width}}]")
```

```text
[       x]
```

## Многострочные f-строки

f-строку можно сделать многострочной с тройными кавычками — так собирают шаблоны промптов:

```python
role = "аналитик данных"
task = "найди аномалии в продажах"
prompt = f"""Ты — {role}.
Задача: {task}.
Ответь списком из 3 пунктов."""
print(prompt)
```

```text
Ты — аналитик данных.
Задача: найди аномалии в продажах.
Ответь списком из 3 пунктов.
```

## Другие способы форматирования

В старом коде вы встретите ещё два способа. Их полезно узнавать, но в новом коде используйте f-строки.

```python
name = "Ада"
score = 0.9
print("Имя: {}, балл: {:.2f}".format(name, score))
print("Имя: %s, балл: %.2f" % (name, score))
```

```text
Имя: Ада, балл: 0.90
Имя: Ада, балл: 0.90
```

Метод `.format()` использует ту же спецификацию формата, что и f-строки, но значения передаются отдельно. Он полезен, когда шаблон хранится отдельно от данных — например, шаблон промпта в файле: `template.format(question=user_question)`. Оператор `%` — наследие языка C, встречается в старом коде и в модуле `logging`.

## Разбор задачи: лог обучения

Типичный вывод во время обучения модели:

```python
loss_values = [0.9123, 0.7456, 0.6311, 0.6402]
accuracy_values = [0.61, 0.72, 0.785, 0.781]
previous = None
for epoch in range(len(loss_values)):
    loss = loss_values[epoch]
    acc = accuracy_values[epoch]
    change = "" if previous is None else f" ({loss - previous:+.4f})"
    print(f"Эпоха {epoch + 1:>2}/{len(loss_values)} | loss {loss:.4f}{change} | acc {acc:.1%}")
    previous = loss
```

```text
Эпоха  1/4 | loss 0.9123 | acc 61.0%
Эпоха  2/4 | loss 0.7456 (-0.1667) | acc 72.0%
Эпоха  3/4 | loss 0.6311 (-0.1145) | acc 78.5%
Эпоха  4/4 | loss 0.6402 (+0.0091) | acc 78.1%
```

Каждый элемент формата работает на читаемость: `>2` выравнивает номер эпохи, `.4f` даёт одинаковое число знаков у loss (столбцы ровные), `+.4f` показывает направление изменения, `.1%` превращает долю в проценты. По такому логу сразу видно: на 4-й эпохе loss вырос — возможно, начинается переобучение.

## Частые ошибки

**1. Забыть префикс `f`.** `"Привет, {name}"` выведет фигурные скобки как есть.

**2. Одинаковые кавычки внутри и снаружи** (до Python 3.12): `f"{d["key"]}"` — `SyntaxError`. Чередуйте: `f"{d['key']}"`.

**3. Одиночные фигурные скобки в тексте.** Для JSON внутри f-строки скобки нужно удваивать: `{{` и `}}`.

**4. Путать `round()` и формат.** Формат возвращает строку — с ней нельзя считать.

**5. `:.2f` для строк.** `f"{'abc':.2f}"` → `ValueError`: формат `f` только для чисел.

**6. Процент умножается дважды.** `f"{accuracy * 100:.1%}"` даст `8765.4%` — формат `%` уже умножает на 100.

## Где это в AI-инженерии

- **Логи обучения.** `f"epoch {epoch:3d} | loss {loss:.4f} | lr {lr:.1e}"` — формат, который вы увидите в любом скрипте обучения.
- **Метрики в отчётах.** Accuracy, precision, recall хранятся как доли, выводятся через `:.1%`.
- **Стоимость запросов.** `f"${cost:.4f}"` — у LLM API цена одного запроса часто меньше цента, нужны 4–6 знаков.
- **Шаблоны промптов.** f-строки и `.format()` подставляют вопрос пользователя, контекст и инструкции в шаблон. Ловушка: пример JSON в шаблоне требует удвоенных скобок.
- **Имена файлов.** `f"checkpoint_epoch_{epoch:03d}.pt"` — чекпойнты сортируются правильно (`010` после `009`, а не после `001`).
- **Отладка.** `print(f"{tensor.shape=}")` — быстрый способ посмотреть размерности при отладке нейросети.

## Итоги урока

- f-строка: `f"текст {выражение} текст"`; внутри скобок — любое выражение.
- Спецификация формата после двоеточия: `.2f` (знаки), `,` (тысячи), `%` (проценты), `e` (научная), `+` (знак).
- Ширина и выравнивание: `<`, `>`, `^`, заполнитель (`*^20`), нули (`05d`).
- `{x=}` — отладочный вывод с именем выражения; `{{` `}}` — фигурные скобки как текст.
- Формат меняет отображение (строка), `round()` — значение (число).
