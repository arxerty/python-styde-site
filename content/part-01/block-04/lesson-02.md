# Методы строк

## Что такое метод

Вы уже знаете функции: `len(text)`, `print(text)`, `int(text)`. Функция — самостоятельная операция, которой передают данные в скобках. **Метод** — это функция, которая «принадлежит» объекту определённого типа и вызывается **через точку**:

```python
text = "Привет, Мир"
print(text.upper())
print(text.lower())
```

```text
ПРИВЕТ, МИР
привет, мир
```

Запись `text.upper()` читается как «у строки `text` вызови метод `upper`». У строк больше 40 методов — все они знают, как работать именно со строками. Посмотреть их список можно командой `dir(str)`, а описание любого — `help(str.upper)`.

## Главное правило: методы не меняют строку

Строки неизменяемы (прошлый урок), поэтому **ни один метод не изменяет исходную строку** — все возвращают новую:

```python
name = "ада"
name.upper()
print(name)
name = name.upper()
print(name)
```

```text
ада
АДА
```

Первый вызов `name.upper()` создал строку `"АДА"`, но её никуда не сохранили — она пропала. Чтобы результат остался, его нужно **присвоить**. Это самая частая ошибка с методами строк.

## Регистр

| Метод | Результат для `"пРиВеТ мИр"` |
|---|---|
| `upper()` | `ПРИВЕТ МИР` |
| `lower()` | `привет мир` |
| `capitalize()` | `Привет мир` — первая буква заглавная, остальные строчные |
| `title()` | `Привет Мир` — каждое слово с заглавной |
| `swapcase()` | `ПрИвЕт МиР` — инвертирует регистр |

Самое частое применение — **сравнение без учёта регистра**: приводим обе строки к одному регистру.

```python
answer = "Париж"
user_input = "париж"
print(answer == user_input)
print(answer.lower() == user_input.lower())
```

```text
False
True
```

Для сравнения многоязычного текста есть ещё более «агрессивный» метод `casefold()` — он, например, превращает немецкую `ß` в `ss`. Для русского и английского достаточно `lower()`.

## Удаление пробелов: strip

Пользователи, файлы и модели постоянно оставляют лишние пробелы и переводы строк по краям текста. `strip()` убирает их с обеих сторон, `lstrip()` — слева, `rstrip()` — справа:

```python
raw = "   данные \n"
print("[" + raw.strip() + "]")
print("[" + raw.lstrip() + "]")
print("[" + raw.rstrip() + "]")
```

```text
[данные]
[данные 
]
[   данные]
```

`strip()` удаляет **все** пробельные символы по краям: пробелы, табуляции, переводы строк. Пробелы **внутри** строки он не трогает.

С аргументом `strip` удаляет указанные символы (любые из перечисленных, в любом порядке):

```python
print("***важно!!!".strip("*!"))
print("...текст,".strip(".,"))
```

```text
важно
текст
```

Аргумент — это **набор символов**, а не подстрока: `strip("*!")` удаляет и звёздочки, и восклицательные знаки, пока на краю встречается любой из них.

### removeprefix и removesuffix

Если нужно убрать конкретную подстроку в начале или в конце, используйте `removeprefix()` / `removesuffix()` (Python 3.9+). Они удаляют её только один раз и только если она там есть:

```python
filename = "draft_report.txt"
print(filename.removeprefix("draft_"))
print(filename.removesuffix(".txt"))
print(filename.removesuffix(".csv"))
```

```text
report.txt
draft_report
draft_report.txt
```

## Разбиение и склейка: split и join

### split

`split()` разбивает строку на части и возвращает **список** строк (о списках подробно — в следующем блоке; пока достаточно знать, что его можно перебрать в `for`, узнать длину через `len()` и взять элемент по индексу).

Без аргументов `split()` режет по **любым** пробельным символам и отбрасывает пустые куски:

```python
sentence = "  я   учу   Python  "
words = sentence.split()
print(words)
print(len(words))
```

```text
['я', 'учу', 'Python']
3
```

С аргументом — режет по указанному разделителю. Здесь пустые куски **сохраняются**:

```python
csv_line = "Ада,36,Лондон"
print(csv_line.split(","))
print("a,,b".split(","))
print("2026-10-16".split("-"))
```

```text
['Ада', '36', 'Лондон']
['a', '', 'b']
['2026', '10', '16']
```

Второй аргумент `maxsplit` ограничивает число разрезов:

```python
log = "ERROR: файл не найден: data.csv"
level, message = log.split(": ", 1)
print(level)
print(message)
```

```text
ERROR
файл не найден: data.csv
```

Без `1` строка разрезалась бы на три части, и распаковка в две переменные упала бы.

Удобен `splitlines()` — разбиение многострочного текста на строки:

```python
text = "первая\nвторая\nтретья"
print(text.splitlines())
```

```text
['первая', 'вторая', 'третья']
```

### join

`join()` — обратная операция: склеивает последовательность строк, вставляя между ними **строку-разделитель**. Синтаксис непривычный: метод вызывается у разделителя.

```python
words = ["машинное", "обучение"]
print(" ".join(words))
print("-".join(words))
print("".join(words))
print(", ".join(["a", "b", "c"]))
```

```text
машинное обучение
машинное-обучение
машинноеобучение
a, b, c
```

Связка `split` + `join` — универсальный инструмент нормализации пробелов:

```python
messy = "  слишком    много   пробелов  "
clean = " ".join(messy.split())
print("[" + clean + "]")
```

```text
[слишком много пробелов]
```

`join` работает только со строками: `", ".join([1, 2])` вызовет `TypeError`. Числа сначала превращают в строки.

> **Почему join быстрее склейки в цикле.** `+=` в цикле на каждом шаге создаёт новую строку и копирует в неё всё накопленное. `join` сначала считает итоговую длину и копирует каждый кусок ровно один раз. Для тысяч кусков разница — в десятки раз.

## Замена: replace

`replace(old, new)` заменяет **все** вхождения подстроки:

```python
price = "3,14"
print(price.replace(",", "."))
print(float(price.replace(",", ".")) * 2)
text = "кот и кот"
print(text.replace("кот", "пёс"))
print(text.replace("кот", "пёс", 1))
print(text.replace(" ", ""))
```

```text
3.14
6.28
пёс и пёс
пёс и кот
котикот
```

Третий аргумент ограничивает число замен. Замена на пустую строку — способ удалить подстроку.

## Поиск: find, index, count

| Метод | Что возвращает | Если не найдено |
|---|---|---|
| `find(sub)` | индекс первого вхождения | `-1` |
| `rfind(sub)` | индекс последнего вхождения | `-1` |
| `index(sub)` | индекс первого вхождения | `ValueError` |
| `count(sub)` | количество непересекающихся вхождений | `0` |

```python
email = "ada.lovelace@example.com"
at = email.find("@")
print(at)
print(email[:at])
print(email[at + 1:])
print(email.find("#"))
print("banana".count("an"))
```

```text
12
ada.lovelace
example.com
-1
2
```

`find` + срез — классический способ разобрать строку по разделителю. А `rfind` удобен для поиска **последнего** вхождения — например, точки перед расширением файла:

```python
filename = "archive.tar.gz"
dot = filename.rfind(".")
print(filename[dot + 1:])
```

```text
gz
```

**Ловушка с -1.** `find` возвращает `-1`, а `-1` — допустимый индекс (последний символ)! Если не проверить результат, получится тихая ошибка:

```python
name = "без_расширения"
dot = name.rfind(".")
print(dot, name[dot + 1:])
```

```text
-1 без_расширения
```

Срез `name[0:]` вернул всю строку как «расширение». Всегда проверяйте `if dot == -1:` или используйте `in` (урок 4).

## Цепочки методов

Поскольку каждый метод возвращает строку, вызовы можно соединять в цепочку — они выполняются слева направо:

```python
raw = "   Привет,  МИР!   "
result = raw.strip().lower().replace(",", "").replace("!", "")
print(result)
```

```text
привет  мир
```

Цепочки удобны для коротких преобразований. Если цепочка длиннее трёх-четырёх вызовов, лучше разбить её на шаги с понятными именами промежуточных переменных — так проще отлаживать.

## Разбор задачи: очистка ответа языковой модели

Языковые модели часто оборачивают ответ в разметку, даже если их просили вернуть «чистый» JSON: добавляют ```` ```json ```` в начале, ```` ``` ```` в конце, лишние пробелы и переводы строк. Перед разбором ответ нужно очистить:

```python
response = "  ```json\n{\"label\": \"positive\"}\n```  "
cleaned = response.strip()
cleaned = cleaned.removeprefix("```json").removeprefix("```")
cleaned = cleaned.removesuffix("```")
cleaned = cleaned.strip()
print(cleaned)
```

```text
{"label": "positive"}
```

Каждый шаг делает одну вещь: убрать пробелы по краям → убрать открывающий маркер (с языком или без) → убрать закрывающий → снова убрать пробелы. Такая функция очистки есть почти в каждом проекте с LLM. (Ещё надёжнее — structured output, при котором модель гарантированно возвращает валидный JSON. Об этом в блоках 2.5 и 7.3.)

## Частые ошибки

**1. Вызвать метод и не сохранить результат.** `s.strip()` без присваивания ничего не меняет.

**2. Путать `split()` и `split(" ")`.** Первый режет по любым пробелам и выбрасывает пустые куски, второй — только по одиночному пробелу и оставляет пустые строки при двойных пробелах.

**3. `join` у списка.** `words.join(" ")` — ошибка. Правильно: `" ".join(words)`.

**4. `join` с числами.** Все элементы должны быть строками.

**5. Не проверять `-1` у `find`.** `-1` — валидный индекс, ошибка будет незаметной.

**6. Думать, что `strip("abc")` удаляет подстроку «abc».** Он удаляет любые из символов a, b, c с краёв. Для подстроки — `removeprefix`/`removesuffix`.

## Где это в AI-инженерии

- **Нормализация текста.** `text.strip().lower()` и `" ".join(text.split())` — стандартная предобработка перед классификацией, поиском и подсчётом статистик.
- **Простейшая токенизация.** `text.split()` — самый наивный токенизатор. Настоящие токенизаторы LLM устроены сложнее (BPE, блок 6.5), но начинают с той же идеи — разрезать текст на единицы.
- **Сборка промптов.** `"\n".join(instructions)` собирает многострочный промпт из списка правил; `"\n\n".join(documents)` — контекст из найденных документов в RAG.
- **Очистка ответов модели.** `strip`, `removeprefix`, `removesuffix`, `replace` — удаление разметки, лишних пробелов и служебных фраз.
- **Разбор логов и форматов.** `split(": ", 1)`, `find`, `rfind` — извлечение уровня логирования, расширения файла, домена из email.
- **Сравнение ответов в эвалах.** Метрика exact match почти всегда сравнивает `pred.strip().lower() == gold.strip().lower()`.

## Итоги урока

- Метод вызывается через точку: `text.upper()`; методы строк **возвращают новую строку** и не меняют исходную.
- Регистр: `upper`, `lower`, `capitalize`, `title`; пробелы: `strip`, `lstrip`, `rstrip`; подстроки по краям: `removeprefix`, `removesuffix`.
- `split()` → список строк; `"разделитель".join(список)` → строка.
- `replace(old, new[, count])` — замена; `find`/`rfind` → индекс или `-1`; `index` → ошибка, если не найдено; `count` — число вхождений.
- Методы можно соединять в цепочки.
