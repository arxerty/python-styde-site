# Проверки строк и перебор символов

## Вопросы к тексту

Прошлый урок был про преобразование строк. Этот — про **вопросы**, которые можно задать строке: «начинается ли она с https?», «состоит ли она только из цифр?», «есть ли в ней слово "ошибка"?», «сколько в ней заглавных букв?». Все такие проверки возвращают `True` или `False` и естественно сочетаются с `if`, циклами и накопителями из прошлых блоков.

Без таких проверок нельзя ни валидировать ввод пользователя, ни фильтровать данные, ни разбирать ответы моделей.

## Оператор in: есть ли подстрока

`подстрока in строка` проверяет, входит ли одна строка в другую:

```python
message = "Произошла ошибка при загрузке модели"
print("ошибка" in message)
print("Ошибка" in message)
print("успех" not in message)
print("" in message)
```

```text
True
False
True
True
```

- Проверка чувствительна к регистру: `"Ошибка"` с заглавной не найдена. Для поиска без учёта регистра приводите обе строки к нижнему: `"ошибка" in message.lower()`.
- `not in` — отрицание; пишется именно так, а не `not "успех" in message` (хотя это тоже сработает, PEP 8 рекомендует `not in`).
- Пустая строка содержится в любой строке.

`in` — самый читаемый способ проверить наличие подстроки. Используйте его вместо `find(...) != -1`.

## startswith и endswith

Проверяют начало и конец строки:

```python
url = "https://example.com/report.PDF"
print(url.startswith("https://"))
print(url.endswith(".pdf"))
print(url.lower().endswith(".pdf"))
```

```text
True
False
True
```

Оба метода принимают **кортеж** вариантов (кортеж — неизменяемый набор значений в круглых скобках; подробно в блоке 1.5) — тогда проверяется, подходит ли **хотя бы один**:

```python
filename = "photo.jpeg"
print(filename.endswith((".jpg", ".jpeg", ".png")))
link = "http://old-site.ru"
print(link.startswith(("http://", "https://")))
```

```text
True
True
```

Почему не срез `url[:8] == "https://"`? Можно и так, но придётся считать длину префикса вручную, и легко ошибиться на единицу. `startswith` и короче, и надёжнее.

## Методы is…: из чего состоит строка

Семейство методов, отвечающих на вопрос «все ли символы строки относятся к категории…»:

| Метод | `True`, если **все** символы… | Пример `True` | Пример `False` |
|---|---|---|---|
| `isdigit()` | цифры | `"2026"` | `"-5"`, `"3.14"` |
| `isalpha()` | буквы (любого алфавита) | `"Привет"` | `"AI2"` |
| `isalnum()` | буквы или цифры | `"gpt4"` | `"gpt-4"` |
| `isspace()` | пробельные символы | `"  \n\t"` | `" a "` |
| `isupper()` | заглавные (среди букв) | `"NASA"` | `"Nasa"` |
| `islower()` | строчные (среди букв) | `"python3"` | `"Python"` |

Два важных правила:

1. Методы проверяют **все** символы. `"abc1".isalpha()` — `False` из-за одной цифры.
2. Для **пустой** строки все `is…`-методы возвращают `False`.

```python
print("12345".isdigit(), "".isdigit(), "12 345".isdigit())
print("Москва".isalpha(), "Нью-Йорк".isalpha())
```

```text
True False False
True False
```

Пробел и дефис — не буквы и не цифры, поэтому проверки «ломаются» на них.

### Ограничения isdigit

`isdigit()` подходит для проверки **целых неотрицательных** чисел. Минус и точка — не цифры:

```python
for text in ["42", "-42", "4.2", "4,2", " 42 "]:
    print(repr(text), text.isdigit())
```

```text
'42' True
'-42' False
'4.2' False
'4,2' False
' 42 ' False
```

(`repr()` показывает строку с кавычками — так видны пробелы по краям.) Для отрицательных чисел можно проверить отдельно знак: `text.lstrip("-").isdigit()`, для дробных — сложнее. Самый надёжный способ проверить, что строка — число, — попробовать преобразовать её и обработать ошибку через `try/except` (блок 1.7). А `isdigit` идеален для простых случаев: ввод номера пункта меню, возраста, количества.

> У `isdigit` есть родственники `isdecimal` и `isnumeric`, которые по-разному относятся к экзотическим символам вроде `²` или `½`. Для обычных цифр 0–9 все три ведут себя одинаково.

## Перебор символов

Проверки отдельных символов в цикле — способ ответить на вопросы «сколько?» и «есть ли хоть один?».

### Подсчёт по категориям

```python
text = "Python 3.12 вышел в 2023!"
letters = digits = spaces = other = 0
for char in text:
    if char.isalpha():
        letters += 1
    elif char.isdigit():
        digits += 1
    elif char.isspace():
        spaces += 1
    else:
        other += 1
print(f"букв: {letters}, цифр: {digits}, пробелов: {spaces}, прочих: {other}")
```

```text
букв: 12, цифр: 7, пробелов: 4, прочих: 2
```

Запись `letters = digits = spaces = other = 0` — цепочка присваивания из блока 1.1: все четыре накопителя начинаются с нуля.

### «Есть ли хотя бы одна…»

Проверка «в пароле есть цифра» — это шаблон «any» из блока про накопители:

```python
password = "secret42"
has_digit = False
for char in password:
    if char.isdigit():
        has_digit = True
        break
print(has_digit)
print(password.isdigit())
```

```text
True
False
```

Обратите внимание на разницу: `password.isdigit()` спрашивает «**все** ли символы цифры», а цикл — «есть ли **хоть одна** цифра». Перепутать их — классическая ошибка.

В Python есть компактная запись этого шаблона через встроенную функцию `any()` и генераторное выражение (подробно в блоке 1.5):

```python
password = "secret42"
print(any(char.isdigit() for char in password))
print(all(char.isalnum() for char in password))
```

```text
True
True
```

### Перебор с индексом

Иногда нужен не только символ, но и его позиция — например, чтобы сравнить символ с соседним. Тогда перебирают индексы:

```python
word = "аббат"
for i in range(len(word) - 1):
    if word[i] == word[i + 1]:
        print(f"Двойная буква «{word[i]}» на позициях {i} и {i + 1}")
```

```text
Двойная буква «б» на позициях 1 и 2
```

`range(len(word) - 1)` — чтобы `word[i + 1]` не вышел за границу. В блоке 1.5 вы узнаете функцию `enumerate()`, которая выдаёт сразу и индекс, и символ.

## Разбор задачи: валидация пароля

Соберём проверки в настоящий валидатор. Требования: не короче 8 символов, хотя бы одна цифра, хотя бы одна заглавная и одна строчная буква. Сообщаем обо **всех** нарушениях сразу — так удобнее пользователю.

```python
password = "qwerty12"
has_digit = has_upper = has_lower = False
for char in password:
    if char.isdigit():
        has_digit = True
    elif char.isupper():
        has_upper = True
    elif char.islower():
        has_lower = True

problems = ""
if len(password) < 8:
    problems += "- короче 8 символов\n"
if not has_digit:
    problems += "- нет цифры\n"
if not has_upper:
    problems += "- нет заглавной буквы\n"
if not has_lower:
    problems += "- нет строчной буквы\n"

if problems:
    print("Пароль ненадёжный:")
    print(problems.rstrip())
else:
    print("Пароль надёжный")
```

```text
Пароль ненадёжный:
- нет заглавной буквы
```

Устройство: один проход по символам собирает три флага, затем независимые проверки накапливают сообщения в строку. `if problems:` — проверка непустоты строки из урока про truthy-значения. `rstrip()` убирает последний перевод строки.

## Разбор задачи: фильтр ссылок

Из списка строк оставим только ссылки на PDF-документы — неважно, в каком регистре записано расширение:

```python
lines = [
    "https://site.ru/report.pdf",
    "ftp://files.ru/data.pdf",
    "https://site.ru/photo.PNG",
    "http://old.ru/Manual.PDF",
]
for line in lines:
    lowered = line.lower()
    if lowered.startswith(("http://", "https://")) and lowered.endswith(".pdf"):
        print(line)
```

```text
https://site.ru/report.pdf
http://old.ru/Manual.PDF
```

Нормализуем регистр **один раз** в переменную `lowered`, а выводим исходную строку. Такой фильтр — типичный шаг при сборе документов для базы знаний RAG-системы.

## Как это устроено внутри

Методы `is…` опираются на **базу данных Unicode**: у каждого символа есть категория — буква, цифра, пробел, знак препинания и так далее. Поэтому `"Привет".isalpha()` и `"東京".isalpha()` одинаково возвращают `True`: Python знает категории символов всех письменностей мира. А `in` для строк использует быстрый алгоритм поиска подстроки, написанный на C: проверка «есть ли слово в мегабайтном тексте» занимает миллисекунды.

## Попробуйте сами

- Проверьте `"Ёлка".isalpha()`, `"١٢٣".isdigit()` (арабские цифры) и `"Ⅻ".isdigit()`. Объясните результаты.
- Посчитайте, сколько слов в предложении начинается с заглавной буквы.
- Напишите проверку, что строка — корректный номер телефона вида `+7XXXXXXXXXX` (12 символов, начинается с `+7`, остальные — цифры).

## Частые ошибки

**1. `isdigit()` вместо «есть ли цифра».** `"abc1".isdigit()` — `False`: метод проверяет **все** символы.

**2. `isdigit()` для отрицательных и дробных.** `"-5"` и `"3.14"` — не «цифры».

**3. Регистр в `in` и `startswith`.** `"PDF" in name` не найдёт `"pdf"`. Нормализуйте `lower()`.

**4. `startswith` со списком.** Варианты передаются **кортежем** в круглых скобках: `s.startswith(("a", "b"))`, а не списком.

**5. Индекс соседнего символа за границей.** `word[i + 1]` при `i = len(word) - 1` → `IndexError`. Перебирайте до `len(word) - 1`.

**6. Пустая строка.** Все `is…` для `""` дают `False` — учитывайте это при проверке ввода.

## Где это в AI-инженерии

- **Фильтрация датасетов.** Отбросить тексты, состоящие только из цифр или пробелов; оставить строки на нужном алфавите; убрать записи, начинающиеся с «RT @» (ретвиты) — это всё проверки строк.
- **Валидация ввода.** Перед отправкой в модель проверяют, что запрос не пустой (`not text.isspace()`), не слишком длинный, не содержит запрещённых фрагментов.
- **Детекция prompt injection.** Наивная, но полезная первая линия защиты — поиск подозрительных фраз: `"ignore previous instructions" in text.lower()`. Подробно о защите — в блоке 8.4.
- **Разбор ответов модели.** `if answer.strip().lower().startswith("да"):` — превращение свободного ответа LLM в решение; `answer.isdigit()` — проверка, что модель вернула число, как просили.
- **Сбор документов для RAG.** Фильтр по расширениям (`endswith((".pdf", ".md"))`) и протоколам (`startswith("https://")`).
- **Признаки для классических моделей.** Доля заглавных букв, количество цифр, наличие восклицательных знаков — простые, но рабочие признаки для детекции спама.

## Итоги урока

- `in` / `not in` — есть ли подстрока; чувствителен к регистру.
- `startswith` / `endswith` — проверка начала и конца; принимают кортеж вариантов.
- `isdigit`, `isalpha`, `isalnum`, `isspace`, `isupper`, `islower` — проверяют, что **все** символы относятся к категории; для пустой строки — `False`.
- «Есть ли хоть один символ…» — цикл с флагом или `any()`.
- Перебор по индексам — когда нужны соседние символы; не выходите за границу.
