# Индексы, срезы и неизменяемость строк

## Строка как последовательность

В первом блоке мы работали со строкой целиком: склеивали, повторяли, измеряли длину. Но текст — это **последовательность символов**, и часто нужен доступ к её частям: первая буква имени, расширение файла, последние три цифры номера, первые 100 символов документа для превью. Для этого есть **индексы** и **срезы**.

Строку удобно представлять как ряд пронумерованных ячеек:

```text
 символ:   P   y   t   h   o   n
 индекс:   0   1   2   3   4   5
 с конца: -6  -5  -4  -3  -2  -1
```

## Индексы

Символ по номеру получают квадратными скобками: `строка[индекс]`. **Нумерация начинается с нуля.**

```python
word = "Python"
print(word[0])
print(word[1])
print(word[5])
```

```text
P
y
n
```

Почему с нуля? Индекс — это **смещение** от начала строки: первый символ смещён на 0 позиций, второй — на 1. Так устроены почти все популярные языки программирования, и к этому быстро привыкаешь. Главное следствие: последний символ имеет индекс `len(строка) - 1`.

```python
word = "Python"
print(len(word))
print(word[len(word) - 1])
```

```text
6
n
```

### Отрицательные индексы

Писать `len(word) - 1` громоздко, поэтому Python поддерживает **отрицательные индексы** — отсчёт с конца: `-1` — последний символ, `-2` — предпоследний и так далее.

```python
word = "Python"
print(word[-1])
print(word[-2])
print(word[-6])
```

```text
n
o
P
```

Внутри Python просто прибавляет длину строки: `word[-1]` — это `word[6 - 1]`, то есть `word[5]`.

### Выход за границы

Обращение к несуществующему индексу вызывает ошибку:

```python
word = "Python"
print(word[6])
```

Получится `IndexError: string index out of range`. Допустимые индексы для строки длины `n`: от `0` до `n - 1` и от `-n` до `-1`. Особенно коварна пустая строка: у неё вообще нет допустимых индексов, и `text[0]` упадёт. Поэтому перед обращением к `text[0]` часто проверяют `if text:`.

## Срезы

**Срез** (slice) извлекает кусок строки: `строка[start:stop]`. Как и `range`, он включает `start` и **не включает** `stop`.

```python
text = "machine learning"
print(text[0:7])
print(text[8:16])
print(text[3:7])
```

```text
machine
learning
hine
```

Правило полуоткрытого интервала даёт те же удобства, что и у `range`:

- длина среза `text[a:b]` равна `b - a`;
- срезы `text[:k]` и `text[k:]` вместе дают всю строку без пропусков и повторов.

### Пропуск границ

Любую границу можно опустить:

- `text[:k]` — от начала до `k` (первые `k` символов);
- `text[k:]` — от `k` до конца (всё, кроме первых `k`);
- `text[:]` — вся строка.

```python
filename = "report_2026.csv"
print(filename[:6])
print(filename[-3:])
print(filename[:-4])
```

```text
report
csv
report_2026
```

`filename[-3:]` — «последние три символа», `filename[:-4]` — «всё, кроме последних четырёх» (отрезали `.csv`). Эти две идиомы встречаются постоянно.

### Срезы прощают ошибки

В отличие от индексов, срезы **не вызывают ошибку** при выходе за границы — они просто обрезаются до реальной длины:

```python
short = "AI"
print(short[0:100])
print(short[5:10])
print(len(short[5:10]))
```

```text
AI

0
```

Это удобно: `text[:100]` даёт «не больше 100 символов» и для короткой строки, и для длинной, без проверок длины. Так делают превью документов и обрезают слишком длинные тексты перед отправкой в модель.

### Шаг среза

Третий параметр — шаг: `строка[start:stop:step]`.

```python
alphabet = "abcdefghij"
print(alphabet[::2])
print(alphabet[1::2])
print(alphabet[1:8:3])
```

```text
acegi
bdfhj
beh
```

`[::2]` — каждый второй символ, начиная с первого; `[1::2]` — каждый второй, начиная со второго.

### Отрицательный шаг и разворот строки

С отрицательным шагом срез идёт **справа налево**. Самая известная идиома Python — разворот строки:

```python
word = "ротор"
print(word[::-1])
print("Python"[::-1])
print("Python"[4:1:-1])
```

```text
ротор
nohtyP
oht
```

При отрицательном шаге `start` должен быть **правее** `stop` (как в `range(5, 0, -1)`). Если границы опущены, `[::-1]` берёт всю строку от конца к началу.

Сравните с блоком про циклы, где для разворота строки понадобился цикл и накопитель. Срез делает то же самое одной операцией — и намного быстрее, потому что работа выполняется внутри интерпретатора на языке C.

## Неизменяемость строк

Строки в Python **неизменяемы** (immutable). Изменить символ по индексу нельзя:

```python
word = "Python"
word[0] = "J"
```

Результат — `TypeError: 'str' object does not support item assignment`.

Чтобы «изменить» строку, создают **новую** из кусков старой:

```python
word = "Python"
new_word = "J" + word[1:]
print(new_word)
print(word)
```

```text
Jython
Python
```

Исходная строка не изменилась. Все строковые операции — склейка, срезы, методы из следующего урока — возвращают **новые** строки.

### Зачем строкам неизменяемость

На первый взгляд — неудобство. Но у него серьёзные причины:

1. **Безопасность.** Если две переменные ссылаются на одну строку, ни одна не может незаметно испортить её для другой. Вспомните картинку «имена-ярлыки» из блока 1.1.
2. **Строки можно использовать как ключи словаря.** Словари (блок 1.5) требуют, чтобы ключ не менялся, — иначе его невозможно было бы найти.
3. **Оптимизация.** Python может хранить одну копию одинаковых строк и безопасно переиспользовать её.

Цена неизменяемости — при многократных изменениях создаётся много промежуточных строк. Для сборки большого текста из множества кусков есть быстрый метод `join()` (следующий урок).

## Разбор задачи: маскирование номера карты

Частая задача при выводе персональных данных: показать номер карты так, чтобы видны были только последние 4 цифры.

```python
card = "4276550012345678"
masked = "*" * (len(card) - 4) + card[-4:]
print(masked)
grouped = masked[0:4] + " " + masked[4:8] + " " + masked[8:12] + " " + masked[12:16]
print(grouped)
```

```text
************5678
**** **** **** 5678
```

`card[-4:]` — последние четыре символа, `len(card) - 4` — сколько символов скрыть. Разбивка на группы по 4 — четыре среза подряд, стыкующихся без пропусков. (В следующих уроках вы научитесь делать это циклом с шагом 4 или через `join`.)

Маскирование персональных данных — реальная задача AI-инженера: прежде чем отправлять текст во внешний API языковой модели, номера карт, телефоны и паспорта нужно скрыть. Подробно — в блоке 8.4 о безопасности LLM-приложений.

## Разбор задачи: проверка палиндрома

Палиндром читается одинаково в обе стороны. С разворотом через срез проверка занимает одну строку:

```python
word = "шалаш"
print(word == word[::-1])
phrase = "А роза упала на лапу Азора"
cleaned = phrase.replace(" ", "").lower()
print(cleaned, cleaned == cleaned[::-1])
```

```text
True
арозаупаланалапуазора True
```

Для фразы сначала убрали пробелы и привели всё к нижнему регистру методами `replace()` и `lower()` — их вы подробно разберёте в следующем уроке.

## Как это устроено внутри

Строка в памяти Python хранит символы подряд в одном блоке памяти, а также свою длину. Поэтому:

- обращение по индексу работает **мгновенно**, независимо от длины строки: Python сразу вычисляет адрес нужного символа;
- `len()` тоже мгновенная — длина хранится, а не пересчитывается;
- срез создаёт **новую** строку и копирует символы — его стоимость пропорциональна длине куска.

Python даже выбирает размер ячейки под каждую строку: если в строке только латиница — по 1 байту на символ, есть кириллица — по 2, есть эмодзи — по 4. Благодаря этому индексация всегда остаётся мгновенной. Подробнее о символах и кодировках — в уроке 5.

## Частые ошибки

**1. Забывать, что индексы с нуля.** Первый символ — `s[0]`, а `s[1]` — второй.

**2. Последний символ через `s[len(s)]`.** Это `IndexError`. Правильно: `s[-1]` или `s[len(s) - 1]`.

**3. Ожидать, что `stop` включается.** `s[0:3]` — три символа: индексы 0, 1, 2.

**4. Пытаться изменить символ.** `s[0] = "X"` → `TypeError`. Создайте новую строку.

**5. Отрицательный шаг с границами в неправильном порядке.** `s[1:5:-1]` — пустая строка.

**6. Индекс у пустой строки.** `""[0]` → `IndexError`. Проверяйте `if s:` перед `s[0]`.

## Где это в AI-инженерии

- **Обрезка до лимита.** `text[:max_chars]` — грубая, но быстрая защита от слишком длинного входа модели. Точнее режут по токенам (часть 7), но идея та же.
- **Превью и логи.** `print(response[:200])` — посмотреть начало длинного ответа модели, не засоряя лог.
- **Чанкинг документов.** В RAG документ режут на куски: `text[start:start + chunk_size]` в цикле по `range(0, len(text), step)`. Перекрытие кусков (overlap) — это шаг меньше размера куска.
- **Маскирование PII.** Скрытие номеров и персональных данных перед отправкой во внешние API.
- **Разбор форматов.** Расширения файлов, префиксы идентификаторов (`"sk-..."` у API-ключей), даты в формате `YYYY-MM-DD` — всё это срезы.
- **Скользящее окно.** Многие алгоритмы обработки текста смотрят на «окно» из n соседних символов или слов: `text[i:i + n]`. Так строятся n-граммы — основа классических языковых моделей.

## Итоги урока

- `s[i]` — символ по индексу; нумерация с 0, отрицательные индексы — с конца (`s[-1]` — последний).
- `s[start:stop:step]` — срез; `stop` не включается; границы можно опускать.
- Срезы не падают при выходе за границы, индексы — падают (`IndexError`).
- `s[::-1]` — разворот строки.
- Строки неизменяемы: «изменение» — это создание новой строки.
