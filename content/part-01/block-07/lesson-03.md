# Работа с файлами

## Данные живут в файлах

Всё, что программа хранит в переменных, исчезает, когда она завершается. Чтобы сохранить результат работы или прочитать данные, подготовленные кем-то другим, нужны **файлы**. Датасеты для обучения, конфигурации, логи экспериментов, сохранённые веса моделей, документы для базы знаний RAG — всё это файлы. Умение уверенно читать и писать их — базовый навык AI-инженера.

На этой платформе код выполняется в браузере, но у Python здесь есть своя виртуальная файловая система: файлы можно создавать, читать и перезаписывать, как на обычном компьютере. Примеры этого урока сначала создают файл, а потом с ним работают.

## open и with

Файл открывают встроенной функцией `open()`, а работать с ним правильно внутри блока `with`:

```python
with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Первая строка\n")
    file.write("Вторая строка\n")

with open("notes.txt", encoding="utf-8") as file:
    content = file.read()
print(content)
```

```text
Первая строка
Вторая строка
```

Разберём `open(путь, режим, encoding=...)`:

- **путь** — имя файла (относительно текущей папки) или полный путь;
- **режим** — что мы собираемся делать с файлом (по умолчанию `"r"` — чтение);
- **`encoding="utf-8"`** — кодировка текста. **Указывайте её всегда**: без неё Python использует кодировку системы (на Windows это часто cp1251), и файл с русским текстом, созданный на Mac, превратится в кракозябры (вспомните урок про Unicode).

`open()` возвращает **файловый объект**, через который читают и пишут. Блок `with` гарантирует, что файл будет **закрыт** по выходу из блока — даже если внутри произошло исключение. Незакрытые файлы держат ресурсы операционной системы, а записанные данные могут не попасть на диск. Без `with` пришлось бы писать `try/finally` с `file.close()` — `with` делает это автоматически. Такие объекты называют **менеджерами контекста** (подробно — в блоке 2.4).

## Режимы открытия

| Режим | Действие | Если файла нет | Если файл есть |
|---|---|---|---|
| `"r"` | чтение | `FileNotFoundError` | читаем с начала |
| `"w"` | запись | создаётся | **содержимое стирается** |
| `"a"` | дозапись в конец | создаётся | пишем в конец |
| `"x"` | создание | создаётся | `FileExistsError` |

К режиму можно добавить `"b"` для **двоичных** файлов (картинки, веса моделей, архивы): `"rb"`, `"wb"`. В двоичном режиме читаются и пишутся `bytes`, а `encoding` не указывается.

Осторожно с `"w"`: открытие существующего файла на запись **сразу** стирает его содержимое — даже если вы ничего не запишете. Для логов и накопления результатов используйте `"a"`:

```python
with open("log.txt", "w", encoding="utf-8") as file:
    file.write("старт\n")
with open("log.txt", "a", encoding="utf-8") as file:
    file.write("эпоха 1\n")
    file.write("эпоха 2\n")
with open("log.txt", encoding="utf-8") as file:
    print(file.read())
```

```text
старт
эпоха 1
эпоха 2
```

## Чтение

Три способа прочитать текстовый файл:

```python
with open("data.txt", "w", encoding="utf-8") as file:
    file.write("кот\nпёс\nпопугай\n")

with open("data.txt", encoding="utf-8") as file:
    whole = file.read()
with open("data.txt", encoding="utf-8") as file:
    lines = file.readlines()
with open("data.txt", encoding="utf-8") as file:
    first = file.readline()

print(repr(whole))
print(lines)
print(repr(first))
```

```text
'кот\nпёс\nпопугай\n'
['кот\n', 'пёс\n', 'попугай\n']
'кот\n'
```

- `read()` — весь файл одной строкой;
- `readlines()` — список строк;
- `readline()` — одну следующую строку.

Обратите внимание: каждая строка **сохраняет символ перевода строки** `\n` на конце. Его почти всегда убирают через `rstrip("\n")` или `strip()`.

### Перебор строк — лучший способ

Файловый объект можно перебирать в цикле `for` — он выдаёт строки **по одной**:

```python
with open("data.txt", "w", encoding="utf-8") as file:
    file.write("кот\nпёс\n\nпопугай\n")

with open("data.txt", encoding="utf-8") as file:
    for number, line in enumerate(file, start=1):
        line = line.strip()
        if not line:
            continue
        print(number, line)
```

```text
1 кот
2 пёс
4 попугай
```

Главное преимущество: файл **не загружается в память целиком**. `read()` и `readlines()` для файла в 20 ГБ (обычный размер датасета для обучения языковой модели) исчерпают память, а перебор `for line in file` обработает его, держа в памяти одну строку. Это **потоковая обработка** — та же идея, что у накопителей «за один проход» из блока про циклы.

## Запись

```python
results = [("accuracy", 0.912), ("loss", 0.231), ("f1", 0.887)]
with open("metrics.txt", "w", encoding="utf-8") as file:
    for name, value in results:
        file.write(f"{name}\t{value:.3f}\n")

with open("metrics.txt", encoding="utf-8") as file:
    print(file.read())
```

```text
accuracy	0.912
loss	0.231
f1	0.887
```

- `write(строка)` пишет строку **как есть** — перевод строки нужно добавлять самому;
- `write` принимает только строки: числа превращайте через f-строки или `str()`;
- `writelines(список)` пишет все строки списка (тоже без автоматических переводов строк).

Удобная альтернатива — `print(..., file=file)`: он сам добавит перевод строки и расставит пробелы:

```python
with open("report.txt", "w", encoding="utf-8") as file:
    print("Отчёт", file=file)
    print("Точность:", 0.91, file=file)

with open("report.txt", encoding="utf-8") as file:
    print(file.read())
```

```text
Отчёт
Точность: 0.91
```

## Пути к файлам

**Относительный** путь (`"data.txt"`, `"data/train.csv"`) отсчитывается от **текущей рабочей папки** — той, из которой запущена программа (а не той, где лежит скрипт!). Это частый источник `FileNotFoundError`: скрипт работает из одной папки и «не находит» файл из другой.

**Абсолютный** путь начинается от корня: `C:\Users\ada\data.txt` (Windows) или `/home/ada/data.txt` (Linux, macOS).

Обратная косая черта в Windows-путях — экранирующий символ (вспомните `\n` и `\t`), поэтому пишите сырые строки `r"C:\new\table.csv"` или прямые слэши `"C:/new/table.csv"` — Python понимает их на любой ОС. Современный способ работы с путями — модуль `pathlib` (урок 6): `Path("data") / "train.csv"` собирает путь правильно на любой системе.

## Ошибки при работе с файлами

Работа с файлами — классическое место для обработки исключений из урока 1:

```python
def read_text(path):
    try:
        with open(path, encoding="utf-8") as file:
            return file.read()
    except FileNotFoundError:
        print(f"Файл не найден: {path}")
    except PermissionError:
        print(f"Нет доступа к файлу: {path}")
    except UnicodeDecodeError:
        print(f"Файл {path} не в кодировке UTF-8")
    return None


print(read_text("missing.txt"))
```

```text
Файл не найден: missing.txt
None
```

- `FileNotFoundError` — нет файла (опечатка в имени, не та рабочая папка);
- `PermissionError` — нет прав, или файл открыт другой программой (часто на Windows);
- `IsADirectoryError` — по пути находится папка, а не файл;
- `UnicodeDecodeError` — файл в другой кодировке или двоичный.

Все они (кроме последнего) — наследники `OSError`, так что при одинаковой реакции можно ловить `OSError`.

## Разбор задачи: потоковая обработка лога

Типичная задача: большой лог сервиса, нужно посчитать ошибки по типам и сохранить отчёт, не загружая лог в память целиком.

```python
log_lines = [
    "2026-10-17 10:00:01 INFO запрос принят",
    "2026-10-17 10:00:02 ERROR RateLimitError",
    "2026-10-17 10:00:05 ERROR TimeoutError",
    "2026-10-17 10:00:09 INFO ответ отправлен",
    "2026-10-17 10:01:00 ERROR RateLimitError",
]
with open("service.log", "w", encoding="utf-8") as file:
    file.write("\n".join(log_lines) + "\n")

errors = {}
total = 0
with open("service.log", encoding="utf-8") as file:
    for line in file:
        total += 1
        parts = line.split()
        if len(parts) >= 4 and parts[2] == "ERROR":
            errors[parts[3]] = errors.get(parts[3], 0) + 1

with open("errors_report.txt", "w", encoding="utf-8") as report:
    print(f"Строк в логе: {total}", file=report)
    for name, count in sorted(errors.items(), key=lambda item: -item[1]):
        print(f"{name}: {count}", file=report)

with open("errors_report.txt", encoding="utf-8") as report:
    print(report.read())
```

```text
Строк в логе: 5
RateLimitError: 2
TimeoutError: 1
```

Схема «читаем поток строк → накапливаем статистику в словаре → пишем отчёт» работает одинаково для пяти строк и для пяти миллиардов. Именно так анализируют логи LLM-сервисов, чтобы понять, сколько запросов упирается в лимиты.

## Частые ошибки

**1. Открывать без `with`** и забывать `close()` — данные могут не записаться.

**2. Не указывать `encoding="utf-8"`.** Кракозябры или `UnicodeDecodeError` на другом компьютере.

**3. `"w"` вместо `"a"`.** Файл с накопленными результатами молча стирается.

**4. Забыть `\n` при `write`.** Все строки сливаются в одну.

**5. Не убирать `\n` при чтении.** Строки `"кот\n"` и `"кот"` не равны — сравнения и поиск ломаются.

**6. `read()` для огромных файлов.** Исчерпание памяти; перебирайте файл по строкам.

**7. Относительный путь от «не той» папки.** Проверьте текущую папку или используйте абсолютные пути и `pathlib`.

## Где это в AI-инженерии

- **Датасеты.** Корпуса текстов для обучения и fine-tuning читают потоково, строка за строкой — они не помещаются в память.
- **JSONL.** Популярный формат датасетов и логов: по одному JSON-объекту на строку. Читается ровно циклом `for line in file` + `json.loads(line)` (следующий урок).
- **Логи экспериментов.** Метрики каждой эпохи дописывают в файл режимом `"a"`, чтобы результаты не потерялись при падении обучения.
- **Документы для RAG.** Загрузка базы знаний — чтение сотен текстовых и Markdown-файлов; кодировка и обработка битых файлов здесь критичны.
- **Веса моделей.** Чекпойнты — двоичные файлы (`"wb"`/`"rb"`); в PyTorch их пишут `torch.save`, но под капотом — тот же `open`.
- **Кэш ответов LLM.** Сохранённые на диск ответы позволяют не платить повторно за одинаковые запросы при отладке.

## Итоги урока

- `with open(path, mode, encoding="utf-8") as file:` — открыть файл и гарантированно закрыть.
- Режимы: `"r"` чтение, `"w"` запись со стиранием, `"a"` дозапись, `"x"` только новый файл; `"b"` — двоичный.
- Чтение: `read()`, `readlines()`, `readline()`, а лучше — `for line in file` (потоково); `\n` на концах убирайте.
- Запись: `write()` (сами добавляйте `\n`) или `print(..., file=file)`.
- Ошибки: `FileNotFoundError`, `PermissionError`, `UnicodeDecodeError` — обрабатывайте через `try/except`.
