# Строки: базовые операции

## Текст — главный материал AI-инженера

Если в машинном обучении главное — числа, то в работе с языковыми моделями главное — **текст**. Промпт, который вы отправляете модели, ответ модели, документы для поиска, отзывы для классификации — всё это строки. В Python текст представлен типом **`str`** (от string — строка).

Строка — это последовательность символов: букв, цифр, пробелов, знаков препинания, эмодзи. Python поддерживает любые языки мира: строка может содержать кириллицу, иероглифы и арабскую вязь одновременно.

```python
message = "Привет, мир!"
model = 'gpt-mini'
mixed = "Python 3.12 — 🐍"
print(message)
print(model)
print(mixed)
print(type(message))
```

```text
Привет, мир!
gpt-mini
Python 3.12 — 🐍
<class 'str'>
```

## Способы записать строку

### Одинарные и двойные кавычки

Между `'...'` и `"..."` нет разницы. Удобно выбирать те, которых нет внутри текста:

```python
print("It's Python")
print('Он сказал: "Привет"')
```

```text
It's Python
Он сказал: "Привет"
```

Если внутри нужны кавычки того же вида, их **экранируют** обратной косой чертой:

```python
print('It\'s Python')
print("Он сказал: \"Привет\"")
```

### Экранированные последовательности

Обратная косая черта `\` внутри строки начинает специальную последовательность:

| Запись | Значение |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\\` | сама обратная косая черта |
| `\"`, `\'` | кавычка |

```python
print("Строка 1\nСтрока 2")
print("Путь: C:\\Users\\ada")
print("Имя\tВозраст")
```

```text
Строка 1
Строка 2
Путь: C:\Users\ada
Имя	Возраст
```

Если обратных косых черт много (пути в Windows, регулярные выражения), используют **сырые строки** с префиксом `r` — в них `\` не считается специальным:

```python
print(r"C:\new\table")
```

```text
C:\new\table
```

Без `r` последовательность `\n` превратилась бы в перевод строки, а `\t` — в табуляцию.

### Многострочные строки

Тройные кавычки (`"""` или `'''`) позволяют писать текст на нескольких строках как есть:

```python
prompt = """Ты — вежливый помощник.
Отвечай кратко.
Используй русский язык."""
print(prompt)
```

```text
Ты — вежливый помощник.
Отвечай кратко.
Используй русский язык.
```

Именно так в реальных проектах записывают длинные промпты для языковых моделей.

### Пустая строка

`""` — пустая строка, в ней ноль символов. Это нормальное значение, часто используемое как начальное перед «накоплением» текста:

```python
result = ""
print("[" + result + "]")
```

```text
[]
```

## Конкатенация: склеивание строк

Оператор `+` для строк означает **склеивание** (конкатенацию):

```python
first_name = "Ада"
last_name = "Лавлейс"
full_name = first_name + " " + last_name
print(full_name)
```

```text
Ада Лавлейс
```

Пробел между словами не появляется сам: `+` склеивает строки вплотную, поэтому `" "` добавляем явно.

### Строку нельзя сложить с числом

```python
age = 36
print("Возраст: " + age)
```

Результат — `TypeError: can only concatenate str (not "int") to str`. Python не угадывает, что вы хотите: сложить числа или склеить текст. Нужно явно превратить число в строку функцией `str()`:

```python
age = 36
print("Возраст: " + str(age))
```

```text
Возраст: 36
```

Обратите внимание на разницу с `print()` через запятую: `print("Возраст:", age)` работает без `str()`, потому что `print()` сам превращает каждый аргумент в строку и ставит между ними пробел. А `+` — это операция над двумя значениями, и типы должны совпадать.

### Накопление строки

Строку можно наращивать через `+=`:

```python
log = "старт"
log += " → загрузка"
log += " → обучение"
log += " → готово"
print(log)
```

```text
старт → загрузка → обучение → готово
```

## Повторение: умножение строки на число

Оператор `*` со строкой и целым числом повторяет строку:

```python
print("ха" * 3)
print("-" * 20)
print("=" * 5 + " Отчёт " + "=" * 5)
```

```text
хахаха
--------------------
===== Отчёт =====
```

Умножение на 0 или отрицательное число даёт пустую строку. Умножать строку на дробное число или на другую строку нельзя — будет `TypeError`.

## Длина строки: len()

Встроенная функция `len()` возвращает количество символов в строке:

```python
print(len("Python"))
print(len("Привет, мир!"))
print(len(""))
print(len("  "))
print(len("a\nb"))
```

```text
6
12
0
2
3
```

Важные детали:

- пробелы и знаки препинания — тоже символы;
- `\n` в коде записан двумя знаками, но это **один** символ перевода строки;
- длина пустой строки — 0.

`len()` часто используется для «вёрстки» вывода. Например, подчеркнуть заголовок линией ровно его длины:

```python
title = "Результаты эксперимента"
print(title)
print("-" * len(title))
```

```text
Результаты эксперимента
-----------------------
```

Здесь `len(title)` вычисляется до умножения, и линия всегда совпадает с заголовком — даже если вы поменяете текст.

## Как строка устроена внутри

Строка в Python — **неизменяемая** (immutable) последовательность символов Unicode. «Неизменяемая» значит, что после создания строку нельзя поменять. Все операции (`+`, `*`) создают **новые** строки, а исходные остаются прежними:

```python
original = "data"
louder = original * 2
print(original)
print(louder)
```

```text
data
datadata
```

Каждый символ имеет свой номер в стандарте Unicode, поэтому Python одинаково работает с латиницей, кириллицей и эмодзи. Подробно о кодировках, индексах и срезах (как достать отдельный символ или кусок строки) — в блоке «Строки глубоко». Пока лишь заглянем вперёд: символ по позиции получают квадратными скобками, нумерация с нуля.

```python
word = "Python"
print(word[0])
print(word[5])
```

```text
P
n
```

### Почему важна неизменяемость

Неизменяемость делает строки безопасными: если две переменные ссылаются на одну строку, ни одна не может «испортить» её другой. Цена — при многократном `+=` в цикле Python каждый раз создаёт новую строку. Для пары сотен склеиваний это незаметно, а для миллионов есть более быстрый способ — метод `join()`, о котором вы узнаете позже.

## Строки и числа: преобразования туда и обратно

Между строками и числами постоянно приходится переводить данные. Пользователь вводит текст, файл содержит текст, API присылает текст — а считать нужно числами. И наоборот: результат вычислений нужно встроить в сообщение.

```python
count = 42
text = str(count)
print(text + "!")
print(len(text))

price_text = "199"
price = int(price_text)
print(price * 2)
print(price_text * 2)
```

```text
42!
2
398
199199
```

Сравните две последние строки: `int("199") * 2` — это арифметика (398), а `"199" * 2` — повторение строки (`199199`). Python всегда смотрит на **тип** значения, а не на то, как оно выглядит. Строка из цифр остаётся строкой, пока вы явно её не преобразуете.

Если строка не похожа на число, преобразование не удастся:

```python
print(int("сорок два"))
```

Результат — `ValueError: invalid literal for int() with base 10`. В уроке про ввод данных вы увидите эту ошибку не раз: пользователи вводят что угодно.

## Длинные строки в коде

По PEP 8 строка кода не должна быть длиннее 79–99 символов. Как быть с длинным текстом? Есть два удобных приёма.

**Соседние литералы склеиваются автоматически**, если стоят в скобках рядом:

```python
instruction = (
    "Проанализируй отзыв клиента. "
    "Определи тональность: позитивная, негативная или нейтральная. "
    "Ответь одним словом."
)
print(instruction)
print(len(instruction))
```

```text
Проанализируй отзыв клиента. Определи тональность: позитивная, негативная или нейтральная. Ответь одним словом.
111
```

Здесь нет ни одного `+`: Python склеивает строковые литералы, стоящие подряд, ещё при разборе кода. Обратите внимание на пробелы в конце кусков — без них слова слиплись бы.

**Тройные кавычки** подходят, когда переводы строк нужны в самом тексте, как в примере с промптом выше.

## Сравнение строк

Строки можно сравнивать на равенство оператором `==`. Результат — логическое значение `True` или `False` (подробно о них — в следующем блоке):

```python
print("python" == "python")
print("Python" == "python")
print("кот" == "кот ")
```

```text
True
False
False
```

Сравнение строгое: учитываются регистр каждой буквы и каждый пробел. Поэтому в реальных программах перед сравнением текст обычно **нормализуют** — приводят к одному регистру и убирают лишние пробелы. Это вы научитесь делать методами строк в блоке 1.4.

## Пример: собираем промпт для модели

Реалистичная задача AI-инженера — собрать текст запроса к языковой модели из частей:

```python
role = "Ты — эксперт по Python."
task = "Объясни, что такое переменная."
style = "Ответь в двух предложениях."
prompt = role + "\n" + task + "\n" + style
print(prompt)
print("-" * 30)
print("Длина промпта в символах:", len(prompt))
```

```text
Ты — эксперт по Python.
Объясни, что такое переменная.
Ответь в двух предложениях.
------------------------------
Длина промпта в символах: 82
```

## Разбор: оформляем строку отчёта

Ещё один практичный приём — выравнивание колонок с помощью `len()` и повторения пробела. Допустим, нужно вывести название метрики и значение так, чтобы значения стояли в одном столбце:

```python
name = "accuracy"
value = "0.93"
width = 12
print(name + " " * (width - len(name)) + value)
name = "f1"
value = "0.88"
print(name + " " * (width - len(name)) + value)
```

```text
accuracy    0.93
f1          0.88
```

Каждая строка добирается пробелами до ширины 12 символов: для `accuracy` (8 символов) — 4 пробела, для `f1` — 10. Позже вы узнаете более удобный способ — форматирование в f-строках, — но принцип «длина + заполнение» лежит в основе любых таблиц в терминале.

## Частые ошибки

**1. Склеивать строку с числом.** `"Итого: " + 100` → `TypeError`. Используйте `str(100)` или `print("Итого:", 100)`.

**2. Забыть пробелы при склейке.** `"Привет," + "мир"` даст `Привет,мир`.

**3. Путать `"5" + "5"` и `5 + 5`.** Первое — склейка (`"55"`), второе — сложение (`10`).

**4. Кавычки внутри строки.** `'It's'` обрывает строку на апострофе → `SyntaxError`. Выберите другие внешние кавычки или экранируйте: `"It's"`, `'It\'s'`.

**5. Обратная косая черта в путях.** `"C:\new"` содержит перевод строки `\n`. Пишите `r"C:\new"` или `"C:\\new"`.

**6. Умножать строку на дробное число.** `"ab" * 2.0` → `TypeError: can't multiply sequence by non-int of type 'float'`.

## Где это в AI-инженерии

- **Промпты — это строки.** Системный промпт, инструкции, примеры (few-shot) собираются из кусков текста. Тройные кавычки и склейка — ежедневные инструменты.
- **Символы ≠ токены.** `len()` считает символы, а языковые модели считают **токены** — куски слов. Английское слово часто один токен, русское — несколько. Лимиты моделей и цена запроса считаются в токенах; как их подсчитать — в части 7. Но оценка «длина в символах» полезна уже сейчас: примерно 3–4 символа английского текста на токен.
- **Контекстное окно.** Если документ слишком длинный для модели, его режут на куски (чанки) по длине — это основа RAG-систем.
- **Предобработка текста.** Перед обучением текст чистят и нормализуют: убирают лишние пробелы, приводят к одному регистру. Это строковые операции, которые вы освоите в блоке 1.4.
- **Логи и отчёты.** Разделители `"=" * 40`, выравнивание с помощью `len()` делают вывод экспериментов читаемым.

## Итоги урока

- Строка (`str`) — неизменяемая последовательность символов; кавычки `'` и `"` равноправны, `"""` — для многострочного текста.
- `\n`, `\t`, `\\` — экранированные последовательности; `r"..."` — сырая строка.
- `+` склеивает строки, `*` повторяет; строку с числом склеить нельзя без `str()`.
- `len()` возвращает число символов, включая пробелы и переводы строк.
