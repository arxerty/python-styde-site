# Шпаргалка: первые шаги

## print()

```python norun
print("текст", 42, 3.14)          # через пробел
print("a", "b", sep="-")          # a-b
print("без перевода", end="")     # следующий вывод — на той же строке
print()                           # пустая строка
```

`print()` вычисляет аргументы → превращает в строки (`str()`) → соединяет через `sep` → добавляет `end` (по умолчанию `\n`).

## Переменные

```python norun
x = 10              # присваивание: вычисли справа → привяжи имя слева
x += 5              # x = x + 5   (также -=, *=, /=)
a, b = 1, 2         # множественное присваивание
a, b = b, a         # обмен значений
x = y = 0           # цепочка
```

- Имя: буквы, цифры, `_`; не с цифры; не ключевое слово; регистр важен.
- Стиль PEP 8: `snake_case` для переменных, `UPPER_CASE` для констант.
- Тип у значения, а не у имени: `type(x)`. Имя — ярлык на объект.

## Типы

| Тип | Пример | Преобразование |
|---|---|---|
| `int` | `42`, `1_000_000` | `int("42")`, `int(3.9)` → 3 |
| `float` | `3.14`, `1e-3` | `float("2.5")` |
| `str` | `"текст"`, `'it'`, `"""…"""` | `str(42)` → `"42"` |
| `bool` | `True`, `False` | |
| `NoneType` | `None` | |

## Арифметика

| `+ - *` | `/` → всегда float | `//` целая часть | `%` остаток | `**` степень |
|---|---|---|---|---|

Приоритет: `**` → унарный `-` → `* / // %` → `+ -`. Сомневаетесь — скобки.

- `abs()`, `round(x, n)` (банковское: `round(2.5)` = 2), `min()`, `max()`, `divmod(a, b)`.
- `0.1 + 0.2 != 0.3` → сравнивайте `abs(a - b) < 1e-9`.

## Строки

```python norun
"a" + "b"      # "ab"   склейка (только str + str)

len("Привет")  # 6
"\n" "\t" "\\" # перевод строки, табуляция, обратная черта
r"C:\new"      # сырая строка
word[0]        # первый символ
```

## Ввод

```python norun
name = input("Имя: ")          # всегда str!
age = int(input("Возраст: "))   # преобразование сразу
price = float(input("Цена: "))  # дробная часть — через точку
```

## Ошибки

| Ошибка | Причина |
|---|---|
| `SyntaxError` | нарушен синтаксис — ничего не выполняется |
| `IndentationError` | лишний/неверный отступ |
| `NameError` | имя не определено (опечатка, использование до присваивания) |
| `TypeError` | неподходящий тип: `"a" + 1` |
| `ValueError` | неподходящее значение: `int("abc")` |
| `ZeroDivisionError` | деление на ноль |

**Traceback читают снизу вверх:** тип и сообщение → строка кода → номер строки.

**Отладка:** `print(x, type(x))` перед проблемной строкой, одна гипотеза — одно изменение.

## Частые ошибки

- `print` вместо `Print`; текст без кавычек → `NameError`.
- `input()` без `int()` → склейка вместо сложения.
- `a + b + c / 3` вместо `(a + b + c) / 3`.
- `"Итого: " + 100` → `TypeError`; используйте `str()` или запятую в print.
- Комментарий `#` объясняет «почему», а не «что».
