# Ввод данных и преобразование типов

## Программа, которая слушает

До сих пор наши программы делали одно и то же при каждом запуске: все данные были записаны прямо в коде. Настоящие программы получают данные **извне**: от пользователя, из файла, по сети. Самый простой источник — клавиатура.

Почти любая программа устроена по схеме **ввод → обработка → вывод**:

1. **Ввод** — получить данные (цена, имя, текст вопроса).
2. **Обработка** — вычислить что-то на их основе.
3. **Вывод** — показать результат.

Эта схема масштабируется до самых сложных систем. Чат-бот на базе LLM работает так же: ввод — сообщение пользователя, обработка — запрос к модели, вывод — ответ.

## Функция input()

`input()` останавливает программу и ждёт, пока пользователь введёт строку и нажмёт Enter. Введённый текст функция **возвращает** — его можно сохранить в переменную:

```python
name = input("Как вас зовут? ")
print("Привет,", name)
```

Строка в скобках — **приглашение** (prompt): текст, который показывается перед вводом. Он необязателен, но делает программу понятнее. Обратите внимание на пробел в конце приглашения — без него ввод прилипнет к знаку вопроса.

На этой платформе при запуске программ с `input()` появляется поле «Ввод»: каждая его строка отдаётся очередному вызову `input()` по порядку. Попробуйте запустить пример выше, вписав имя в поле.

### Как работает input() внутри

1. Выводит приглашение (без перевода строки).
2. Ждёт, пока в стандартный поток ввода (stdin) придёт строка, заканчивающаяся переводом строки.
3. Отбрасывает этот последний перевод строки.
4. Возвращает остальное как значение типа `str`.

Пункт 4 — самый важный в уроке: **`input()` всегда возвращает строку**. Даже если пользователь ввёл `42`, программа получит текст `"42"`, а не число.

```python
value = input()
print(type(value))
```

Запустите и введите `42` — увидите `<class 'str'>`.

## Ловушка: строка вместо числа

Посмотрите, что будет, если забыть о типе:

```python
a = input("Первое число: ")
b = input("Второе число: ")
print("Сумма:", a + b)
```

Введите `2` и `3` — получите `Сумма: 23`. Python не ошибся: он **склеил** две строки `"2"` и `"3"`. А если попробовать `a + 1`, будет `TypeError`: строку и число сложить нельзя.

## Преобразование типов

Чтобы считать, строку нужно явно превратить в число. Для этого используют функции с именами типов:

| Функция | Что делает | Пример | Результат |
|---|---|---|---|
| `int(x)` | в целое число | `int("42")` | `42` |
| `float(x)` | в дробное число | `float("3.5")` | `3.5` |
| `str(x)` | в строку | `str(42)` | `"42"` |

Исправленная программа:

```python
a = int(input("Первое число: "))
b = int(input("Второе число: "))
print("Сумма:", a + b)
```

Запись `int(input(...))` читается изнутри наружу: сначала `input()` получает строку, затем `int()` превращает её в число. Это одна из самых частых конструкций в учебных программах.

### Что умеет int()

```python
print(int("42"))
print(int("-17"))
print(int("  8  "))
print(int("007"))
print(int(3.99))
print(int(-3.99))
```

```text
42
-17
8
7
3
-3
```

- Пробелы по краям игнорируются.
- Ведущие нули не мешают.
- Из `float` берётся целая часть (отбрасывается к нулю, а не округляется).

Чего `int()` **не** умеет — превращать строку с дробной частью:

```python
print(int("3.5"))
```

Получится `ValueError: invalid literal for int() with base 10: '3.5'`. Если нужно целое из такой строки, преобразуйте в два шага: `int(float("3.5"))` → `3`.

### Что умеет float()

```python
print(float("3.14"))
print(float("10"))
print(float("1e-3"))
print(float(" -2.5 "))
```

```text
3.14
10.0
0.001
-2.5
```

Дробная часть отделяется **точкой**, а не запятой. Строка `"3,14"` вызовет `ValueError` — частая проблема с русскоязычными пользователями. В блоке про строки вы научитесь заменять запятую на точку методом `replace()`.

### str() и обратное преобразование

`str()` превращает что угодно в строку — нужно для склейки через `+`:

```python
score = 0.875
message = "Точность: " + str(score)
print(message)
print(len(str(12345)))
```

```text
Точность: 0.875
5
```

Второй пример — популярный трюк: количество цифр в числе можно узнать через длину его строкового представления.

### Неявные и явные преобразования

Python сам преобразует типы только в «безопасных» случаях — например, `int` в `float` при смешанной арифметике (`2 + 0.5` = `2.5`), ведь ничего не теряется. Между строками и числами он **никогда** не преобразует неявно: слишком велик риск ошибиться в намерениях программиста. Такую типизацию называют **строгой**: Python динамический (тип у значения, а не у имени), но строгий (типы не смешиваются «как-нибудь»).

Сравните с JavaScript, где `"5" + 1` даёт `"51"`, а `"5" - 1` даёт `4`. В Python оба выражения — ошибка, и это хорошо: ошибка видна сразу, а не прячется в неверных данных.

## Несколько значений

Каждый вызов `input()` читает **одну строку**. Чтобы получить три числа, вызывают `input()` три раза:

```python
length = float(input("Длина: "))
width = float(input("Ширина: "))
height = float(input("Высота: "))
volume = length * width * height
print("Объём:", round(volume, 2))
```

Если пользователь вводит несколько значений в одной строке через пробел, их разбивают методом `split()` — его вы детально изучите в блоке «Строки глубоко»:

```python
a, b = input("Два числа через пробел: ").split()
print(int(a) + int(b))
```

## Разбор задачи: калькулятор скидки

Напишем программу полностью: пользователь вводит цену товара и процент скидки, программа выводит итоговую цену и сумму экономии.

```python
price = float(input("Цена: "))
discount = float(input("Скидка, %: "))

saving = price * discount / 100
final_price = price - saving

print("Экономия:", round(saving, 2))
print("К оплате:", round(final_price, 2))
```

При вводе `2500` и `15` программа выведет:

```text
Экономия: 375.0
К оплате: 2125.0
```

Обратите внимание на структуру: блок ввода, блок вычислений, блок вывода, разделённые пустыми строками. Такой код легко читать и легко менять: захотите читать данные из файла — поменяется только первый блок.

## Как проверяются программы с вводом

Полезно понимать, как платформа (и любые автоматические тесты) проверяет ваши программы с `input()`. Человек за клавиатурой тестам не нужен: программе подают заранее подготовленный текст, как будто его ввели с клавиатуры. Каждая строка этого текста — ответ на очередной вызов `input()`.

Например, для программы сложения тест может выглядеть так:

| Ввод (stdin) | Ожидаемый вывод (stdout) |
|---|---|
| `2` и `3` на отдельных строках | `Сумма: 5` |
| `-4` и `4` | `Сумма: 0` |
| `1000000` и `1` | `Сумма: 1000001` |

Отсюда несколько практических правил:

- **Вывод должен совпадать посимвольно.** Лишнее слово, другой знак препинания или пропущенный пробел — и тест не пройдёт, даже если вычисление верное. Внимательно читайте формат в условии.
- **Приглашения в `input()` при проверке не учитываются.** Можно писать `input("Цена: ")` — тест сравнит только то, что вывел `print()`.
- **Порядок ввода важен.** Если в условии сначала вводится ширина, а потом высота, читайте именно в таком порядке.
- **Программа должна работать для любых корректных данных**, а не только для примера из условия. Скрытые тесты проверяют граничные случаи: ноль, отрицательные числа, очень большие значения.

В реальной разработке так же устроены тесты консольных утилит: на вход подаётся текст, на выходе сравнивается текст. А ещё стандартные потоки можно перенаправлять в терминале — `python app.py < input.txt` подаст содержимое файла вместо клавиатуры.

## Валидация: что, если ввели не то?

Пользователи вводят что угодно: буквы вместо цифр, пустую строку, запятую вместо точки. Сейчас наша программа на таком вводе упадёт с `ValueError`. Это нормально для учебного кода, но в реальных программах ввод **проверяют** (валидируют). Инструменты для этого — условия (следующий блок) и обработка исключений `try/except` (блок 1.7). Запомните принцип: **никогда не доверяйте вводу**. В AI-приложениях это правило станет ещё важнее — вплоть до защиты от prompt injection в части 8.

## Частые ошибки

**1. Забыть преобразовать ввод.** `input()` — всегда строка: `"2" + "3"` = `"23"`, а `"5" * 3` = `"555"`.

**2. `int()` от дробной строки.** `int("2.5")` → `ValueError`. Используйте `float()` или `int(float(...))`.

**3. Запятая в дробных числах.** `float("2,5")` → `ValueError`. Python понимает только точку.

**4. Преобразовать не то.** `int(input)` без скобок у `input` → `TypeError`: вы передали саму функцию, а не результат её вызова.

**5. Лишний вызов input().** Каждый вызов ждёт новую строку. Если написать `input()` дважды, программа попросит ввод дважды.

**6. Ожидать, что `bool("False")` даст `False`.** Любая непустая строка превращается в `True` — даже `"False"` и `"0"`. Подробно — в следующем блоке.

## Где это в AI-инженерии

- **Консольный чат-бот.** В части 7 вы напишете бота, который в цикле читает `input("Вы: ")`, отправляет сообщение языковой модели и печатает ответ. Начало ровно такое же, как в этом уроке.
- **Всё снаружи — строки.** Данные из CSV-файлов, переменные окружения с API-ключами и настройками, ответы веб-API — приходят текстом. Преобразование `int()`/`float()` — первый шаг их обработки. Например, `max_tokens = int(os.environ["MAX_TOKENS"])`.
- **Парсинг ответов модели.** Если попросить LLM вернуть оценку от 1 до 10, она вернёт строку `"7"` — а иногда `"Оценка: 7"`. Преобразование и валидация ответов модели — важная часть AI-инженерии, для этого есть structured output и Pydantic (часть 2).
- **Гиперпараметры из командной строки.** Скрипты обучения принимают `--lr 0.001 --epochs 10` — это строки, которые преобразуются в числа.
- **Интерактивная разметка данных.** Простейший инструмент разметки — консольная программа, которая показывает текст отзыва и ждёт ввода метки: `label = input("Тональность (1 — позитив, 0 — негатив): ")`. Так часто начинают собирать первые сотни примеров для датасета, прежде чем подключать полноценные сервисы разметки. И здесь тоже нужна проверка: человек может ошибиться клавишей.

## Итоги урока

- `input(prompt)` выводит приглашение и возвращает введённую строку — **всегда `str`**.
- `int()`, `float()`, `str()` явно преобразуют значения; неверная строка вызывает `ValueError`.
- `int()` не принимает `"3.5"`; `float()` не принимает запятую.
- Python строго типизирован: строки и числа не смешиваются неявно.
- Схема программы: ввод → обработка → вывод.
