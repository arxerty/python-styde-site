# Числа: int, float и арифметика

## Два основных числовых типа

Машинное обучение — это в первую очередь вычисления: взвешенные суммы, градиенты, вероятности, метрики. Поэтому уверенная работа с числами — фундамент всего курса.

В Python два основных числовых типа:

- **`int`** (integer) — целые числа: `0`, `42`, `-7`, `1000000`;
- **`float`** (floating point) — числа с плавающей точкой, то есть дробные: `3.14`, `-0.5`, `2.0`.

```python
print(type(10))
print(type(10.0))
print(type(-3))
print(type(0.001))
```

```text
<class 'int'>
<class 'float'>
<class 'int'>
<class 'float'>
```

Обратите внимание: `10` и `10.0` — разные типы, хотя математически это одно и то же число. Точка в записи делает число дробным.

### Удобные формы записи

Длинные числа можно разбивать подчёркиванием — Python его игнорирует, а читать становится проще:

```python
population = 8_100_000_000
params = 175_000_000_000
print(population)
print(params)
```

```text
8100000000
175000000000
```

Очень большие и очень маленькие дробные числа удобно писать в **научной нотации**: `e` означает «умножить на 10 в степени»:

```python
learning_rate = 3e-4
big = 1.5e6
print(learning_rate)
print(big)
```

```text
0.0003
1500000.0
```

`3e-4` = 3 × 10⁻⁴ = 0.0003. Такая запись повсеместна в ML: скорости обучения `1e-3`, `3e-4`, малые константы `1e-8`.

## Арифметические операторы

| Оператор | Действие | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3.5` |
| `//` | целочисленное деление | `7 // 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |
| `**` | возведение в степень | `7 ** 2` | `49` |

### Обычное деление всегда даёт float

```python
print(10 / 2)
print(9 / 3)
print(7 / 2)
```

```text
5.0
3.0
3.5
```

Даже если делится нацело, результат `/` — `float`. Это сделано специально: тип результата не зависит от конкретных чисел, и программа ведёт себя предсказуемо.

### Целочисленное деление и остаток

`//` отбрасывает дробную часть (точнее, округляет вниз), `%` даёт остаток. Вместе они отвечают на вопрос «сколько раз поместится и сколько останется»:

```python
total_minutes = 135
hours = total_minutes // 60
minutes = total_minutes % 60
print(hours, "ч", minutes, "мин")
```

```text
2 ч 15 мин
```

Остаток `%` — неожиданно полезный инструмент:

- `n % 2 == 0` — проверка чётности;
- `n % 10` — последняя цифра числа;
- `n // 10` — число без последней цифры;
- `step % 100 == 0` — «каждый сотый шаг» (так в ML решают, когда печатать лог или сохранять модель).

```python
number = 4721
print(number % 10)
print(number // 10)
print(number // 10 % 10)
```

```text
1
472
2
```

Функция `divmod()` возвращает обе части сразу:

```python
print(divmod(135, 60))
```

```text
(2, 15)
```

> **Отрицательные числа.** `//` округляет **вниз** (к минус бесконечности), а не к нулю: `-7 // 2` равно `-4`, а `-7 % 2` равно `1`. Python выбирает остаток так, чтобы выполнялось `(a // b) * b + (a % b) == a`. На практике это редко важно, но знать полезно.

```python
print(-7 // 2, -7 % 2)
```

```text
-4 1
```

### Возведение в степень

```python
print(2 ** 10)
print(9 ** 0.5)
print(10 ** -2)
```

```text
1024
3.0
0.01
```

Степень `0.5` — это квадратный корень. Отрицательная степень — деление: `10 ** -2` = 1/100.

## Приоритет операций

Как и в математике, операции выполняются не просто слева направо, а по приоритету — от высшего к низшему:

1. `**` — степень;
2. унарный минус: `-x`;
3. `*`, `/`, `//`, `%`;
4. `+`, `-`.

Операции одного уровня выполняются слева направо (кроме `**` — она справа налево). Скобки меняют порядок.

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 ** 3 ** 2)
print(-3 ** 2)
```

```text
14
20
512
-9
```

Последние две строки — ловушки. `2 ** 3 ** 2` = `2 ** 9` = 512, потому что степень вычисляется справа налево. А `-3 ** 2` = `-(3 ** 2)` = -9: степень старше унарного минуса. Если нужен квадрат отрицательного числа, пишите `(-3) ** 2`.

> **Правило инженера:** если сомневаетесь в порядке — ставьте скобки. Они ничего не стоят и делают формулу очевидной для читателя.

## Смешивание int и float

Если в операции участвуют `int` и `float`, результат — `float`:

```python
print(3 + 0.5)
print(2 * 1.0)
print(type(10 - 4.0))
```

```text
3.5
2.0
<class 'float'>
```

## Встроенные функции для чисел

```python
print(abs(-12))
print(round(3.14159, 2))
print(round(7.6))
print(min(4, 9, 1))
print(max(4, 9, 1))
print(int(7.9))
print(float(5))
```

```text
12
3.14
8
1
9
7
5.0
```

- `abs(x)` — модуль числа;
- `round(x, n)` — округление до `n` знаков после запятой; без `n` — до целого (результат `int`);
- `min()` / `max()` — минимум и максимум из нескольких чисел;
- `int(x)` — превращает в целое, **отбрасывая** дробную часть (не округляя!): `int(7.9)` = 7, `int(-7.9)` = -7;
- `float(x)` — превращает в дробное.

### Особенность round: банковское округление

```python
print(round(0.5), round(1.5), round(2.5), round(3.5))
```

```text
0 2 2 4
```

Сюрприз: `round(2.5)` даёт `2`, а не `3`. Python использует **банковское округление**: число ровно посередине округляется к ближайшему **чётному**. Так при суммировании многих округлений ошибки не накапливаются в одну сторону. В финансовых и статистических расчётах это стандарт.

## Внутри float: почему 0.1 + 0.2 ≠ 0.3

Попробуйте:

```python
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
```

```text
0.30000000000000004
False
```

Это не ошибка Python — так ведут себя дробные числа почти во всех языках. Компьютер хранит `float` в **двоичной** системе по стандарту IEEE 754 (64 бита: знак, порядок и мантисса). Число 0.1 в двоичной системе — бесконечная периодическая дробь, как 1/3 = 0.333… в десятичной. Её приходится обрезать, и возникает крошечная погрешность.

Практические следствия:

1. **Не сравнивайте float через `==`.** Проверяйте, что разница достаточно мала: `abs(a - b) < 1e-9`.
2. **Деньги не храните во float** — используйте целые копейки или модуль `decimal`.
3. **Точность float — около 15–16 значащих цифр.** Для большинства вычислений этого достаточно.

```python
a = 0.1 + 0.2
b = 0.3
print(abs(a - b) < 1e-9)
```

```text
True
```

### А int — бесконечный

В отличие от многих языков, `int` в Python не переполняется: он растёт, пока хватает памяти.

```python
print(2 ** 100)
```

```text
1267650600228229401496703205376
```

У `float` же есть предел (около 1.8 × 10³⁰⁸), и очень маленькие числа превращаются в ноль. В ML это реальная проблема: произведение тысяч вероятностей быстро становится 0.0. Решение — работать с логарифмами, о чём вы узнаете в блоке про вероятности.

## Пример: формула из жизни

Сложные проценты: сумма через `years` лет при ставке `rate` процентов годовых:

```python
principal = 100_000
rate = 12
years = 5
amount = principal * (1 + rate / 100) ** years
print(round(amount, 2))
```

```text
176234.17
```

Порядок вычисления: `rate / 100` → `1 + …` → `… ** years` → `principal * …`. Скобки вокруг `1 + rate / 100` обязательны: без них степень применилась бы только к `rate / 100`.

## Разбор задачи: сколько батчей в эпохе

Соберём всё вместе на типичной задаче из машинного обучения. Модель обучают на 10 450 примерах, подавая их порциями (батчами) по 64 штуки. Вопросы: сколько будет полных батчей, сколько примеров попадёт в последний неполный батч и сколько всего шагов обучения займёт одна эпоха?

```python
num_samples = 10_450
batch_size = 64

full_batches = num_samples // batch_size
last_batch = num_samples % batch_size
steps_per_epoch = full_batches + (1 if last_batch else 0)

print("Полных батчей:", full_batches)
print("В последнем батче:", last_batch)
print("Шагов за эпоху:", steps_per_epoch)
```

```text
Полных батчей: 163
В последнем батче: 18
Шагов за эпоху: 164
```

Разберём по шагам:

1. `10450 // 64` — сколько раз 64 целиком помещается в 10 450: 163 раза (163 × 64 = 10 432).
2. `10450 % 64` — сколько осталось: 10 450 − 10 432 = 18 примеров.
3. Если остаток не нулевой, нужен ещё один (неполный) шаг. Конструкцию `1 if last_batch else 0` вы подробно разберёте в следующем блоке; пока прочитайте её как «1, если остаток есть, иначе 0».

Есть и чисто арифметический приём «деления с округлением вверх», который часто встречается в коде:

```python
num_samples = 10_450
batch_size = 64
steps = (num_samples + batch_size - 1) // batch_size
print(steps)
```

```text
164
```

Добавив `batch_size - 1` перед целочисленным делением, мы «подталкиваем» любой ненулевой остаток до следующего целого. Попробуйте подставить `num_samples = 10_432` (делится нацело) — получится ровно 163.

## Преобразования между типами

Иногда нужно явно превратить число одного типа в другой:

```python
print(int(3.99))
print(int(-3.99))
print(float(7))
print(int("42") + 1)
print(float("2.5") * 2)
```

```text
3
-3
7.0
43
5.0
```

`int()` и `float()` умеют превращать в числа и строки с цифрами — это пригодится в уроке про ввод данных, ведь всё, что вводит пользователь, приходит строкой. `int()` у дробного числа отбрасывает дробную часть «к нулю»: у положительных — вниз, у отрицательных — вверх.

## Частые ошибки

**1. Ожидать целое от `/`.** `10 / 2` — это `5.0`, а не `5`. Если нужно целое — `//`.

**2. Забыть приоритет.**

```python
average = 10 + 20 + 30 / 3
print(average)
```

```text
40.0
```

Хотели среднее (20), а получили 10 + 20 + 10. Правильно: `(10 + 20 + 30) / 3`.

**3. Сравнивать float через `==`.** `0.1 + 0.2 == 0.3` — `False`. Сравнивайте с допуском.

**4. Путать `int()` и `round()`.** `int(2.9)` = 2 (отбрасывает), `round(2.9)` = 3 (округляет).

**5. Деление на ноль.**

```python
print(5 / 0)
```

Результат — `ZeroDivisionError`. Перед делением на значение, которое может быть нулём, его нужно проверять (как — в следующем блоке).

**6. `-x ** 2`.** Это `-(x ** 2)`, а не `(-x) ** 2`.

## Где это в AI-инженерии

- **Нормализация данных.** Признаки приводят к одному масштабу формулой `(x - mean) / std` — здесь важны скобки и float-деление.
- **Функции потерь.** Среднеквадратичная ошибка — это `(prediction - target) ** 2`, усреднённая по примерам.
- **Батчи.** Число батчей в эпохе — `num_samples // batch_size`, а размер последнего неполного батча — `num_samples % batch_size`.
- **Логирование.** `if step % 100 == 0:` — печатать метрики каждые 100 шагов.
- **Точность float.** Нейросети обучают во float32 и даже float16/bfloat16 — числах с ещё меньшей точностью, чем float в Python. Отсюда проблемы «взрывающихся» и «исчезающих» градиентов и трюки вроде добавления `1e-8` в знаменатель, чтобы не делить на ноль.
- **Подсчёт стоимости LLM.** Цена запроса = `tokens / 1_000_000 * price_per_million`, а затем `round(cost, 4)`.

## Итоги урока

- `int` — целые, `float` — дробные; `/` всегда даёт float, `//` и `%` — целую часть и остаток.
- Приоритет: `**` → унарный минус → `* / // %` → `+ -`. Сомневаетесь — ставьте скобки.
- float хранится в двоичном виде с погрешностью: сравнивайте с допуском.
- `round()` использует банковское округление, `int()` отбрасывает дробную часть.
