# Переменные и присваивание

## Зачем нужны переменные

В прошлом уроке мы печатали готовые значения. Но настоящая программа работает с данными, которые меняются: цена товара, количество пользователей, ответ нейросети, точность модели после очередной эпохи обучения. Чтобы работать с такими данными, им нужно дать **имя**.

**Переменная** — это имя, привязанное к значению. Через имя программа может получить значение, использовать его в вычислениях и заменить на новое.

```python
price = 250
print(price)
print(price * 3)
```

```text
250
750
```

Имя `price` теперь обозначает число `250`. Везде, где Python встречает `price`, он подставляет текущее значение.

## Присваивание

Строка `price = 250` называется **присваиванием**. Знак `=` в Python — это не «равно» из математики, а команда: «вычисли то, что справа, и привяжи результат к имени слева».

Порядок действий всегда такой:

1. Вычисляется правая часть.
2. Результат связывается с именем слева.

Поэтому возможна строка, которая в математике была бы абсурдом:

```python
counter = 10
counter = counter + 1
print(counter)
```

```text
11
```

Разберём вторую строку: сначала вычисляется `counter + 1` — это `10 + 1 = 11`. Затем имя `counter` привязывается к новому значению `11`. Старое значение забыто.

> Читайте `x = 5` как «x **получает** 5» или «x теперь указывает на 5», а не «x равно 5». Для сравнения на равенство в Python есть отдельный оператор `==` — о нём в блоке про условия.

### Переприсваивание

Переменную можно сколько угодно раз привязать к новому значению. Каждый раз действует последнее присваивание:

```python
status = "загрузка"
print(status)
status = "обучение"
print(status)
status = "готово"
print(status)
```

```text
загрузка
обучение
готово
```

### Составное присваивание

Изменить значение «относительно себя» приходится так часто, что для этого есть сокращения:

| Запись | Полная форма |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 2` | `x = x - 2` |
| `x *= 3` | `x = x * 3` |
| `x /= 4` | `x = x / 4` |

```python
loss = 1.0
loss *= 0.5
loss *= 0.5
print(loss)

steps = 0
steps += 100
steps += 100
print(steps)
```

```text
0.25
200
```

### Несколько присваиваний в одной строке

Python позволяет присвоить сразу несколько переменных — значения сопоставляются по порядку:

```python
width, height = 1920, 1080
print(width, height)
```

```text
1920 1080
```

Это удобно для знаменитого трюка — **обмена значениями** без временной переменной:

```python
a = "левый"
b = "правый"
a, b = b, a
print(a, b)
```

```text
правый левый
```

Как это работает: сначала полностью вычисляется правая часть — пара значений `("правый", "левый")`, и лишь затем они раскладываются по именам `a` и `b`. Поэтому ничего не теряется.

Одно значение нескольким именам можно присвоить цепочкой:

```python
x = y = z = 0
print(x, y, z)
```

```text
0 0 0
```

## Как это устроено внутри: имена и объекты

Важная идея, которая сэкономит вам часы отладки в будущем. Во многих учебниках переменную сравнивают с «коробкой», в которую кладут значение. В Python точнее другая метафора: переменная — это **ярлык (бирка)**, привязанный к объекту.

Каждое значение в Python — это **объект** в памяти. У объекта есть тип (число, строка…), значение и уникальный номер (`id`). Имя лишь ссылается на объект.

```python
a = 1000
b = a
print(id(a) == id(b))
```

```text
True
```

`b = a` не копирует число — теперь два ярлыка висят на одном и том же объекте. Для чисел и строк это не заметно, потому что их нельзя изменить «на месте». Но в блоке про коллекции вы увидите списки, где эта разница становится критичной: изменение через одно имя будет видно через другое.

Когда мы пишем `a = a + 1`, Python создаёт **новый** объект с результатом и перевешивает ярлык `a` на него.

## Правила имён

Имена переменных подчиняются строгим правилам:

- состоят из букв, цифр и символа подчёркивания `_`;
- **не начинаются с цифры**: `model2` — можно, `2model` — нельзя;
- не содержат пробелов и дефисов: `learning rate` и `learning-rate` — ошибки;
- **регистр важен**: `Score`, `score` и `SCORE` — три разных имени;
- нельзя использовать **ключевые слова** языка.

Ключевые слова — зарезервированные слова Python. Их немного, и вы выучите их по ходу курса:

```python
import keyword
print(keyword.kwlist)
```

Среди них `if`, `for`, `while`, `def`, `class`, `return`, `True`, `False`, `None`, `import`, `and`, `or`, `not`, `in`, `is`, `lambda`. Попытка назвать так переменную даст `SyntaxError`.

### Соглашения (PEP 8)

Кроме правил, есть **соглашения** — то, как принято писать в сообществе. Их описывает документ PEP 8:

- переменные — `snake_case`: строчные буквы, слова через подчёркивание: `user_name`, `batch_size`, `max_tokens`;
- константы (значения, которые не должны меняться) — `UPPER_CASE`: `MAX_RETRIES = 3`, `API_URL = "..."`;
- имена — **говорящие**: `temperature` лучше, чем `t`; `num_users` лучше, чем `n2`.

Технически Python примет и `userName`, и `x1`, но код читают люди. Хорошие имена — половина документации.

```python
# Плохо: непонятно, что это
a = 0.001
b = 32
c = 10

# Хорошо: читается без комментариев
learning_rate = 0.001
batch_size = 32
num_epochs = 10
```

## Динамическая типизация

У каждого значения есть **тип**. Узнать его помогает функция `type()`:

```python
print(type(42))
print(type(3.14))
print(type("текст"))
print(type(True))
```

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

Основные типы, с которых всё начинается:

| Тип | Что хранит | Пример |
|---|---|---|
| `int` | целые числа | `42`, `-7`, `0` |
| `float` | дробные числа | `3.14`, `0.001`, `-2.5` |
| `str` | текст (строку) | `"привет"`, `'gpt-4'` |
| `bool` | логическое значение | `True`, `False` |

В Python тип принадлежит **значению**, а не имени. Имя можно перепривязать к значению другого типа — это называется **динамической типизацией**:

```python
data = 42
print(type(data))
data = "сорок два"
print(type(data))
```

```text
<class 'int'>
<class 'str'>
```

В языках со статической типизацией (Java, C++, Go) так нельзя: переменная объявляется с типом навсегда. Динамическая типизация делает Python гибким и быстрым для экспериментов, но требует внимательности: Python не предупредит заранее, что в переменной оказалось не то, что вы ждали. Ошибка проявится только при выполнении. Позже, в части 2, вы научитесь добавлять **аннотации типов** и проверять их инструментами — так делают в серьёзных проектах.

### Специальное значение None

`None` означает «ничего, значение отсутствует». Его используют, когда переменная должна существовать, но значения пока нет:

```python
best_score = None
print(best_score)
print(type(best_score))
```

```text
None
<class 'NoneType'>
```

## Трассировка: выполняем программу «в уме»

Профессиональный навык, который стоит тренировать с первого дня, — **трассировка**: мысленно пройти программу строка за строкой и записывать значения переменных. Так вы находите ошибки ещё до запуска и отвечаете на вопросы «что выведет код?».

Возьмём программу:

```python
tokens = 120
price = 2
cost = tokens * price
tokens += 30
cost = cost + tokens * price
print(tokens, cost)
```

Составим таблицу: после каждой строки — текущие значения.

| Строка | `tokens` | `price` | `cost` |
|---|---|---|---|
| `tokens = 120` | 120 | — | — |
| `price = 2` | 120 | 2 | — |
| `cost = tokens * price` | 120 | 2 | 240 |
| `tokens += 30` | 150 | 2 | 240 |
| `cost = cost + tokens * price` | 150 | 2 | 540 |

Вывод: `150 540`. Обратите внимание на строку 4: изменение `tokens` **не пересчитывает** `cost` автоматически. Переменная `cost` хранит результат, вычисленный в момент присваивания, а не формулу. Это частое заблуждение новичков, пришедших из Excel, где ячейки с формулами пересчитываются сами.

```python
a = 5
b = a * 2
a = 100
print(b)
```

```text
10
```

`b` получила значение `10` в момент присваивания и больше не связана с `a`.

## Значение по шагам: что происходит в памяти

Посмотрим, как меняются ярлыки при работе со строками:

```python
greeting = "Привет"
copy = greeting
greeting = greeting + "!"
print(copy)
print(greeting)
```

```text
Привет
Привет!
```

1. Создаётся объект-строка `"Привет"`, на него вешается ярлык `greeting`.
2. `copy = greeting` — на **тот же** объект вешается второй ярлык.
3. `greeting + "!"` создаёт **новую** строку `"Привет!"`, и ярлык `greeting` перевешивается на неё.
4. Ярлык `copy` по-прежнему висит на старой строке.

Строки нельзя изменить «на месте», поэтому любые операции создают новые объекты, и такие сюрпризы безопасны. Запомните картинку с ярлыками — она понадобится в блоке про списки.

## Частые ошибки

**1. Использовать переменную до присваивания.**

```python
print(total)
total = 100
```

Код выполняется сверху вниз: на первой строке имени `total` ещё не существует → `NameError: name 'total' is not defined`.

**2. Опечатка в имени.**

```python
accuracy = 0.95
print(acuracy)
```

Для Python `acuracy` — совершенно другое имя → `NameError`. Именно поэтому говорящие и аккуратные имена так важны.

**3. Перепутать стороны присваивания.**

```python
10 = x
```

Слева всегда имя, справа — значение. Здесь будет `SyntaxError`.

**4. Затереть встроенную функцию.**

```python
print = "текст"
print("привет")
```

Теперь имя `print` указывает на строку, а не на функцию → `TypeError: 'str' object is not callable`. Не называйте переменные `print`, `type`, `len`, `list`, `str`, `input`, `sum`, `max`, `min`.

**5. Недопустимые имена.** `my-var`, `2nd_model`, `learning rate`, `class` — всё это вызовет ошибки синтаксиса.

## Где это в AI-инженерии

- **Гиперпараметры.** Обучение модели начинается с набора переменных: `learning_rate = 3e-4`, `batch_size = 64`, `num_epochs = 20`, `dropout = 0.1`. Понятные имена здесь — не прихоть: по ним вы и коллеги будете сравнивать эксперименты.
- **Параметры генерации LLM.** При вызове языковой модели задают `temperature = 0.7`, `max_tokens = 500`, `model = "..."`. Это обычные переменные, которые передаются в API.
- **Константы конфигурации.** `MODEL_NAME`, `MAX_RETRIES`, `TIMEOUT_SECONDS` пишут в верхнем регистре, чтобы было видно: это настройка, её не меняют по ходу программы.
- **Счётчики и накопители.** Во время обучения суммируют loss по батчам (`total_loss += loss`), считают шаги (`step += 1`). Составное присваивание вы будете писать постоянно.
- **Ссылочная модель.** Понимание «имя — ярлык на объект» критично для работы с тензорами в PyTorch и массивами NumPy: многие операции не копируют данные, и изменение через одно имя меняет «другую» переменную.

## Итоги урока

- Переменная — имя, привязанное к объекту; `=` сначала вычисляет правую часть, потом привязывает имя.
- `+=`, `-=`, `*=`, `/=` — сокращения для изменения «относительно себя».
- `a, b = b, a` — обмен значений.
- Имена: буквы, цифры, `_`, не с цифры, не ключевые слова; стиль — `snake_case`.
- Тип принадлежит значению; `type()` его показывает; имя можно перепривязать к значению другого типа.
