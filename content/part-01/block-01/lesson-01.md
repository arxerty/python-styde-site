# Что такое Python и программирование

## Программа — это инструкция для исполнителя

Компьютер не умеет «догадываться». Он выполняет ровно то, что ему сказали, шаг за шагом, очень быстро и без усталости. **Программа** — это последовательность таких инструкций, записанная на языке, который компьютер может понять.

Представьте рецепт: «налей воду, вскипяти, положи пасту, вари 9 минут». Повар выполняет шаги по порядку. Если в рецепте написано «положи пасту» раньше, чем «налей воду», повар так и сделает — и получится ерунда. С программами то же самое: порядок важен, и каждая инструкция должна быть однозначной.

**Программирование** — это умение разбить задачу на такие однозначные шаги и записать их на языке программирования.

## Почему именно Python

Python — язык общего назначения, созданный Гвидо ван Россумом в 1991 году. Его главная идея — код читается почти как английский текст:

```python
print("Привет, мир!")
```

Этого одного выражения достаточно, чтобы программа заработала. В других языках для того же нужно несколько строк служебного кода.

Почему Python стал главным языком AI и машинного обучения:

- **Простой синтаксис.** Исследователи и инженеры думают о задаче, а не о технических деталях языка.
- **Огромная экосистема библиотек.** NumPy, pandas, scikit-learn, PyTorch, Hugging Face Transformers, SDK для OpenAI и Anthropic — всё это Python.
- **Интерактивность.** Можно выполнить строчку, посмотреть результат и сразу продолжить — идеально для экспериментов с данными.
- **Сообщество.** На любой вопрос уже есть ответ, а на любую задачу — библиотека.

Почти каждая нейросеть, о которой вы слышали — от GPT до Stable Diffusion, — обучалась кодом на Python.

## Как выполняется код

Компьютер на самом деле понимает только машинные команды — последовательности нулей и единиц для процессора. Писать так людям неудобно, поэтому придумали языки высокого уровня, а между ними и процессором поставили «переводчика».

У Python этот переводчик называется **интерпретатор**. Когда вы запускаете программу, происходит следующее:

1. Интерпретатор читает ваш файл с кодом (обычно с расширением `.py`).
2. Проверяет, что код написан по правилам языка (синтаксис). Если нет — сразу сообщает об ошибке и ничего не выполняет.
3. Переводит код в промежуточное представление — **байт-код**.
4. Выполняет байт-код **строка за строкой, сверху вниз**.

Пункт 4 — самое важное для начала. Python выполняет инструкции по порядку:

```python
print("Шаг 1: открываем файл")
print("Шаг 2: читаем данные")
print("Шаг 3: обучаем модель")
```

```text
Шаг 1: открываем файл
Шаг 2: читаем данные
Шаг 3: обучаем модель
```

Поменяйте строки местами — поменяется и порядок вывода. Нажмите «✎ Изменить» и попробуйте.

> **Интерпретатор vs компилятор.** Языки вроде C++ сначала целиком переводятся в машинный код (компиляция), и только потом программа запускается. Python переводит и выполняет код «на лету». Цена — Python медленнее C++. Плата за скорость разработки. Поэтому тяжёлые вычисления в AI (умножение огромных матриц) библиотеки вроде NumPy и PyTorch делают на C/C++/CUDA, а Python лишь «командует» ими.

### Где запускают Python

- **Здесь, в браузере.** Платформа использует Pyodide — интерпретатор Python, работающий внутри веб-страницы. Удобно для учёбы.
- **На своём компьютере.** Устанавливается с python.org, программы запускаются командой `python my_script.py`.
- **В Jupyter Notebook / Google Colab.** Код разбит на ячейки, результат каждой виден сразу. Это стандартный инструмент для работы с данными и ML.
- **На сервере.** Готовые AI-сервисы (например, чат-бот компании) работают на серверах как Python-приложения.

## Функция print()

`print()` — функция, которая **выводит** значения на экран (точнее, в стандартный поток вывода). Это главный способ увидеть, что происходит в программе.

Синтаксис: имя функции, затем в круглых скобках — что вывести.

```python
print("Я учу Python")
print(42)
print(3.14)
```

```text
Я учу Python
42
3.14
```

Текст обязательно берётся в кавычки — одинарные или двойные, Python всё равно:

```python
print('Одинарные кавычки')
print("Двойные кавычки")
print("Внутри двойных можно 'одинарные'")
```

Числа пишутся без кавычек. И это не просто формальность: `42` — число, с ним можно считать, а `"42"` — текст из двух символов.

```python
print(2 + 3)
print("2 + 3")
```

```text
5
2 + 3
```

В первой строке Python **вычислил** выражение и вывел результат. Во второй — вывел текст как есть.

### Несколько значений через запятую

В `print()` можно передать несколько значений через запятую. По умолчанию они выводятся через пробел:

```python
print("Возраст:", 25)
print("Сумма:", 10 + 5, "рублей")
```

```text
Возраст: 25
Сумма: 15 рублей
```

### Параметры sep и end

У `print()` есть настройки. Параметр `sep` (от separator — разделитель) задаёт, чем разделять значения:

```python
print(2026, 10, 16, sep="-")
print("a", "b", "c", sep="")
print("x", "y", sep=" | ")
```

```text
2026-10-16
abc
x | y
```

Параметр `end` задаёт, чем закончить вывод. По умолчанию это перевод строки, поэтому каждый `print()` начинается с новой строки. Можно заменить:

```python
print("Загрузка", end="")
print("...", end="")
print(" готово")
```

```text
Загрузка... готово
```

### Пустой print()

Вызов без аргументов выводит пустую строку — удобно, чтобы разделить блоки вывода:

```python
print("Раздел 1")
print()
print("Раздел 2")
```

```text
Раздел 1

Раздел 2
```

### Специальные символы

Внутри строки обратная косая черта `\` начинает специальную последовательность:

- `\n` — перевод строки,
- `\t` — табуляция,
- `\"` и `\'` — кавычка внутри строки.

```python
print("Первая строка\nВторая строка")
print("Имя:\tАда")
```

```text
Первая строка
Вторая строка
Имя:	Ада
```

## Функции: первый взгляд

`print` — это **функция**: именованный кусок кода, который что-то делает. Чтобы её **вызвать**, после имени пишут круглые скобки, а внутри — **аргументы**, то есть данные для работы. Без скобок функция не вызывается:

```python
print
```

Этот код ничего не выведет: мы лишь упомянули функцию, но не вызвали её. Позже вы будете писать собственные функции, а пока запомните форму: `имя(аргументы)`.

В Python десятки встроенных функций: `len()` считает длину, `round()` округляет, `input()` читает ввод. Их вы встретите в следующих уроках.

## Что происходит внутри print()

Полезно понимать, что `print()` делает «под капотом», — это пригодится, когда вы начнёте выводить сложные объекты: массивы, таблицы, ответы моделей.

1. **Вычисляет аргументы.** Если передано выражение (`2 + 3`), сначала считается его значение. Функция получает уже готовые значения, а не текст выражения.
2. **Превращает каждое значение в строку.** Для этого вызывается встроенная функция `str()`. Число `42` становится текстом `"42"`, дробь `0.5` — текстом `"0.5"`.
3. **Склеивает строки**, вставляя между ними `sep`, а в конце добавляет `end`.
4. **Записывает результат в стандартный поток вывода** (stdout). В терминале это экран, на этой платформе — панель «Вывод».

Шаг 2 объясняет, почему можно смешивать текст и числа: print() сам приводит всё к строкам.

```python
print("Точность модели:", 0.93, "| Эпох:", 10)
```

```text
Точность модели: 0.93 | Эпох: 10
```

А шаг 1 объясняет, почему `print(10 / 4)` выводит `2.5`: сначала выполняется деление, а печатается уже результат.

## Комбинируем всё вместе

Соберём небольшой «отчёт» об обучении модели только с помощью `print()`:

```python
print("=== Отчёт об обучении ===")
print("Модель:", "классификатор отзывов")
print("Эпох:", 5, sep="\t")
print("Время, мин:", 3 * 12)
print()
print("Статус", "готово", sep=": ")
```

```text
=== Отчёт об обучении ===
Модель: классификатор отзывов
Эпох:	5
Время, мин: 36

Статус: готово
```

Здесь каждая строка вывода — отдельный вызов, `sep` меняет разделитель, а выражение `3 * 12` вычисляется до печати.

## Как читать код: три уровня

Новички часто пытаются «прочитать» программу как книгу — быстро и целиком. Опытные разработчики читают код на трёх уровнях:

1. **Что делает каждая строка.** `print("Эпох:", 5, sep="\t")` — вывести слово и число через табуляцию.
2. **В каком порядке это происходит.** Сверху вниз; внутри строки — сначала аргументы, потом вызов функции.
3. **Зачем это всё.** Вся программа выше — это отчёт о результатах обучения.

Привыкайте задавать себе эти три вопроса с первого урока. Когда программы станут длиннее, именно этот навык позволит быстро разбираться в чужом коде — а AI-инженер читает чужой код (библиотек, примеров, моделей) больше, чем пишет свой.

## Итоги урока

- Программа — последовательность однозначных инструкций; Python выполняет их сверху вниз.
- Интерпретатор сначала проверяет синтаксис всего файла, затем выполняет код.
- `print()` вычисляет аргументы, превращает их в строки, соединяет через `sep` и завершает `end`.
- Текст — в кавычках, числа — без. Регистр букв важен.

## Частые ошибки

**1. Кавычки не закрыты.**

```python
print("Привет)
```

Python сообщит `SyntaxError: unterminated string literal` — строка не закрыта. Каждая открывающая кавычка должна иметь пару того же вида.

**2. Скобка не закрыта.**

```python
print("Привет"
```

Ошибка `SyntaxError: '(' was never closed`. Следите за парностью скобок — редактор подсвечивает пары.

**3. Заглавная буква.** Python различает регистр: `Print` и `print` — разные имена.

```python
Print("Привет")
```

Будет `NameError: name 'Print' is not defined`.

**4. Текст без кавычек.**

```python
print(Привет)
```

Python решит, что `Привет` — это имя переменной, и сообщит `NameError`. Текст всегда в кавычках.

**5. Лишние пробелы в начале строки.** Отступы в Python — часть синтаксиса (подробно — в блоке про условия). Строка верхнего уровня должна начинаться с начала:

```python
 print("Привет")
```

Результат: `IndentationError: unexpected indent`.

**6. Путать вывод и вычисление.** `print("2 + 2")` выведет текст `2 + 2`, а не `4`.

## Где это в AI-инженерии

- **Отладка.** Самый частый инструмент AI-инженера — `print()`: посмотреть, что вернула модель, какой формы получился массив, что пришло от API. Позже вы освоите логирование, но принцип тот же.
- **Логи обучения.** Во время обучения нейросети каждую эпоху выводится что-то вроде `epoch 3 | loss 0.412 | accuracy 0.87`. Это обычный `print()` с параметрами `sep` и `end`.
- **Индикаторы прогресса.** Строки вида `Обработано 500/1000` обновляются на месте благодаря `end="\r"` — возврату каретки.
- **Стриминг ответов LLM.** Когда чат-бот печатает ответ «по словам», каждый новый кусочек текста выводится через `print(chunk, end="", flush=True)` — без перевода строки. Вы напишете такой код в части 7.

Главное из урока: программа — последовательность инструкций, Python выполняет их сверху вниз, а `print()` — ваше окно внутрь программы.
