# lambda, map, filter и sorted с key

## Функции — тоже объекты

В Python функция — такой же объект, как число или строка. Её можно присвоить переменной, положить в список или словарь, передать в другую функцию как аргумент и вернуть из функции (вы уже делали это в уроке про замыкания):

```python
def shout(text):
    return text.upper() + "!"


speak = shout
print(speak("привет"))
actions = {"громко": shout, "тихо": str.lower}
print(actions["тихо"]("ТИШИНА"))
print(type(shout))
```

```text
ПРИВЕТ!
тишина
<class 'function'>
```

Обратите внимание: `speak = shout` — **без скобок**. Мы не вызываем функцию, а даём ей второе имя. Со скобками (`shout()`) была бы попытка вызова.

Функции, которые **принимают** другие функции или **возвращают** их, называют **функциями высшего порядка**. Вы уже пользовались ими: `sorted(words, key=len)` — `sorted` принимает функцию `len` и вызывает её для каждого элемента. В этом уроке — главные инструменты этого стиля: `lambda`, `map`, `filter` и `key`-функции.

## lambda: функция в одну строку

Часто функция нужна лишь для того, чтобы передать её куда-то один раз, — например, как ключ сортировки. Писать для этого полноценный `def` громоздко. Для таких случаев есть **lambda-выражение** — анонимная (безымянная) функция:

```python
square = lambda x: x * x
add = lambda a, b: a + b
print(square(5), add(2, 3))
```

```text
25 5
```

Синтаксис: `lambda параметры: выражение`. Это эквивалентно:

```python norun
def square(x):
    return x * x
```

Ограничения lambda:

- тело — **одно выражение** (без `if`-инструкций, циклов, присваиваний); результат выражения возвращается автоматически, `return` не пишется;
- можно использовать тернарный оператор: `lambda x: "чёт" if x % 2 == 0 else "нечет"`.

Присваивать lambda переменной, как в примере выше, — **плохая практика** (PEP 8 прямо это не рекомендует): если функции нужно имя, пишите `def`. У `def` есть нормальное имя в traceback, можно добавить docstring и несколько строк. Настоящее место lambda — **аргумент другой функции**, прямо в месте использования.

## sorted, min, max с key

Самое частое применение lambda — ключ сортировки. В уроке про списки мы сортировали по встроенным функциям (`key=len`, `key=str.lower`). С lambda можно сортировать по **любому признаку**:

```python
students = [
    {"name": "Ада", "score": 95, "age": 36},
    {"name": "Алан", "score": 88, "age": 41},
    {"name": "Грейс", "score": 95, "age": 85},
]
by_score = sorted(students, key=lambda s: s["score"], reverse=True)
print([s["name"] for s in by_score])
oldest = max(students, key=lambda s: s["age"])
print(oldest["name"])
```

```text
['Ада', 'Грейс', 'Алан']
Грейс
```

`key=lambda s: s["score"]` — «для каждого студента сравнивай его поле score». Это та самая строка, которая в уроке про вложенные структуры потребовала трюка с кортежами.

### Сортировка по нескольким признакам

Ключ может возвращать **кортеж** — тогда сравнение идёт по первому элементу, при равенстве по второму:

```python
students = [
    {"name": "Ада", "score": 95},
    {"name": "Алан", "score": 88},
    {"name": "Грейс", "score": 95},
    {"name": "Билл", "score": 88},
]
ranked = sorted(students, key=lambda s: (-s["score"], s["name"]))
print([f"{s['name']} {s['score']}" for s in ranked])
```

```text
['Ада 95', 'Грейс 95', 'Алан 88', 'Билл 88']
```

Трюк `-s["score"]`: минус превращает «по убыванию балла» в «по возрастанию отрицательного балла», а имя при этом сортируется по возрастанию. Так в одном ключе комбинируются разные направления сортировки (для чисел).

### Сортировка словаря по значениям

```python
counts = {"кот": 3, "пёс": 5, "мышь": 1}
for word, count in sorted(counts.items(), key=lambda pair: pair[1], reverse=True):
    print(word, count)
```

```text
пёс 5
кот 3
мышь 1
```

`counts.items()` даёт пары `(слово, частота)`, `pair[1]` — частота. Это альтернатива `sorted(counts, key=counts.get)`, когда нужны сразу и ключи, и значения.

## map: применить функцию к каждому элементу

`map(функция, последовательность)` применяет функцию к каждому элементу и выдаёт результаты:

```python
numbers = ["3", "1", "4"]
print(list(map(int, numbers)))
print(list(map(lambda x: x * 10, [1, 2, 3])))
print(list(map(str.strip, ["  a ", "b  "])))
```

```text
[3, 1, 4]
[10, 20, 30]
['a', 'b']
```

`map` возвращает **ленивый** объект (как `range`): он вычисляет элементы по мере перебора. Чтобы увидеть всё сразу, оборачивают в `list()`. Его можно передать прямо в `sum`, `max`, `" ".join` или распаковать:

```python
a, b = map(int, "10 20".split())
print(a + b)
print(sum(map(len, ["ab", "cde", "f"])))
```

```text
30
6
```

`a, b = map(int, input().split())` — классическая идиома чтения нескольких чисел из одной строки ввода.

С несколькими последовательностями `map` работает как `zip` + функция:

```python
print(list(map(lambda x, y: x * y, [1, 2, 3], [10, 20, 30])))
```

```text
[10, 40, 90]
```

## filter: отобрать подходящие

`filter(функция, последовательность)` оставляет элементы, для которых функция вернула истинное значение:

```python
numbers = [5, -2, 8, 0, -7, 3]
print(list(filter(lambda n: n > 0, numbers)))
words = ["", "кот", "", "пёс"]
print(list(filter(None, words)))
```

```text
[5, 8, 3]
['кот', 'пёс']
```

`filter(None, ...)` — особый случай: оставляет truthy-элементы (отбрасывает пустые строки, нули, `None`).

## map/filter или comprehension?

Всё, что делают `map` и `filter`, можно записать comprehension'ом:

```python
numbers = [5, -2, 8, 0]
print(list(map(lambda x: x * 2, numbers)))
print([x * 2 for x in numbers])
print(list(filter(lambda x: x > 0, numbers)))
print([x for x in numbers if x > 0])
```

```text
[10, -4, 16, 0]
[10, -4, 16, 0]
[5, 8]
[5, 8]
```

Как выбирать:

- если функция уже есть по имени (`int`, `str.strip`, `len`, ваша `clean_text`) — `map(int, data)` короче и читается хорошо;
- если пришлось бы писать `lambda` — comprehension почти всегда понятнее: `[x * 2 for x in data]` проще, чем `map(lambda x: x * 2, data)`;
- если нужно и преобразовать, и отфильтровать — однозначно comprehension.

Сообщество Python в целом предпочитает comprehensions, но `map` с готовыми функциями — вполне идиоматичен.

## functools: reduce и partial (кратко)

В модуле `functools` есть ещё два классических инструмента функционального стиля (подробно — в блоке 2.4):

```python
from functools import partial, reduce

product = reduce(lambda acc, x: acc * x, [1, 2, 3, 4, 5])
print(product)
round2 = partial(round, ndigits=2)
print(round2(3.14159), round2(2.71828))
```

```text
120
3.14 2.72
```

- `reduce` сворачивает последовательность в одно значение, применяя функцию к накопителю и очередному элементу — обобщение шаблона «накопитель».
- `partial` создаёт новую функцию с «зафиксированными» аргументами.

## Таблица функций: диспетчеризация

Поскольку функции — объекты, их удобно хранить в словаре и выбирать по ключу. Этот приём заменяет длинные цепочки `if/elif`:

```python
operations = {
    "+": lambda a, b: a + b,
    "-": lambda a, b: a - b,
    "*": lambda a, b: a * b,
    "/": lambda a, b: a / b if b != 0 else None,
}
for op in ["+", "*", "/"]:
    print(op, operations[op](12, 4))
```

```text
+ 16
* 48
/ 3.0
```

Добавить операцию — значит добавить строку в словарь, не трогая остальной код. Именно так устроен вызов инструментов AI-агента: словарь «имя инструмента → функция», модель возвращает имя и аргументы, код вызывает `tools[name](**arguments)`.

## Разбор задачи: ранжирование ответов модели

Модель сгенерировала несколько вариантов ответа, у каждого — оценка уверенности и длина. Нужно отбросить пустые, отсортировать по уверенности (при равенстве — более короткие выше) и показать топ-2:

```python
candidates = [
    {"text": "Париж", "confidence": 0.92},
    {"text": "", "confidence": 0.99},
    {"text": "Столица Франции — Париж.", "confidence": 0.92},
    {"text": "Лион", "confidence": 0.31},
]
valid = filter(lambda c: c["text"].strip(), candidates)
ranked = sorted(valid, key=lambda c: (-c["confidence"], len(c["text"])))
for c in ranked[:2]:
    print(f'{c["confidence"]:.2f} | {c["text"]}')
```

```text
0.92 | Париж
0.92 | Столица Франции — Париж.
```

Пустой ответ с максимальной уверенностью отброшен фильтром, равные по уверенности упорядочены по длине. Такая пост-обработка нескольких вариантов (`n > 1` в API) — реальный приём повышения качества ответов (best-of-n).

## Частые ошибки

**1. Вызывать функцию вместо передачи.** `sorted(data, key=len())` — ошибка; нужно `key=len`. Аналогично `map(int(), data)`.

**2. Присваивать lambda переменной.** `f = lambda x: ...` — используйте `def f(x):`.

**3. Сложная логика в lambda.** Если выражение не читается с первого взгляда — вынесите в `def` с говорящим именем.

**4. Забыть `list()` вокруг `map`/`filter`.** `print(map(...))` выведет `<map object at 0x...>`.

**5. Повторный перебор map/filter.** Они ленивые и одноразовые: после первого `list()` второй вернёт пустой список.

**6. Отрицание строк в ключе.** Трюк `-x` работает только для чисел. Для строк по убыванию — `reverse=True` или сортировка в два прохода (стабильность).

## Где это в AI-инженерии

- **Ранжирование.** `sorted(documents, key=lambda d: d["score"], reverse=True)[:k]` — top-k в ретривере RAG.
- **pandas.** `df["text"].apply(lambda t: t.lower())`, `df.sort_values(key=...)` — та же идея на таблицах (блок 4.2).
- **Предобработка.** `list(map(clean_text, texts))`, `dataset.map(tokenize)` в Hugging Face Datasets — применение функции ко всему датасету.
- **Инструменты агента.** Словарь функций `tools = {"search": search, "calculator": calc}` и вызов по имени — сердце агентного цикла (блок 7.6).
- **Метрики и колбэки.** Функции передаются в фреймворки обучения как параметры: `compute_metrics=my_metrics` в Hugging Face Trainer, `key`/`scoring` в scikit-learn.
- **Выбор лучшего ответа.** `max(candidates, key=score_fn)` — best-of-n и LLM-as-a-judge (блок 7.7).

## Итоги урока

- Функции — объекты: их можно присваивать, хранить в словарях, передавать и возвращать.
- `lambda параметры: выражение` — короткая анонимная функция, в основном для аргументов вроде `key`.
- `sorted`/`min`/`max` с `key=lambda ...` — сортировка и поиск по любому признаку; кортеж в ключе — несколько признаков.
- `map(f, seq)` — применить функцию к каждому; `filter(f, seq)` — отобрать; оба ленивые.
- С lambda обычно понятнее comprehension; `map` хорош с готовыми функциями.
- Словарь функций заменяет длинные `if/elif` и лежит в основе вызова инструментов агентами.
