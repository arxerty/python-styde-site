# *args и **kwargs

## Функции с любым числом аргументов

Встроенные функции умеют принимать произвольное количество аргументов: `print("a")`, `print("a", "b", "c")`, `max(3, 7)`, `max(3, 7, 1, 9)`. Как написать такую функцию самому? Можно, конечно, принимать список: `total([1, 2, 3])`. Но иногда удобнее вызывать функцию как `total(1, 2, 3)`. Для этого в Python есть два механизма:

- **`*args`** — собирает лишние **позиционные** аргументы в кортеж;
- **`**kwargs`** — собирает лишние **именованные** аргументы в словарь.

Имена `args` (arguments) и `kwargs` (keyword arguments) — соглашение. Значение имеют звёздочки: можно написать `*numbers` или `**options`, и часто так даже понятнее.

## *args: позиционные аргументы в кортеж

```python
def total(*numbers):
    print(type(numbers), numbers)
    return sum(numbers)


print(total(1, 2, 3))
print(total(10))
print(total())
```

```text
<class 'tuple'> (1, 2, 3)
6
<class 'tuple'> (10,)
10
<class 'tuple'> ()
0
```

Параметр со звёздочкой собирает все переданные позиционные аргументы в **кортеж**. Если аргументов нет — кортеж пустой. Внутри функции это обычный кортеж: его можно перебрать, измерить, проиндексировать.

`*args` можно сочетать с обычными параметрами. Обычные получают свои аргументы первыми, остаток уходит в `*args`:

```python
def log(level, *messages):
    print(f"[{level}]", " | ".join(messages))


log("INFO", "сервер запущен")
log("ERROR", "нет ключа API", "запрос отклонён", "повтор через 5 с")
```

```text
[INFO] сервер запущен
[ERROR] нет ключа API | запрос отклонён | повтор через 5 с
```

Это та же идея, что у звёздочной распаковки `first, *rest = seq` из урока про кортежи — только в определении функции.

### Параметры после *args — только именованные

Всё, что стоит **после** `*args`, можно передать только по имени (как после одиночной `*` из прошлого урока):

```python
def join_words(*words, sep=" "):
    return sep.join(words)


print(join_words("машинное", "обучение"))
print(join_words("a", "b", "c", sep="-"))
```

```text
машинное обучение
a-b-c
```

Иначе Python не смог бы понять, где кончаются слова и начинается разделитель. Именно так устроен `print(*objects, sep=" ", end="\n")`.

## **kwargs: именованные аргументы в словарь

```python
def describe(**info):
    print(type(info))
    for key, value in info.items():
        print(f"  {key} = {value}")


describe(model="mini", layers=12, trained=True)
```

```text
<class 'dict'>
  model = mini
  layers = 12
  trained = True
```

Двойная звёздочка собирает все именованные аргументы, для которых нет отдельных параметров, в **словарь**: ключи — имена, значения — переданные значения. Порядок сохраняется.

### Полная сигнатура

Все виды параметров можно сочетать в строгом порядке:

```python norun
def f(обязательные, со_значением=..., *args, только_именованные=..., **kwargs):
```

```python
def request(url, method="GET", *path_parts, timeout=10, **headers):
    full_url = "/".join([url, *path_parts])
    return f"{method} {full_url} timeout={timeout} headers={headers}"


print(request("https://api.ai", "POST", "v1", "chat", timeout=30, Authorization="Bearer xxx"))
```

```text
POST https://api.ai/v1/chat timeout=30 headers={'Authorization': 'Bearer xxx'}
```

На практике такие «всеядные» сигнатуры встречаются редко — чем больше видов параметров, тем сложнее понять функцию. Используйте `*args` и `**kwargs`, когда это действительно упрощает вызов.

## Звёздочки при вызове: распаковка

Звёздочки работают и в обратную сторону — **при вызове** функции они **распаковывают** коллекцию в отдельные аргументы:

```python
def describe(model, params, year):
    return f"{model}: {params} млрд, {year}"


data = ["GPT-3", 175, 2020]
print(describe(*data))
config = {"model": "BERT", "params": 0.34, "year": 2018}
print(describe(**config))
```

```text
GPT-3: 175 млрд, 2020
BERT: 0.34 млрд, 2018
```

- `*список` — элементы становятся позиционными аргументами по порядку;
- `**словарь` — пары становятся именованными аргументами (ключи должны совпадать с именами параметров).

Распаковка при вызове особенно полезна, когда параметры хранятся в конфигурации:

```python
def train(*, epochs, learning_rate, batch_size):
    return f"{epochs} эпох, lr={learning_rate}, batch={batch_size}"


config = {"epochs": 5, "learning_rate": 0.001, "batch_size": 32}
print(train(**config))
print(train(**config | {"epochs": 50}))
```

```text
5 эпох, lr=0.001, batch=32
50 эпох, lr=0.001, batch=32
```

Второй вызов: слияние словарей (урок про словари) переопределяет один параметр, а `**` превращает результат в аргументы. Так запускают эксперименты с разными настройками.

Вы уже встречали распаковку при вызове: `print(*items)` печатает элементы через пробел, а `zip(*matrix)` транспонирует матрицу — каждая строка становится отдельным аргументом `zip`.

```python
items = ["a", "b", "c"]
print(items)
print(*items)
print(*items, sep=", ")
```

```text
['a', 'b', 'c']
a b c
a, b, c
```

## Передача аргументов дальше

Главное практическое применение `*args` и `**kwargs` — **функции-обёртки**, которые принимают любые аргументы и передают их другой функции без изменений:

```python
def call_with_log(func, *args, **kwargs):
    print(f"Вызов {func.__name__} с args={args}, kwargs={kwargs}")
    result = func(*args, **kwargs)
    print(f"Результат: {result}")
    return result


call_with_log(round, 3.14159, 2)
call_with_log(sorted, [3, 1, 2], reverse=True)
```

```text
Вызов round с args=(3.14159, 2), kwargs={}
Результат: 3.14
Вызов sorted с args=([3, 1, 2],), kwargs={'reverse': True}
Результат: [3, 2, 1]
```

Обёртке не нужно знать, какие параметры у оборачиваемой функции: `*args, **kwargs` в определении «ловят» всё, а `*args, **kwargs` в вызове «отдают» всё. Функции, которые принимают другие функции (здесь `func`), — функции высшего порядка; ими займёмся в уроке 5 и в части 2. На этом приёме построены **декораторы** — например, `@retry`, который повторяет вызов LLM API при сбое (блок 2.4).

## Как не злоупотреблять

`**kwargs` удобен, но у него есть цена:

- **Опечатки не ловятся.** `train(lerning_rate=0.1)` с явными параметрами даст ошибку сразу, а с `**kwargs` значение молча попадёт в словарь и проигнорируется.
- **Непонятно, что передавать.** Сигнатура `def f(**kwargs)` ничего не говорит о допустимых параметрах — приходится читать код или документацию.
- **Нет подсказок в редакторе.** Автодополнение не знает имён параметров.

Правило: **явные параметры, когда они известны; `*args`/`**kwargs` — для обёрток и действительно переменного числа аргументов.**

## Разбор задачи: гибкая функция статистики

Напишем функцию, которая принимает любое число значений и опции подсчёта:

```python
def stats(*values, precision=2, include=("mean", "min", "max")):
    if not values:
        return {}
    result = {}
    if "mean" in include:
        result["mean"] = round(sum(values) / len(values), precision)
    if "min" in include:
        result["min"] = min(values)
    if "max" in include:
        result["max"] = max(values)
    if "count" in include:
        result["count"] = len(values)
    return result


print(stats(4, 8, 15, 16, 23, 42))
print(stats(1, 2, precision=0, include=("mean", "count")))
scores = [5, 4, 5]
print(stats(*scores))
print(stats())
```

```text
{'mean': 18.0, 'min': 4, 'max': 42}
{'mean': 2.0, 'count': 2}
{'mean': 4.67, 'min': 4, 'max': 5}
{}
```

Обратите внимание:

- значения передаются как отдельные аргументы, а готовый список — распаковкой `*scores`;
- опции идут после `*values`, поэтому передаются только по имени — их невозможно случайно принять за значение;
- умолчание `include` — **кортеж**, а не список: неизменяемое значение по умолчанию безопасно (прошлый урок).

## Частые ошибки

**1. Путать определение и вызов.** В определении `*args` **собирает** аргументы, при вызове `*items` **распаковывает** коллекцию.

**2. Ожидать список.** `*args` — это кортеж; `args.append(...)` не сработает.

**3. Неверный порядок параметров.** `def f(**kwargs, *args)` — `SyntaxError`. Порядок: обычные → `*args` → только именованные → `**kwargs`.

**4. Лишние ключи при `**dict`.** `TypeError: got an unexpected keyword argument` — словарь должен соответствовать параметрам.

**5. Передать список вместо элементов.** `total([1, 2, 3])` даст `args = ([1, 2, 3],)` — один аргумент-список. Нужно `total(*[1, 2, 3])`.

**6. Злоупотребление `**kwargs`.** Скрывает опечатки и делает функцию непонятной.

## Где это в AI-инженерии

- **Обёртки над API.** `def ask(prompt, **params): return client.create(prompt=prompt, **params)` — передать любые параметры генерации дальше без перечисления.
- **Декораторы.** `@retry`, `@timer`, `@cache` (блок 2.4) построены на `def wrapper(*args, **kwargs): return func(*args, **kwargs)`.
- **Конфигурации экспериментов.** `model = Model(**config["model"])`, `train(**config["training"])` — словарь из YAML превращается в аргументы.
- **Hugging Face.** `model(**inputs)` — токенизатор возвращает словарь (`input_ids`, `attention_mask`), который распаковывается в аргументы модели. Одна из самых частых строк в коде с transformers.
- **Инструменты агентов.** Модель возвращает имя инструмента и аргументы в виде словаря (JSON), а код вызывает `tools[name](**arguments)` — ровно распаковка `**`.
- **Логирование.** `logger.info("msg", extra={...})`, `print(*values, sep=" | ")` — переменное число значений.

## Итоги урока

- `*args` в определении собирает лишние позиционные аргументы в кортеж; `**kwargs` — именованные в словарь.
- Параметры после `*args` — только именованные.
- Порядок: обычные → со значением по умолчанию → `*args` → только именованные → `**kwargs`.
- При вызове `*seq` и `**dict` распаковывают коллекции в аргументы.
- `def wrapper(*args, **kwargs): return func(*args, **kwargs)` — основа обёрток и декораторов.
- Предпочитайте явные параметры; `**kwargs` скрывает опечатки.
